    Ms Office মক টেষ্ট — ছেট 3

    মক টেষ্ট ছেট 3 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. এটা স্লাইড দ্ৰুতভাৱে নকল কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + D
    (B) Ctrl + C
    (C) Ctrl + V
    (D) Ctrl + M
    ব্যাখ্যা: বাছনি কৰা স্লাইড দ্ৰুতভাৱে নকল (duplicate) কৰিবলৈ Ctrl + D ব্যৱহাৰ হয়।
    Answer: Ctrl + D
    ২. বুলেট আৰু নাম্বাৰিং কোন টেবৰ অধীনত থাকে?
    (A) Home
    (B) Insert
    (C) Layout
    (D) Design
    ব্যাখ্যা: Bullets আৰু Numbering বিকল্প Home টেবত পোৱা যায়।
    Answer: গৃহপৃষ্ঠা
    ৩. হেডাৰ আৰু ফুটৰ সন্নিবিষ্ট কৰিবলৈ কোন টেব ব্যৱহাৰ হয়?
    (A) Home
    (B) Layout
    (C) Review
    (D) Insert
    ব্যাখ্যা: হেডাৰ আৰু ফুটাৰ যোগ কৰিবলৈ Insert টেব ব্যৱহাৰ হয়।
    Answer: Insert
    ৪. লিখনীৰ শৃংখলা সংযোগ কৰিবলৈ কোন ফলন ব্যৱহাৰ হয়?
    (A) CONCATENATE
    (B) SUM
    (C) JOIN
    (D) MERGE
    ব্যাখ্যা: CONCATENATE ফাংচনে একাধিক লিখা অংশ সংযোগ কৰিবলৈ ব্যৱহাৰ হয়।
    Answer: CONCATENATE
    ৫. সকলো সমল নিৰ্বাচন কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + A
    (B) Ctrl + E
    (C) Ctrl + Q
    (D) Ctrl + S
    ব্যাখ্যা: সকলো সমল বাছনি কৰিবলৈ Ctrl + A ব্যৱহাৰ হয়।
    Answer: Ctrl + A
    ৬. ডেটা এটা নিৰ্দিষ্ট ক্ৰমত সজাবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) ফিল্টাৰ (Filter)
    (B) ফৰ্মেট (Format)
    (C) চৰ্ট (Sort)
    (D) ফাইণ্ড (Find)
    উত্তৰ: চৰ্ট
    ব্যাখ্যা: Sort সুবিধা ব্যৱহাৰ কৰি তথ্য নিৰ্দিষ্ট ক্ৰমত সজোৱা হয়।
    ৭. ফণ্ট গ্ৰুপ কোন টেবৰ অধীনত থাকে?
    (A) Home
    (B) Review
    (C) Insert
    (D) View
    ব্যাখ্যা: Font গ্ৰুপ Home টেবত পোৱা যায়।
    Answer: গৃহপৃষ্ঠা
    ৮. সৰ্বাধিক মান ঘূৰাই দিয়া ফলন কোনটো?
    (A) MAX
    (B) MIN
    (C) SUM
    (D) LARGE
    ব্যাখ্যা: MAX ফাংচনে এটা পৰিসৰৰ পৰা আটাইতকৈ ডাঙৰ মান ঘূৰাই দিয়ে।
    Answer: MAX
    ৯. স্লাইড প্ৰেজেণ্টেচন বনোৱাৰ বাবে কোন এপ্লিকেচন উত্তম?
    (A) MS Excel
    (B) MS PowerPoint
    (C) MS Access
    (D) MS Word
    ব্যাখ্যা: স্লাইড উপস্থাপন সাজিবলৈ MS PowerPoint আটাইতকৈ উপযুক্ত।
    Answer: MS PowerPoint
    ১০. স্লাইডত placeholders ৰ বিন্যাসক কি বুলি কোৱা হয়?
    (A) থীম (Theme)
    (B) স্লাইড ডিজাইন (Slide Design)
    (C) স্লাইড মাষ্টাৰ (Slide Master)
    (D) স্লাইড লে'আউট (Slide Layout)
    উত্তৰ: স্লাইড লে'আউট
    ব্যাখ্যা: স্লাইডত প্লে'ছহ'ল্ডাৰৰ বিন্যাসক Slide Layout বোলা হয়।
    ১১. ইমেইল পঠোৱা আৰু গ্ৰহণ কৰিবলৈ কোন এপ্লিকেচন ব্যৱহাৰ হয়?
    (A) MS Outlook
    (B) MS Word
    (C) MS Excel
    (D) MS Access
    ব্যাখ্যা: MS Outlook ইমেইল পঠিওৱা আৰু লোৱাৰ বাবে ব্যৱহাৰ হয়।
    Answer: MS Outlook
    ১২. ডকুমেণ্টৰ ফুটৰ ক'ত দেখুৱা হয়?
    (A) বাওঁফালে (Left side)
    (B) পৃষ্ঠাৰ তলত (Bottom of the page)
    (C) পৃষ্ঠাৰ ওপৰত (Top of the page)
    (D) পৃষ্ঠাৰ মাজত (Center of the page)
    উত্তৰ: পৃষ্ঠাৰ তলত
    ব্যাখ্যা: নথিপত্ৰৰ ফুটাৰ পৃষ্ঠাৰ তলত দেখা যায়।
    ১৩. MS Excel-ত এটা ফাইলক কি বুলি কোৱা হয়?
    (A) ডেটাবেছ (Database)
    (B) ডকুমেণ্ট (Document)
    (C) ৱৰ্কবুক (Workbook)
    (D) প্ৰেজেণ্টেচন (Presentation)
    উত্তৰ: ৱৰ্কবুক
    ব্যাখ্যা: MS Excel ত এটা ফাইলক ৱৰ্কবুক বোলা হয়।
    ১৪. ডেটাবেছ সৃষ্টি আৰু পৰিচালনা কৰিবলৈ কোন এপ্লিকেচন ব্যৱহাৰ হয়?
    (A) MS PowerPoint
    (B) MS Access
    (C) MS Word
    (D) MS Excel
    ব্যাখ্যা: MS Access ডেটাবেছ সৃষ্টি আৰু পৰিচালনা কৰিবলৈ ব্যৱহাৰ হয়।
    Answer: MS Access
    ১৫. Excel-ত প্ৰতিটো ফৰ্মুলা কোন চিহ্নৰে আৰম্ভ হয়?
    (A) @
    (B) +
    (C) -
    (D) =
    ব্যাখ্যা: Excel ত প্ৰতিটো ফৰ্মুলা = চিহ্নৰ পৰা আৰম্ভ হয়।
    Answer: =
    ১৬. Ctrl + U কিৰ বাবে ব্যৱহাৰ হয়?
    (A) আপাৰকেছ (Uppercase)
    (B) আপডেট (Update)
    (C) আণ্ডাৰলাইন (Underline)
    (D) আনডু (Undo)
    উত্তৰ: আণ্ডাৰলাইন
    ব্যাখ্যা: বাছনি কৰা লিখাৰ তলত ৰেখা (underline) দিবলৈ Ctrl + U ব্যৱহাৰ হয়।
    ১৭. কপি কৰা সমল পেইষ্ট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + P
    (B) Ctrl + V
    (C) Ctrl + C
    (D) Ctrl + X
    ব্যাখ্যা: কপি কৰা সমল পে'ষ্ট কৰিবলৈ Ctrl + V ব্যৱহাৰ হয়।
    Answer: Ctrl + V
    ১৮. ৱৰ্ড কাউণ্ট বিকল্প কোন টেবত উপলব্ধ?
    (A) View
    (B) Insert
    (C) Home
    (D) Review
    ব্যাখ্যা: Word Count বিকল্প Review টেবত উপলব্ধ।
    Answer: Review
    ১৯. কাৰ্ছৰক ডকুমেণ্টৰ আৰম্ভণিলৈ নিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Home
    (B) Alt + Home
    (C) Ctrl + Home
    (D) Ctrl + End
    ব্যাখ্যা: Ctrl + Home য়ে কাৰ্ছৰক নথিপত্ৰৰ আৰম্ভণিলৈ লৈ যায়।
    Answer: Ctrl + Home
    ২০. এটা কাৰ্য পুনৰ কৰিবলৈ (redo) কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + U
    (B) Ctrl + Y
    (C) Ctrl + R
    (D) Ctrl + Z
    ব্যাখ্যা: বাতিল কৰা কাৰ্য পুনৰ কৰিবলৈ (redo) Ctrl + Y ব্যৱহাৰ হয়।
    Answer: Ctrl + Y
    ২১. বৰ্তমান স্লাইডৰ পৰা স্লাইড শ্ব' আৰম্ভ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Alt + F5
    (B) F6
    (C) Shift + F5
    (D) Ctrl + F5
    ব্যাখ্যা: Shift + F5 য়ে বৰ্তমান স্লাইডৰ পৰা স্লাইড শ্ব' আৰম্ভ কৰে।
    Answer: Shift + F5
    ২২. Ctrl + J কোন এলাইনমেণ্টৰ বাবে ব্যৱহাৰ হয়?
    (A) জয়েন (Join)
    (B) জাংক (Junk)
    (C) জাষ্টিফাই (Justify)
    (D) জাম্প (Jump)
    উত্তৰ: জাষ্টিফাই
    ব্যাখ্যা: Ctrl + J য়ে Justify alignment ৰ বাবে ব্যৱহাৰ হয়, যি লিখাক দুয়োফালে সমানভাৱে সজায়।
    ২৩. শাৰী আৰু স্তম্ভৰ ছেদবিন্দুক কি বুলি কোৱা হয়?
    (A) বক্স (Box)
    (B) চেল (Cell)
    (C) ৰেঞ্জ (Range)
    (D) শ্বীট (Sheet)
    উত্তৰ: চেল
    ব্যাখ্যা: শাৰী আৰু স্তম্ভৰ সংযোগস্থলক চেল (cell) বোলা হয়।
    ২৪. কপি কৰিলে নসলনি হোৱা চেল ৰেফাৰেন্সক কি বুলি কোৱা হয়?
    (A) বৃত্তাকাৰ ৰেফাৰেন্স (Circular reference)
    (B) আপেক্ষিক ৰেফাৰেন্স (Relative reference)
    (C) মিশ্ৰ ৰেফাৰেন্স (Mixed reference)
    (D) পৰম ৰেফাৰেন্স (Absolute reference)
    উত্তৰ: পৰম ৰেফাৰেন্স
    ব্যাখ্যা: কপি কৰিলে যি চেল ৰেফাৰেন্স সলনি নহয় তাক absolute reference বোলা হয়।
    ২৫. ফাইণ্ড এণ্ড ৰিপ্লেইচ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + G
    (B) Ctrl + R
    (C) Ctrl + F
    (D) Ctrl + H
    ব্যাখ্যা: Find and Replace ৰ বাবে Ctrl + H ব্যৱহাৰ হয়।
    Answer: Ctrl + H

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
