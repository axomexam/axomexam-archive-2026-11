    Ms Office মক টেষ্ট — ছেট 2

    মক টেষ্ট ছেট 2 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. সকলো স্লাইডৰ থাম্বনেইল দেখুওৱা পেইন কোনটো?
    (A) ষ্টেটাছ বাৰ (Status bar)
    (B) নোটছ পেইন (Notes pane)
    (C) টাস্ক পেইন (Task pane)
    (D) স্লাইড পেইন (Slide pane)
    উত্তৰ: স্লাইড পেইন
    ব্যাখ্যা: Slide পেনে সকলো স্লাইডৰ থাম্বনেইল দেখুৱায়, যাৰ দ্বাৰা দ্ৰুতভাৱে বিচৰণ আৰু পুনৰ্বিন্যাস কৰিব পাৰি।
    ২. নিৰ্বাচিত লিখনী বোল্ড কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + D
    (B) Ctrl + B
    (C) Ctrl + I
    (D) Ctrl + U
    ব্যাখ্যা: Ctrl + B য়ে বাছনি কৰা লিখাক বোল্ড (গাঢ়) কৰে।
    Answer: Ctrl + B
    ৩. MS Word ডকুমেণ্টৰ ডিফল্ট ফাইল এক্সটেনচন কি?
    (A) .xlsx
    (B) .pptx
    (C) .docx
    (D) .txt
    ব্যাখ্যা: MS Word নথিপত্ৰৰ ডিফ'ল্ট ফাইল এক্সটেনশ্যন হৈছে .docx।
    Answer: .docx
    ৪. নতুন স্লাইড সৃষ্টি কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + S
    (B) Ctrl + K
    (C) Ctrl + N
    (D) Ctrl + M
    ব্যাখ্যা: PowerPoint ত নতুন স্লাইড সৃষ্টি কৰিবলৈ Ctrl + M ব্যৱহাৰ হয়।
    Answer: Ctrl + M
    ৫. Excel-ত স্তম্ভবোৰ কিৰে লেবেল কৰা হয়?
    (A) ৰং (Colors)
    (B) সংখ্যা (Numbers)
    (C) আখৰ (Letters)
    (D) চিহ্ন (Symbols)
    উত্তৰ: আখৰ
    ব্যাখ্যা: Excel ত স্তম্ভবোৰ (columns) আখৰেৰে (A, B, C ...) লেবেল কৰা হয়।
    ৬. টেবুল বিকল্প কোন টেবত আছে?
    (A) View
    (B) Insert
    (C) Design
    (D) Home
    ব্যাখ্যা: Table বিকল্প Insert টেবত আছে।
    Answer: Insert
    ৭. সকলো স্লাইডৰ সামগ্ৰিক ডিজাইন সম্পাদনা কৰিবলৈ কোন ভিউৱে অনুমতি দিয়ে?
    (A) নৰ্মাল (Normal)
    (B) ৰিডিং (Reading)
    (C) স্লাইড চৰ্টাৰ (Slide Sorter)
    (D) স্লাইড মাষ্টাৰ (Slide Master)
    উত্তৰ: স্লাইড মাষ্টাৰ
    ব্যাখ্যা: Slide Master দৃশ্যই সকলো স্লাইডৰ সামগ্ৰিক ডিজাইন একেলগে সম্পাদনা কৰিবলৈ দিয়ে।
    ৮. ফৰ্মুলা বাৰে কিৰ সমল দেখুৱায়?
    (A) সক্ৰিয় চেল (The active cell)
    (B) টুলবাৰ (The toolbar)
    (C) ষ্টেটাছ বাৰ (The status bar)
    (D) সমগ্ৰ শ্বীট (The whole sheet)
    উত্তৰ: সক্ৰিয় চেল
    ব্যাখ্যা: ফৰ্মুলা বাৰে সক্ৰিয় চেলৰ সমল দেখুৱায়।
    ৯. নিৰ্বাচিত সমল কাট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + V
    (B) Ctrl + X
    (C) Ctrl + Z
    (D) Ctrl + C
    ব্যাখ্যা: বাছনি কৰা সমল কাট কৰিবলৈ Ctrl + X ব্যৱহাৰ হয়।
    Answer: Ctrl + X
    ১০. শ্ব' চলোঁতে পৰৱৰ্তী স্লাইডলৈ যাবলৈ কোন কি ব্যৱহাৰ হয়?
    (A) Backspace
    (B) স্পেচবাৰ (Spacebar)
    (C) Tab
    (D) Esc
    উত্তৰ: স্পেচবাৰ
    ব্যাখ্যা: স্লাইড শ্ব'ৰ সময়ত Spacebar য়ে পৰৱৰ্তী স্লাইডলৈ যায়।
    ১১. সক্ৰিয় উইণ্ড' বন্ধ কৰিবলৈ কোন কি সংমিশ্ৰণ ব্যৱহাৰ হয়?
    (A) Ctrl + W
    (B) Ctrl + F4
    (C) Alt + F4
    (D) Shift + F4
    ব্যাখ্যা: সক্ৰিয় উইণ্ড' বন্ধ কৰিবলৈ Alt + F4 ব্যৱহাৰ হয়।
    Answer: Alt + F4
    ১২. নামসহ সংৰক্ষিত ফৰ্মেটিং ছেটিংছৰ সংগ্ৰহক কি বুলি কোৱা হয়?
    (A) ষ্টাইল (Style)
    (B) মেক্ৰ' (Macro)
    (C) থীম (Theme)
    (D) টেমপ্লেট (Template)
    উত্তৰ: ষ্টাইল
    ব্যাখ্যা: ষ্টাইল হৈছে এটা নামেৰে সংৰক্ষিত ফৰ্মেটিং ছেটিংছৰ সংগ্ৰহ।
    ১৩. তলৰ কোনটো MS Office এপ্লিকেচন?
    (A) গুগল ক্ৰ'ম (Google Chrome)
    (B) VLC মিডিয়া প্লেয়াৰ (VLC Media Player)
    (C) MS Excel
    (D) এড'বি ফট'শ্বপ (Adobe Photoshop)
    ব্যাখ্যা: MS Excel এটা MS Office এপ্লিকেশ্যন যি স্প্ৰেডশ্বীটৰ বাবে ব্যৱহাৰ হয়।
    Answer: MS Excel
    ১৪. তলৰ কোনটো MS Word-ৰ এটা মানক কাগজৰ আকাৰ?
    (A) A4
    (B) M5
    (C) Z5
    (D) B5
    ব্যাখ্যা: A4 MS Word ত এটা মানক কাগজৰ আকাৰ।
    Answer: A4
    ১৫. MS Excel ৱৰ্কবুকৰ ডিফল্ট ফাইল এক্সটেনচন কি?
    (A) .xlsx
    (B) .docx
    (C) .pptx
    (D) .txt
    ব্যাখ্যা: MS Excel ৱৰ্কবুকৰ ডিফ'ল্ট ফাইল এক্সটেনশ্যন হৈছে .xlsx।
    Answer: .xlsx
    ১৬. কাৰ্ছৰক ডকুমেণ্টৰ শেষলৈ নিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + End
    (B) End
    (C) Alt + End
    (D) Ctrl + Home
    ব্যাখ্যা: Ctrl + End য়ে কাৰ্ছৰক নথিপত্ৰৰ শেষলৈ লৈ যায়।
    Answer: Ctrl + End
    ১৭. ষ্টেটাছ বাৰ সাধাৰণতে ক'ত অৱস্থিত?
    (A) বাওঁফালে (Left side)
    (B) সোঁফালে (Right side)
    (C) উইণ্ড'ৰ তলত (Bottom of the window)
    (D) উইণ্ড'ৰ ওপৰত (Top of the window)
    উত্তৰ: উইণ্ড'ৰ তলত
    ব্যাখ্যা: ষ্টেটাছ বাৰ সাধাৰণতে উইণ্ড'ৰ তলত অৱস্থিত।
    ১৮. লিখনী ইটালিক কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + I
    (B) Ctrl + U
    (C) Ctrl + T
    (D) Ctrl + B
    ব্যাখ্যা: Ctrl + I য়ে লিখাক ইটালিক কৰে।
    Answer: Ctrl + I
    ১৯. স্লাইডৰ বস্তুত গতি যোগ কৰা সুবিধা কোনটো?
    (A) ট্ৰানজিচন (Transition)
    (B) ডিজাইন (Design)
    (C) লে'আউট (Layout)
    (D) এনিমেচন (Animation)
    উত্তৰ: এনিমেচন
    ব্যাখ্যা: এনিমেশ্যনে স্লাইডৰ বস্তুত গতি যোগ কৰে।
    ২০. PowerPoint প্ৰেজেণ্টেচনৰ ডিফল্ট ফাইল এক্সটেনচন কি?
    (A) .mdb
    (B) .pptx
    (C) .docx
    (D) .xlsx
    ব্যাখ্যা: PowerPoint উপস্থাপনৰ ডিফ'ল্ট ফাইল এক্সটেনশ্যন হৈছে .pptx।
    Answer: .pptx
    ২১. চেল ৰেফাৰেন্সত $ চিহ্নে কি সূচাই?
    (A) লিখনী (Text)
    (B) পৰম ৰেফাৰেন্স (Absolute reference)
    (C) আপেক্ষিক ৰেফাৰেন্স (Relative reference)
    (D) মুদ্ৰা (Currency)
    উত্তৰ: পৰম ৰেফাৰেন্স
    ব্যাখ্যা: চেল ৰেফাৰেন্সত $ চিহ্নই পৰম (absolute) ৰেফাৰেন্স সূচায়।
    ২২. MS Office-ৰ ৰিবন কেতবোৰ কিৰ সংগ্ৰহত সজ্জিত?
    (A) অংশ (Sections)
    (B) শ্বীট (Sheets)
    (C) টেব (Tabs)
    (D) পৃষ্ঠা (Pages)
    উত্তৰ: টেব
    ব্যাখ্যা: MS Office ৰ ৰিবন কেইবাটাও টেবত সংগঠিত।
    ২৩. সক্ৰিয় ফাইল প্ৰিন্ট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + Q
    (B) Ctrl + R
    (C) Ctrl + T
    (D) Ctrl + P
    ব্যাখ্যা: সক্ৰিয় ফাইল ছপা কৰিবলৈ Ctrl + P ব্যৱহাৰ হয়।
    Answer: Ctrl + P
    ২৪. বাতৰি কাকতৰ দৰে বিন্যাসত লিখনী সজাবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) কলাম (Columns)
    (B) বৰ্ডাৰ (Borders)
    (C) শ্বেডিং (Shading)
    (D) ষ্টাইল (Styles)
    উত্তৰ: কলাম
    ব্যাখ্যা: Columns সুবিধা ব্যৱহাৰ কৰি সংবাদপত্ৰৰ দৰে বিন্যাসত লিখা সজোৱা হয়।
    ২৫. Excel-ত শাৰীবোৰ কিৰে লেবেল কৰা হয়?
    (A) ৰং (Colors)
    (B) আখৰ (Letters)
    (C) চিহ্ন (Symbols)
    (D) সংখ্যা (Numbers)
    উত্তৰ: সংখ্যা
    ব্যাখ্যা: Excel ত শাৰীবোৰ (rows) সংখ্যাৰে (1, 2, 3 ...) লেবেল কৰা হয়।

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
