    গৃহপৃষ্ঠা/মক টেষ্ট/কম্পিউটাৰ সজাগতা/Fundamentals/Set 6

    Comp Fundamentals মক টেষ্ট — ছেট 6

    মক টেষ্ট ছেট 6 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. BIOS-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) বেচিক ইনপুট আউটপুট চিষ্টেম (Basic Input Output System)
    (B) বেচিক ইণ্টিগ্ৰেটেড অপাৰেটিং চিষ্টেম (Basic Integrated Operating System)
    (C) বাইনেৰী ইনপুট আউটপুট চিষ্টেম (Binary Input Output System)
    (D) বেচিক ইনপুট আউটপুট ছফটৱেৰ (Basic Input Output Software)
    উত্তৰ: বেচিক ইনপুট আউটপুট চিষ্টেম
    ব্যাখ্যা: BIOS ৰ সম্পূৰ্ণ ৰূপ Basic Input Output System। ই কম্পিউটাৰ আৰম্ভ কৰে আৰু বুটিং সময়ত হাৰ্ডৱেৰ পৰীক্ষা কৰে।
    ২. CPU-ৰ কোন অংশই গাণিতিক আৰু যুক্তিমূলক কাৰ্য সম্পাদন কৰে?
    (A) কণ্ট্ৰোল ইউনিট (Control Unit)
    (B) এৰিথমেটিক লজিক ইউনিট (Arithmetic Logic Unit)
    (C) মেমেৰী ইউনিট (Memory Unit)
    (D) ৰেজিষ্টাৰ (Register)
    উত্তৰ: এৰিথমেটিক লজিক ইউনিট
    ব্যাখ্যা: ALU (Arithmetic Logic Unit) য়ে CPU ৰ ভিতৰত সকলো গাণিতিক আৰু যুক্তিমূলক কাৰ্য সম্পাদন কৰে।
    ৩. তলৰ কোনটো পইণ্টিং ইনপুট ডিভাইচ?
    (A) মাউছ (Mouse)
    (B) প্ৰিণ্টাৰ (Printer)
    (C) স্পীকাৰ (Speaker)
    (D) প্লটাৰ (Plotter)
    উত্তৰ: মাউছ
    ব্যাখ্যা: মাউছ এটা পইণ্টিং ইনপুট ডিভাইচ, যি পইণ্টাৰ লৈ যাবলৈ আৰু স্ক্ৰীনত বস্তু বাছনি কৰিবলৈ ব্যৱহাৰ হয়।
    ৪. তলৰ কোনটো ছফট কপি আউটপুট ডিভাইচ?
    (A) কীব’ৰ্ড (Keyboard)
    (B) স্কেনাৰ (Scanner)
    (C) মনিটৰ (Monitor)
    (D) মাউছ (Mouse)
    উত্তৰ: মনিটৰ
    ব্যাখ্যা: মনিটৰে স্ক্ৰীনত আউটপুট দেখুৱায়, যি ছফট কপি।
    ৫. তলৰ কোনটো ইনপুট আৰু আউটপুট দুয়োটা ডিভাইচ?
    (A) টাচ স্ক্ৰীন (Touch screen)
    (B) প্ৰিণ্টাৰ (Printer)
    (C) স্পীকাৰ (Speaker)
    (D) স্কেনাৰ (Scanner)
    উত্তৰ: টাচ স্ক্ৰীন
    ব্যাখ্যা: টাচ স্ক্ৰীনে স্পৰ্শৰে ইনপুট লয় আৰু আউটপুটও দেখুৱায়; সেয়ে ই দুয়োটা হিচাপে কাম কৰে।
    ৬. ১ GB কিমানৰ সমান?
    (A) ১০০০ MB (1000 MB)
    (B) ১০২৪ MB (1024 MB)
    (C) ৫১২ MB (512 MB)
    (D) ২০৪৮ MB (2048 MB)
    উত্তৰ: ১০২৪ MB
    ব্যাখ্যা: ১ GB (গিগাবাইট) = ১০২৪ MB (মেগাবাইট)।
    ৭. ১ নিবল কিমানৰ সমান?
    (A) ২ বিট (2 bits)
    (B) ৮ বিট (8 bits)
    (C) ৪ বিট (4 bits)
    (D) ১৬ বিট (16 bits)
    উত্তৰ: ৪ বিট
    ব্যাখ্যা: ১ নিবল = ৪ বিট, অৰ্থাৎ এটা বাইটৰ আধা।
    ৮. তলৰ কোনটো অপৰিৱৰ্তনশীল (non-volatile) স্মৃতি?
    (A) RAM
    (B) ক্যাশ (Cache)
    (C) ROM
    (D) ৰেজিষ্টাৰ (Register)
    ব্যাখ্যা: ROM অপৰিৱৰ্তনশীল স্মৃতি; বিদ্যুৎ বন্ধ হ'লেও ইয়াৰ তথ্য থাকে।
    Answer: ROM
    ৯. তলৰ কোনটো প্ৰাথমিক স্মৃতি?
    (A) হাৰ্ড ডিস্ক (Hard disk)
    (B) RAM
    (C) DVD
    (D) পেন ড্ৰাইভ (Pen drive)
    ব্যাখ্যা: RAM প্ৰাথমিক স্মৃতি; কম্পিউটাৰ চলি থকা সময়ত CPU য়ে ইয়াক পোনপটীয়াকৈ ব্যৱহাৰ কৰিব পাৰে।
    Answer: RAM
    ১০. GUI-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) গ্ৰাফিকেল ইউজাৰ ইন্টাৰফেচ (Graphical User Interface)
    (B) জেনেৰেল ইউজাৰ ইন্টাৰফেচ (General User Interface)
    (C) গ্ৰাফিকেল ইউটিলিটি ইন্টাৰফেচ (Graphical Utility Interface)
    (D) গাইডেড ইউজাৰ ইন্টাৰফেচ (Guided User Interface)
    উত্তৰ: গ্ৰাফিকেল ইউজাৰ ইন্টাৰফেচ
    ব্যাখ্যা: GUI ৰ সম্পূৰ্ণ ৰূপ Graphical User Interface; ই আইকন, ৱিণ্ডো আৰু মেনু ব্যৱহাৰ কৰে।
    ১১. তলৰ কোনটো চিষ্টেম ছফটৱেৰ?
    (A) MS Excel
    (B) অপাৰেটিং চিষ্টেম (Operating system)
    (C) Google Chrome
    (D) Adobe Photoshop
    উত্তৰ: অপাৰেটিং চিষ্টেম
    ব্যাখ্যা: অপাৰেটিং চিষ্টেম চিষ্টেম ছফটৱেৰ, যি হাৰ্ডৱেৰ পৰিচালনা কৰে আৰু আন প্ৰগ্ৰামৰ বাবে প্লেটফৰ্ম দিয়ে।
    ১২. তলৰ কোনটো স্প্ৰেডশ্বীট এপ্লিকেচন?
    (A) MS Excel
    (B) MS Word
    (C) MS PowerPoint
    (D) MS Access
    ব্যাখ্যা: MS Excel স্প্ৰেডশ্বীট ছফটৱেৰ, যি গণনা, টেবুল আৰু চাৰ্ট তৈয়াৰ কৰিবলৈ ব্যৱহাৰ হয়।
    Answer: MS Excel
    ১৩. তলৰ কোনটো মুক্ত-উৎস (open-source) অপাৰেটিং চিষ্টেম?
    (A) Windows
    (B) macOS
    (C) Linux
    (D) MS Office
    ব্যাখ্যা: Linux এটা open-source অপাৰেটিং চিষ্টেম, যাৰ চোৰ্ছ কোড মুকলিকৈ উপলব্ধ।
    Answer: Linux
    ১৪. Undo-ৰ শ্বৰ্টকাট কি?
    (A) Ctrl + Z
    (B) Ctrl + C
    (C) Ctrl + X
    (D) Ctrl + V
    ব্যাখ্যা: Ctrl + Z হৈ শেষ কাৰ্য বাতিল (undo) কৰাৰ সাধাৰণ শ্বৰ্টকাট।
    Answer: Ctrl + Z
    ১৫. Select All-ৰ শ্বৰ্টকাট কি?
    (A) Ctrl + S
    (B) Ctrl + V
    (C) Ctrl + P
    (D) Ctrl + A
    ব্যাখ্যা: Ctrl + A য়ে বৰ্তমান ৱিণ্ডোৰ সকলো লিখা বা বস্তু বাছনি কৰে।
    Answer: Ctrl + A
    ১৬. কোন কীয়ে কাৰ্ছৰক এটা শাৰীৰ আৰম্ভণিলৈ লৈ যায়?
    (A) End
    (B) Home
    (C) Page Up
    (D) Tab
    ব্যাখ্যা: Home কীয়ে কাৰ্ছৰক বৰ্তমান শাৰীৰ আৰম্ভণিলৈ লৈ যায়।
    Answer: গৃহপৃষ্ঠা
    ১৭. URL-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ইউনিফৰ্ম ৰিছ’ৰ্চ লোকেটৰ (Uniform Resource Locator)
    (B) ইউনিভাৰ্চেল ৰিছ’ৰ্চ লিংক (Universal Resource Link)
    (C) ইউনিফৰ্ম ৰেফাৰেন্স লোকেটৰ (Uniform Reference Locator)
    (D) ইউনাইটেড ৰিছ’ৰ্চ লোকেটৰ (United Resource Locator)
    উত্তৰ: ইউনিফৰ্ম ৰিছ’ৰ্চ লোকেটৰ
    ব্যাখ্যা: URL ৰ সম্পূৰ্ণ ৰূপ Uniform Resource Locator; ই ৱেবত এটা সম্পদৰ ঠিকনা দিয়ে।
    ১৮. DNS-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ডিজিটেল নেটৱৰ্ক চিষ্টেম (Digital Network System)
    (B) ডমেইন নেম চিষ্টেম (Domain Name System)
    (C) ডমেইন নেটৱৰ্ক চাৰ্ভিছ (Domain Network Service)
    (D) ডেটা নেম চিষ্টেম (Data Name System)
    উত্তৰ: ডমেইন নেম চিষ্টেম
    ব্যাখ্যা: DNS ৰ সম্পূৰ্ণ ৰূপ Domain Name System; ই ডমেইন নামক IP ঠিকনালৈ ৰূপান্তৰ কৰে।
    ১৯. তলৰ কোনটো ৱেব ব্ৰাউজাৰ?
    (A) Google Chrome
    (B) MS Word
    (C) Windows
    (D) Photoshop
    ব্যাখ্যা: Google Chrome এটা ৱেব ব্ৰাউজাৰ, যি ইণ্টাৰনেটত ৱেবচাইট চাবলৈ ব্যৱহাৰ হয়।
    Answer: Google Chrome
    ২০. LAN-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) লং এৰিয়া নেটৱৰ্ক (Long Area Network)
    (B) লোকেল এক্সেছ নেটৱৰ্ক (Local Access Network)
    (C) লোকেল এৰিয়া নেটৱৰ্ক (Local Area Network)
    (D) লিংকড এৰিয়া নেটৱৰ্ক (Linked Area Network)
    উত্তৰ: লোকেল এৰিয়া নেটৱৰ্ক
    ব্যাখ্যা: LAN ৰ সম্পূৰ্ণ ৰূপ Local Area Network; ই অফিচ বা বিদ্যালয়ৰ দৰে সৰু এলেকাৰ সঁজুলি সংযোগ কৰে।
    ২১. WAN-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ৱৰ্ল্ড এৰিয়া নেটৱৰ্ক (World Area Network)
    (B) ৱায়াৰলেছ এৰিয়া নেটৱৰ্ক (Wireless Area Network)
    (C) ৱাইড এক্সেছ নেটৱৰ্ক (Wide Access Network)
    (D) ৱাইড এৰিয়া নেটৱৰ্ক (Wide Area Network)
    উত্তৰ: ৱাইড এৰিয়া নেটৱৰ্ক
    ব্যাখ্যা: WAN ৰ সম্পূৰ্ণ ৰূপ Wide Area Network; ই বৃহৎ ভৌগোলিক এলেকা সামৰি লয়।
    ২২. তলৰ কোনটো এণ্টিভাইৰাছ ছফটৱেৰ?
    (A) MS Word
    (B) Norton
    (C) Google Chrome
    (D) Photoshop
    ব্যাখ্যা: Norton এণ্টিভাইৰাছ ছফটৱেৰ, যি ক্ষতিকাৰক প্ৰগ্ৰাম চিনাক্ত আৰু আঁতৰ কৰে।
    Answer: Norton
    ২৩. ফায়াৰৱাল কি কামত ব্যৱহাৰ হয়?
    (A) ইণ্টাৰনেটৰ গতি বঢ়াবলৈ (Increase internet speed)
    (B) অননুমোদিত প্ৰৱেশৰ পৰা নেটৱৰ্ক সুৰক্ষিত কৰিবলৈ (Protect a network from unauthorized access)
    (C) ফাইল স্থায়ীভাৱে সংৰক্ষণ কৰিবলৈ (Store files permanently)
    (D) নথিপত্ৰ ছপাবলৈ (Print documents)
    উত্তৰ: অননুমোদিত প্ৰৱেশৰ পৰা নেটৱৰ্ক সুৰক্ষিত কৰিবলৈ
    ব্যাখ্যা: ফায়াৰৱালে নেটৱৰ্ক ট্ৰেফিক নিৰীক্ষণ আৰু ফিল্টাৰ কৰি অননুমোদিত প্ৰৱেশ বাধা দিয়ে।
    ২৪. PDF-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) পাৰ্ছনেল ডকুমেণ্ট ফাইল (Personal Document File)
    (B) প’ৰ্টেবল ডেটা ফাইল (Portable Data File)
    (C) প্ৰিণ্টেবল ডকুমেণ্ট ফৰ্মেট (Printable Document Format)
    (D) প’ৰ্টেবল ডকুমেণ্ট ফৰ্মেট (Portable Document Format)
    উত্তৰ: প’ৰ্টেবল ডকুমেণ্ট ফৰ্মেট
    ব্যাখ্যা: PDF ৰ সম্পূৰ্ণ ৰূপ Portable Document Format; ই নথিপত্ৰৰ বিন্যাস সংৰক্ষণ কৰে।
    ২৫. পেন ড্ৰাইভ সাধাৰণতে কোন প’ৰ্টত সংযোগ কৰা হয়?
    (A) HDMI প’ৰ্ট (HDMI port)
    (B) USB প’ৰ্ট (USB port)
    (C) VGA প’ৰ্ট (VGA port)
    (D) ইথাৰনেট প’ৰ্ট (Ethernet port)
    উত্তৰ: USB প’ৰ্ট
    ব্যাখ্যা: পেন ড্ৰাইভ তথ্য স্থানান্তৰৰ বাবে USB প’ৰ্টত সংযোগ কৰা হয়।

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
