    Comp Fundamentals মক টেষ্ট — ছেট 7

    মক টেষ্ট ছেট 7 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. কেশ্ব স্মৃতি সাধাৰণতে কোন ধৰণৰ স্মৃতিৰে তৈয়াৰ কৰা হয়?
    (A) SRAM
    (B) DRAM
    (C) ROM
    (D) হাৰ্ড ডিস্ক (Hard disk)
    ব্যাখ্যা: কেশ্ব স্মৃতি সাধাৰণতে SRAM ৰে তৈয়াৰ কৰা হয়, কাৰণ ই DRAM তকৈ দ্ৰুত।
    Answer: SRAM
    ২. কোন স্মৃতিয়ে BIOS আৰু ফাৰ্মৱেৰ সংৰক্ষণ কৰে?
    (A) RAM
    (B) ROM
    (C) কেশ্ব (Cache)
    (D) ৰেজিষ্টাৰ (Register)
    ব্যাখ্যা: ROM য়ে BIOS আৰু ফাৰ্মৱেৰ সংৰক্ষণ কৰে, যি কম্পিউটাৰ আৰম্ভ হ'বলৈ প্ৰয়োজন।
    Answer: ROM
    ৩. তলৰ কোনটো গৌণ সংৰক্ষণ সঁজুলি?
    (A) RAM
    (B) কেশ্ব (Cache)
    (C) DVD
    (D) ৰেজিষ্টাৰ (Register)
    ব্যাখ্যা: DVD গৌণ সংৰক্ষণ, যি তথ্য পিছত ব্যৱহাৰৰ বাবে স্থায়ীভাৱে ৰাখে।
    Answer: DVD
    ৪. ১ MB কিমানৰ সমান?
    (A) ১০০০ KB (1000 KB)
    (B) ১০২৪ KB (1024 KB)
    (C) ৫১২ KB (512 KB)
    (D) ২০৪৮ KB (2048 KB)
    উত্তৰ: ১০২৪ KB
    ব্যাখ্যা: ১ MB (মেগাবাইট) = ১০২৪ KB (কিলোবাইট)।
    ৫. ASCII-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) আমেৰিকান নেশ্যনেল ষ্টেণ্ডাৰ্ড কোড (American National Standard Code)
    (B) আমেৰিকান ষ্টেণ্ডাৰ্ড কোড ফৰ ইনফৰ্মেশ্যন এক্সচেঞ্জ (American Standard Code for Information Exchange)
    (C) আমেৰিকান চিষ্টেম কোড ফৰ ইনফৰ্মেশ্যন ইন্টাৰচেঞ্জ (American System Code for Information Interchange)
    (D) আমেৰিকান ষ্টেণ্ডাৰ্ড কোড ফৰ ইনফৰ্মেশ্যন ইন্টাৰচেঞ্জ (American Standard Code for Information Interchange)
    উত্তৰ: আমেৰিকান ষ্টেণ্ডাৰ্ড কোড ফৰ ইনফৰ্মেশ্যন ইন্টাৰচেঞ্জ
    ব্যাখ্যা: ASCII ৰ সম্পূৰ্ণ ৰূপ American Standard Code for Information Interchange; ই আখৰ এনকোডিংৰ মান।
    ৬. এটা নিবলত কিমান বিট থাকে?
    (A) ৪ বিট (4 bits)
    (B) ৮ বিট (8 bits)
    (C) ২ বিট (2 bits)
    (D) ১৬ বিট (16 bits)
    উত্তৰ: ৪ বিট
    ব্যাখ্যা: এটা নিবলত ৪ বিট থাকে, আনহাতে এটা বাইটত ৮ বিট থাকে।
    ৭. ডাঙৰ অংকন আৰু মানচিত্ৰ ছপাবলৈ কোন সঁজুলি ব্যৱহাৰ হয়?
    (A) প্ৰিণ্টাৰ (Printer)
    (B) প্লটাৰ (Plotter)
    (C) মনিটৰ (Monitor)
    (D) স্পীকাৰ (Speaker)
    উত্তৰ: প্লটাৰ
    ব্যাখ্যা: প্লটাৰ এটা আউটপুট সঁজুলি, যি ডাঙৰ অংকন, মানচিত্ৰ আৰু ডিজাইন ছপাবলৈ ব্যৱহাৰ হয়।
    ৮. নথিপত্ৰ কম্পিউটাৰত স্কেন কৰিবলৈ কোন সঁজুলি ব্যৱহাৰ হয়?
    (A) মাউছ (Mouse)
    (B) কীব’ৰ্ড (Keyboard)
    (C) স্কেনাৰ (Scanner)
    (D) জয়ষ্টিক (Joystick)
    উত্তৰ: স্কেনাৰ
    ব্যাখ্যা: স্কেনাৰে ছপা নথিপত্ৰ আৰু ছবি ডিজিটেল ৰূপলৈ ৰূপান্তৰ কৰে।
    ৯. তলৰ কোনটো সংৰক্ষণ সঁজুলি?
    (A) মনিটৰ (Monitor)
    (B) কীব’ৰ্ড (Keyboard)
    (C) প্ৰিণ্টাৰ (Printer)
    (D) পেন ড্ৰাইভ (Pen drive)
    উত্তৰ: পেন ড্ৰাইভ
    ব্যাখ্যা: পেন ড্ৰাইভ এটা বহনযোগ্য সংৰক্ষণ সঁজুলি, যি তথ্য সংৰক্ষণ আৰু স্থানান্তৰ কৰিবলৈ ব্যৱহাৰ হয়।
    ১০. তলৰ কোনটো প্ৰগ্ৰামিং ভাষা?
    (A) Python
    (B) MS Word
    (C) Windows
    (D) Google Chrome
    ব্যাখ্যা: Python এটা উচ্চস্তৰীয় প্ৰগ্ৰামিং ভাষা, যি কম্পিউটাৰ প্ৰগ্ৰাম লিখিবলৈ ব্যৱহাৰ হয়।
    Answer: Python
    ১১. কোন অনুবাদকে প্ৰগ্ৰাম শাৰী শাৰীকৈ ৰূপান্তৰ কৰে?
    (A) ক’ম্পাইলাৰ (Compiler)
    (B) ইণ্টাৰপ্ৰেটাৰ (Interpreter)
    (C) এচেম্বলাৰ (Assembler)
    (D) লিংকাৰ (Linker)
    উত্তৰ: ইণ্টাৰপ্ৰেটাৰ
    ব্যাখ্যা: ইণ্টাৰপ্ৰেটাৰে প্ৰগ্ৰাম এটা এটা শাৰীকৈ অনুবাদ আৰু সম্পাদন কৰে।
    ১২. কোন অনুবাদকে সম্পূৰ্ণ প্ৰগ্ৰাম একেলগে ৰূপান্তৰ কৰে?
    (A) ইণ্টাৰপ্ৰেটাৰ (Interpreter)
    (B) এচেম্বলাৰ (Assembler)
    (C) ক’ম্পাইলাৰ (Compiler)
    (D) লোডাৰ (Loader)
    উত্তৰ: ক’ম্পাইলাৰ
    ব্যাখ্যা: ক’ম্পাইলাৰে সম্পূৰ্ণ প্ৰগ্ৰাম একেলগে মেচিন কোডলৈ ৰূপান্তৰ কৰে।
    ১৩. HTML-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) হাইপাৰটেক্সট মেচিন লেংগুৱেজ (HyperText Machine Language)
    (B) হাইপাৰলিংক টেক্সট মাৰ্কআপ লেংগুৱেজ (Hyperlink Text Markup Language)
    (C) হাই টেক্সট মাৰ্কআপ লেংগুৱেজ (High Text Markup Language)
    (D) হাইপাৰটেক্সট মাৰ্কআপ লেংগুৱেজ (HyperText Markup Language)
    উত্তৰ: হাইপাৰটেক্সট মাৰ্কআপ লেংগুৱেজ
    ব্যাখ্যা: HTML ৰ সম্পূৰ্ণ ৰূপ HyperText Markup Language, যি ৱেবপৃষ্ঠা তৈয়াৰ কৰিবলৈ ব্যৱহাৰ হয়।
    ১৪. FTP-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ফাইল ট্ৰান্সফাৰ প্ৰট’কল (File Transfer Protocol)
    (B) ফাইল ট্ৰান্সমিছন প্ৰট’কল (File Transmission Protocol)
    (C) ফাষ্ট ট্ৰান্সফাৰ প্ৰট’কল (Fast Transfer Protocol)
    (D) ফাইল টেক্সট প্ৰট’কল (File Text Protocol)
    উত্তৰ: ফাইল ট্ৰান্সফাৰ প্ৰট’কল
    ব্যাখ্যা: FTP ৰ সম্পূৰ্ণ ৰূপ File Transfer Protocol, যি নেটৱৰ্কত কম্পিউটাৰৰ মাজত ফাইল স্থানান্তৰ কৰে।
    ১৫. SMTP-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ছিম্পল মেইল ট্ৰান্সফাৰ প্ৰগ্ৰাম (Simple Mail Transfer Program)
    (B) ছিম্পল মেইল ট্ৰান্সফাৰ প্ৰট’কল (Simple Mail Transfer Protocol)
    (C) ছিকিউৰ মেইল ট্ৰান্সফাৰ প্ৰট’কল (Secure Mail Transfer Protocol)
    (D) ছিম্পল মেছেজ ট্ৰান্সফাৰ প্ৰট’কল (Simple Message Transfer Protocol)
    উত্তৰ: ছিম্পল মেইল ট্ৰান্সফাৰ প্ৰট’কল
    ব্যাখ্যা: SMTP ৰ সম্পূৰ্ণ ৰূপ Simple Mail Transfer Protocol, যি ই-মেইল পঠিয়াবলৈ ব্যৱহাৰ হয়।
    ১৬. IMAP-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ইণ্টাৰনেট মেইল এক্সেছ প্ৰগ্ৰাম (Internet Mail Access Program)
    (B) ইণ্টাৰনেট মেছেজ এক্সেছ প্ৰগ্ৰাম (Internet Message Access Program)
    (C) ইণ্টাৰনেট মেছেজ এক্সেছ প্ৰট’কল (Internet Message Access Protocol)
    (D) ইণ্টাৰনেল মেইল এক্সেছ প্ৰট’কল (Internal Mail Access Protocol)
    উত্তৰ: ইণ্টাৰনেট মেছেজ এক্সেছ প্ৰট’কল
    ব্যাখ্যা: IMAP ৰ সম্পূৰ্ণ ৰূপ Internet Message Access Protocol, যি মেইল চাৰ্ভাৰৰ পৰা ই-মেইল আনিবলৈ ব্যৱহাৰ হয়।
    ১৭. Cut-ৰ শ্বৰ্টকাট কি?
    (A) Ctrl + C
    (B) Ctrl + V
    (C) Ctrl + Z
    (D) Ctrl + X
    ব্যাখ্যা: Ctrl + X য়ে বাছনি কৰা লিখা বা বস্তু কাট (cut) কৰে।
    Answer: Ctrl + X
    ১৮. Save-ৰ শ্বৰ্টকাট কি?
    (A) Ctrl + S
    (B) Ctrl + P
    (C) Ctrl + O
    (D) Ctrl + N
    ব্যাখ্যা: Ctrl + S হৈ ফাইল সংৰক্ষণ কৰাৰ সাধাৰণ শ্বৰ্টকাট।
    Answer: Ctrl + S
    ১৯. Print-ৰ শ্বৰ্টকাট কি?
    (A) Ctrl + O
    (B) Ctrl + P
    (C) Ctrl + S
    (D) Ctrl + F
    ব্যাখ্যা: বেছিভাগ এপ্লিকেচনত Ctrl + P য়ে প্ৰিণ্ট ডায়লগ বক্স খোলে।
    Answer: Ctrl + P
    ২০. ৱেবচাইটৰ ঠিকনাক সাধাৰণতে কি বোলা হয়?
    (A) IP ঠিকনা (IP address)
    (B) ডমেইন নাম (Domain name)
    (C) URL
    (D) HTTP
    ব্যাখ্যা: ৱেবচাইটৰ সম্পূৰ্ণ ঠিকনাক URL (Uniform Resource Locator) বোলা হয়।
    Answer: URL
    ২১. তলৰ কোনটো ম’বাইল অপাৰেটিং চিষ্টেম?
    (A) Windows
    (B) Android
    (C) Linux
    (D) macOS
    ব্যাখ্যা: Android এটা ম’বাইল অপাৰেটিং চিষ্টেম, যি স্মাৰ্টফোন আৰু টেবলেটৰ বাবে তৈয়াৰ কৰা।
    Answer: Android
    ২২. DBMS-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ডেটাবেছ মেনেজমেণ্ট ছফটৱেৰ (Database Management Software)
    (B) ডেটা মেনেজমেণ্ট চিষ্টেম (Data Management System)
    (C) ডেটাবেছ মেনেজমেণ্ট চিষ্টেম (Database Management System)
    (D) ডেটাবেছ মেচিন চিষ্টেম (Database Machine System)
    উত্তৰ: ডেটাবেছ মেনেজমেণ্ট চিষ্টেম
    ব্যাখ্যা: DBMS ৰ সম্পূৰ্ণ ৰূপ Database Management System, যি ডেটাবেছত তথ্য সংৰক্ষণ আৰু পৰিচালনা কৰে।
    ২৩. SQL-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ছিম্পল কোৱেৰী লেংগুৱেজ (Simple Query Language)
    (B) ষ্ট্ৰাকচাৰ্ড কোৱেৰী লজিক (Structured Query Logic)
    (C) ষ্টেণ্ডাৰ্ড কোৱেৰী লেংগুৱেজ (Standard Query Language)
    (D) ষ্ট্ৰাকচাৰ্ড কোৱেৰী লেংগুৱেজ (Structured Query Language)
    উত্তৰ: ষ্ট্ৰাকচাৰ্ড কোৱেৰী লেংগুৱেজ
    ব্যাখ্যা: SQL ৰ সম্পূৰ্ণ ৰূপ Structured Query Language, যি ডেটাবেছৰ সৈতে কাম কৰিবলৈ ব্যৱহাৰ হয়।
    ২৪. তলৰ কোনটো ইউটিলিটি ছফটৱেৰ?
    (A) এণ্টিভাইৰাছ (Antivirus)
    (B) MS Excel
    (C) Google Chrome
    (D) Photoshop
    উত্তৰ: এণ্টিভাইৰাছ
    ব্যাখ্যা: এণ্টিভাইৰাছ ইউটিলিটি ছফটৱেৰ, যি কম্পিউটাৰ চিষ্টেম ৰক্ষণাবেক্ষণ আৰু সুৰক্ষিত কৰাত সহায় কৰে।
    ২৫. তলৰ কোনটো ইনপুট ডিভাইচ নহয়?
    (A) মনিটৰ (Monitor)
    (B) কীব’ৰ্ড (Keyboard)
    (C) মাউছ (Mouse)
    (D) স্কেনাৰ (Scanner)
    উত্তৰ: মনিটৰ
    ব্যাখ্যা: মনিটৰ আউটপুট ডিভাইচ, ইনপুট ডিভাইচ নহয়।

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
