    এটা অট্টালিকা বা চৌহদ সামৰা নেটৱৰ্কক কি বোলা হয়
    Q1. A network that covers a single building or campus is called a
    (A) LAN
    (B) WAN
    (C) MAN
    (D) PAN
    Answer: A) LAN
    LAN এ এটা ঠাই সামৰে। WAN এ নগৰ বা দেশজুৰি ঠাই জোড়ে।
    Explanation: A local area network spans one site. A wide area network joins sites across cities or countries.
    URL ৰ সম্পূৰ্ণ ৰূপ
    Q2. The full form of URL is
    (A) Uniform Resource Locator
    (B) Universal Reference Link
    (C) Uniform Routing Layer
    (D) User Registered Location
    Answer: A) Uniform Resource Locator
    Uniform Resource Locator হ'ল সেই ঠিকনা যি ব্ৰাউজাৰক পৃষ্ঠা ক'ত আছে আৰু কেনেকৈ আনিব কয়।
    Explanation: A uniform resource locator is the address that tells a browser where a page lives and how to fetch it.
    ৱেব পৃষ্ঠা সঞ্চাৰ কৰিবলৈ কোন প্ৰট'কল ব্যৱহৃত হয়
    Q3. Which protocol is used to transfer web pages?
    (A) HTTP
    (B) FTP
    (C) SMTP
    (D) TCP only কেৱল TCP
    Answer: A) HTTP
    HTTP এ ছাৰ্ভাৰ আৰু ব্ৰাউজাৰৰ মাজত পৃষ্ঠা নিয়ে। SMTP এ মেইল পঠিয়ায় আৰু FTP এ ফাইল সৰায়।
    Explanation: Hypertext transfer protocol carries pages between server and browser. SMTP sends mail and FTP moves files.
    192.168.1.1 ৰ দৰে IP ঠিকনা কোন সংস্কৰণৰ
    Q4. An IP address of the form 192.168.1.1 belongs to which version?
    (A) IPv4
    (B) IPv6
    (C) MAC
    (D) URL
    Answer: A) IPv4
    IPv4 এ আঠ বিটৰ চাৰিটা দশমিক গোট ব্যৱহাৰ কৰে। IPv6 এ হেক্সাডেচিমেল গোট ব্যৱহাৰ কৰি বহু দীঘল।
    Explanation: IPv4 uses four decimal groups of eight bits each. IPv6 uses hexadecimal groups and is much longer.
    বেলেগ নেটৱৰ্কৰ মাজত তথ্য পেকেট আগবঢ়োৱা সজুলিটো
    Q5. A device that forwards data packets between different networks is a
    (A) router ৰাউটাৰ
    (B) hub হাব
    (C) repeater ৰিপিটাৰ
    (D) modem মডেম
    A) ৰাউটাৰ
    Answer: A) router
    ৰাউটাৰে গন্তব্য ঠিকনা পঢ়ি পৰৱৰ্তী নেটৱৰ্ক বাছে। হাবে কেবল প্ৰতিটো প'ৰ্টলৈ সংকেত পুনৰাবৃত্তি কৰে।
    Explanation: A router reads the destination address and chooses the next network. A hub only repeats signals to every port.
    WWW ৰ সম্পূৰ্ণ ৰূপ
    Q6. The full form of WWW is
    (A) World Wide Web
    (B) Wide World Web
    (C) World Web Wide
    (D) Web World Wide
    Answer: A) World Wide Web
    World Wide Web ইণ্টাৰনেটৰ ওপৰত দিয়া জড়িত পৃষ্ঠাৰ সমষ্টি। ইণ্টাৰনেট নিজেই তলৰ নেটৱৰ্ক।
    Explanation: The world wide web is the collection of linked pages served over the internet. The internet itself is the underlying network.
    তলৰ কোনটো সন্ধান ইঞ্জিন
    Q7. Which of the following is a search engine?
    (A) Google গুগল
    (B) Chrome ক্ৰম
    (C) Firefox ফায়াৰফক্স
    (D) Windows উইণ্ড'জ
    A) গুগল
    Answer: A) Google
    গুগলে পৃষ্ঠা সূচীবদ্ধ কৰি প্ৰশ্নৰ উত্তৰ দিয়ে। ক্ৰম আৰু ফায়াৰফক্সে ফল দেখুওৱা ব্ৰাউজাৰ।
    Explanation: Google indexes pages and answers queries. Chrome and Firefox are browsers that display the results.
    IPv6 ঠিকনাত থকা বিটৰ সংখ্যা
    Q8. The number of bits in an IPv6 address is
    (A) 128 ১২৮
    (B) 32 ৩২
    (C) 64 ৬৪
    (D) 256 ২৫৬
    A) ১২৮
    Answer: A) 128
    IPv6 এ ১২৮ বিট ব্যৱহাৰ কৰে, সেয়ে বিশাল ঠিকনা স্থান। IPv4 ত কেবল ৩২ বিট, সেয়ে ঠিকনা কমি গৈছিল।
    Explanation: IPv6 uses 128 bits, giving an enormous address space. IPv4 uses only 32 bits, which is why addresses ran short.
    নেটৱৰ্ক কাৰ্ডত সোমাই থকা অদ্বিতীয় হাৰ্ডৱেৰ ঠিকনাক কি বোলা হয়
    Q9. A unique hardware address burned into a network card is called the
    (A) MAC address MAC ঠিকনা
    (B) IP address IP ঠিকনা
    (C) port number প'ৰ্ট সংখ্যা
    (D) domain name ডমেইন নাম
    A) MAC ঠিকনা
    Answer: A) MAC address
    MAC ঠিকনা নিৰ্মাণতে স্থিৰ হয়। IP ঠিকনা দিয়া হয় আৰু সলনি হ'ব পাৰে।
    Explanation: The media access control address is fixed at manufacture. An IP address is assigned and can change.
    তাৰযুক্ত স্থানীয় নেটৱৰ্কত আটাই বেছি ব্যৱহৃত কেবল
    Q10. Which cable is most commonly used for wired local networks?
    (A) twisted pair cable টুইষ্টেড পেয়াৰ কেবল
    (B) coaxial cable ক'এক্সিয়েল কেবল
    (C) fibre optic cable ফাইবাৰ অপটিক কেবল
    (D) telephone wire টেলিফোন তাৰ
    A) টুইষ্টেড পেয়াৰ কেবল
    Answer: A) twisted pair cable
    RJ-45 প্লাগযুক্ত টুইষ্টেড পেয়াৰ সস্তা আৰু সহজ, সেয়ে কাৰ্যালয়ত প্ৰধান। ফাইবাৰ দীঘল পথত ব্যৱহৃত।
    Explanation: Twisted pair with RJ-45 plugs is cheap and easy to install, so it dominates office wiring. Fibre is used for long runs.
    ইমেইল পঠিয়াবলৈ ব্যৱহৃত প্ৰট'কল
    Q11. The protocol used to send email is
    (A) SMTP
    (B) POP3
    (C) IMAP
    (D) HTTP
    Answer: A) SMTP
    SMTP এ ক্লায়েণ্টৰপৰা ছাৰ্ভাৰলৈ মেইল পঠিয়ায়। POP3 আৰু IMAP ইয়াক অনিবলৈ।
    Explanation: Simple mail transfer protocol sends mail from client to server. POP3 and IMAP are for retrieving it.
    https ৰে আৰম্ভ হোৱা ৱেব ঠিকনাই বুজায় যে
    Q12. A web page address beginning with https indicates that
    (A) the connection is encrypted সংযোগ এনক্ৰিপ্ট কৰা আছে
    (B) the site is government owned চাইট চৰকাৰৰ মালিকী
    (C) the page is free of errors পৃষ্ঠা ত্ৰুটিমুক্ত
    (D) the site needs no password চাইটলৈ পাছৱৰ্ড নালাগে
    A) সংযোগ এনক্ৰিপ্ট কৰা আছে
    Answer: A) the connection is encrypted
    s ৰ অৰ্থ সুৰক্ষিত, অৰ্থাৎ তথ্য TLS ৰে এনক্ৰিপ্ট। চাইট কাৰ, তাক ই নকয়।
    Explanation: The s stands for secure, meaning traffic is encrypted with TLS. It says nothing about who owns the site.
    টেলিফোন লাইনৰে স্থানীয় নেটৱৰ্ক ইণ্টাৰনেটত জোড়া সজুলিটো
    Q13. The device that connects a local network to the internet through a telephone line is a
    (A) modem মডেম
    (B) switch স্বিচ
    (C) bridge ব্ৰিজ
    (D) gateway গেটৱে
    A) মডেম
    Answer: A) modem
    মডেমে ডিজিটেল তথ্য আৰু লাইনে কঢ়িয়া যোৱা সংকেতৰ মাজত সলায়। স্বিচে কেবল স্থানীয় প'ৰ্ট জোড়ে।
    Explanation: The modem converts between digital data and the signals the line carries. A switch only links local ports.
    কোন ট'প'লজিয়ে প্ৰতিটো সজুলি এটা কেন্দ্ৰীয় সজুলিৰ সৈতে জোড়ে
    Q14. Which topology connects every device to a single central device?
    (A) star ষ্টাৰ
    (B) ring ৰিং
    (C) bus বাছ
    (D) mesh মেশ
    A) ষ্টাৰ
    Answer: A) star
    ষ্টাৰত প্ৰতিটো ন'ডৰ নিজৰ সংযোগ হাব বা স্বিচলৈ, সেয়ে এটা কেবল নষ্ট হ'লে কেবল সেই ন'ড ক্ষতিগ্ৰস্ত। ৰিঙত তথ্য ন'ডে ন'ডে যায়।
    Explanation: In a star every node has its own link to the hub or switch, so one cable failure affects only that node. A ring passes data node to node.
    DNS ৰ সম্পূৰ্ণ ৰূপ
    Q15. The full form of DNS is
    (A) Domain Name System
    (B) Digital Network Service
    (C) Data Node Server
    (D) Direct Name Search
    Answer: A) Domain Name System
    DNS এ axomexam.in ৰ দৰে নামক নেটৱৰ্কই প্ৰয়োজনীয় সংখ্যা ঠিকনালৈ সলায়।
    Explanation: The domain name system turns a name such as axomexam.in into the numeric address the network needs.
    তলৰ কোনটো বেতাঁৰ নেটৱৰ্কিং প্ৰযুক্তি
    Q16. Which of the following is a wireless networking technology?
    (A) Wi-Fi ৱাই-ফাই
    (B) Ethernet ইথাৰনেট
    (C) USB
    (D) HDMI
    A) ৱাই-ফাই
    Answer: A) Wi-Fi
    ৱাই-ফাইয়ে ৰেডিঅ' তৰংগেৰে তথ্য নিয়ে। ইথাৰনেটলৈ কেবল লাগে, আৰু USB তথা HDMI চমু দূৰত্বৰ সংযোগ।
    Explanation: Wi-Fi carries data over radio waves. Ethernet needs cable, and USB and HDMI are short range device links.
    এটা সংস্থাৰ অন্তৰ্গত ৱেব পৃষ্ঠাৰ সমষ্টিক কি বোলা হয়
    Q17. A collection of web pages belonging to one organisation is called a
    (A) website ৱেবচাইট
    (B) web browser ৱেব ব্ৰাউজাৰ
    (C) search engine সন্ধান ইঞ্জিন
    (D) home page only কেৱল হোম পেজ
    A) ৱেবচাইট
    Answer: A) website
    ৱেবচাইট গোটেই পৃষ্ঠাৰ সমষ্টি। হোম পেজ কেবল প্ৰথম পৃষ্ঠা, আৰু ব্ৰাউজাৰ চোৱা প্ৰগ্ৰাম।
    Explanation: A website is the whole set of pages. A home page is only its first page, and a browser is the program used to view it.
    নেটৱৰ্ক সংযোগৰ বেণ্ডৱিথ কিৰে জোখা হয়
    Q18. Bandwidth of a network connection is measured in
    (A) bits per second প্ৰতি ছেকেণ্ডত বিট
    (B) hertz per metre প্ৰতি মিটাৰত হাৰ্টজ
    (C) bytes per metre প্ৰতি মিটাৰত বাইট
    (D) cycles per minute প্ৰতি মিনিটত চক্ৰ
    A) প্ৰতি ছেকেণ্ডত বিট
    Answer: A) bits per second
    বেণ্ডৱিথে প্ৰতি ছেকেণ্ডত কিমান বিট যাব পাৰে গণে, সেয়ে মেগাবিট প্ৰতি ছেকেণ্ডত দিয়া হয়। সঞ্চয় বাইটত জোখা হয়।
    Explanation: Bandwidth counts how many bits can flow each second, so it is quoted in megabits per second. Storage is measured in bytes.
    ৱেবচাইটে আপোনাৰ কম্পিউটাৰত ৰখা সৰু লিখা ফাইলটোক কি বোলা হয়
    Q19. A small text file stored by a website on your computer is called a
    (A) cookie কুকি
    (B) cache কেশ্ব
    (C) plugin প্লাগইন
    (D) script স্ক্ৰিপ্ট
    A) কুকি
    Answer: A) cookie
    কুকিয়ে লগইন বা কাৰ্টৰ দৰে অৱস্থা পৰৱৰ্তী ভ্ৰমণলৈ মনত ৰাখে। কেশ্বে দ্ৰুততাৰ বাবে পৃষ্ঠাৰ নকল ৰাখে।
    Explanation: A cookie remembers state such as a login or a cart between visits. A cache stores copies of pages for speed.
    তলৰ কোনটো ৱেব ব্ৰাউজাৰৰ উদাহৰণ
    Q20. Which of the following is an example of a web browser?
    (A) Mozilla Firefox ম'জিলা ফায়াৰফক্স
    (B) Windows 10 উইণ্ড'জ ১০
    (C) MS Excel MS এক্সেল
    (D) Linux লিনাক্স
    A) ম'জিলা ফায়াৰফক্স
    Answer: A) Mozilla Firefox
    ফায়াৰফক্সে ৱেব পৃষ্ঠা আনি দেখুৱায়। উইণ্ড'জ আৰু লিনাক্স অপাৰেটিং চিষ্টেম আৰু এক্সেল স্প্ৰেডশ্বীট।
    Explanation: Firefox fetches and renders web pages. Windows and Linux are operating systems and Excel is a spreadsheet.
    নেটৱৰ্কত স্বয়ংক্ৰিয়ভাৱে IP ঠিকনা দিয়া প্ৰট'কল
    Q21. The protocol used to assign IP addresses automatically on a network is
    (A) DHCP
    (B) DNS
    (C) FTP
    (D) SNMP
    Answer: A) DHCP
    DHCP এ সজুলি যোগ দিয়েই ঠিকনা দিয়ে। DNS এ নাম সমাধান কৰে, ঠিকনা নহয়।
    Explanation: Dynamic host configuration protocol hands out addresses as devices join. DNS resolves names, not addresses.
    এটা কম্পিউটাৰে আনৰ বাবে কেন্দ্ৰীয় ছাৰ্ভাৰ হোৱা নেটৱৰ্কক কি বোলা হয়
    Q22. A network in which one computer acts as a central server for others is called
    (A) client-server network ক্লায়েণ্ট-ছাৰ্ভাৰ নেটৱৰ্ক
    (B) peer-to-peer network পিয়াৰ-টু-পিয়াৰ নেটৱৰ্ক
    (C) standalone system অকলশৰীয়া চিষ্টেম
    (D) intranet only কেৱল ইণ্ট্ৰানেট
    A) ক্লায়েণ্ট-ছাৰ্ভাৰ নেটৱৰ্ক
    Answer: A) client-server network
    ক্লায়েণ্ট-ছাৰ্ভাৰ আৰ্হিত ছাৰ্ভাৰে ভাগ কৰা ফাইল আৰু সেৱা ৰাখে। পিয়াৰ-টু-পিয়াৰত সুকীয়া ছাৰ্ভাৰ নাই।
    Explanation: In a client-server model the server holds shared files and services. Peer-to-peer has no dedicated server.
    ফায়াৰৱালৰ মূল কাম হ'ল
    Q23. The main function of a firewall is to
    (A) block unauthorised network traffic অননুমোদিত নেটৱৰ্ক তথ্য অহা-যোৱা ৰোধ কৰা
    (B) speed up the internet ইণ্টাৰনেট দ্ৰুত কৰা
    (C) store web pages ৱেব পৃষ্ঠা ৰখা
    (D) assign IP addresses IP ঠিকনা দিয়া
    A) অননুমোদিত নেটৱৰ্ক তথ্য অহা-যোৱা ৰোধ কৰা
    Answer: A) block unauthorised network traffic
    ফায়াৰৱালে নিয়মৰ সৈতে তথ্য পৰীক্ষা কৰি অননুমোদিত বাদ দিয়ে। গতি বঢ়োৱা তাৰ উদ্দেশ্য নহয়।
    Explanation: A firewall inspects traffic against rules and drops what is not allowed. Speeding up traffic is not its purpose.
    তলৰ কোনটোৱে ইণ্টাৰনেট ভালদৰে বৰ্ণনা কৰে
    Q24. Which of the following best describes the internet?
    (A) a global network of interconnected networks জড়িত নেটৱৰ্কৰ বিশ্বব্যাপী নেটৱৰ্ক
    (B) a single large computer এটা ডাঙৰ কম্পিউটাৰ
    (C) a software program এটা ছফ্টৱেৰ প্ৰগ্ৰাম
    (D) a type of cable এবিধ কেবল
    A) জড়িত নেটৱৰ্কৰ বিশ্বব্যাপী নেটৱৰ্ক
    Answer: A) a global network of interconnected networks
    ইণ্টাৰনেট সাধাৰণ প্ৰট'কলৰে জড়িত নেটৱৰ্কৰ নেটৱৰ্ক। ৱেব তাৰ ওপৰত চলা এটা সেৱা।
    Explanation: The internet is a network of networks joined by common protocols. The web is one service running on it.
    দূৰৰ ছাৰ্ভাৰৰপৰা আপোনাৰ কম্পিউটাৰলৈ ফাইল অনাক কি বোলা হয়
    Q25. The transfer of a file from a remote server to your computer is called
    (A) downloading ডাউনলোডিং
    (B) uploading আপলোডিং
    (C) browsing ব্ৰাউজিং
    (D) streaming ষ্ট্ৰিমিং
    A) ডাউনলোডিং
    Answer: A) downloading
    ডাউনলোডিঙে ফাইল আপোনাৰ ফালে আনে, আপলোডিঙে পঠিয়ায়। ষ্ট্ৰিমিঙে অহা অহা বজায়।
    Explanation: Downloading brings a file towards you, uploading sends it away. Streaming plays while it arrives.
    তলৰ কোনটো ডমেইন নামৰ শুদ্ধ উদাহৰণ
    Q26. Which of the following is a valid example of a domain name?
    (A) axomexam.in
    (B) 192.168.0.1
    (C) ftp://files
    (D) 00:1A:2B:3C:4D:5E
    Answer: A) axomexam.in
    ডমেইন নাম পঢ়িব পৰা লিখা যি in বা com ৰ দৰে শীৰ্ষ স্তৰত শেষ হয়। বাকীবোৰ IP ঠিকনা, URL আৰু MAC ঠিকনা।
    Explanation: A domain name is readable text ending in a top level domain such as in or com. The others are an IP address, a URL and a MAC address.
    সংস্থাৰ ভিতৰত ব্যক্তিগত কিন্তু ইণ্টাৰনেট প্ৰযুক্তি ব্যৱহাৰ কৰা নেটৱৰ্কক কি বোলা হয়
    Q27. A network that is private to an organisation but uses internet technology is called an
    (A) intranet ইণ্ট্ৰানেট
    (B) extranet only কেৱল এক্সট্ৰানেট
    (C) internet ইণ্টাৰনেট
    (D) WAN
    A) ইণ্ট্ৰানেট
    Answer: A) intranet
    ইণ্ট্ৰানেট ভিতৰুৱা আৰু বাহিৰৰ বাবে বন্ধ। এক্সট্ৰানেটে তাৰ অংশ বিশ্বাসী অংশীদাৰলৈ মেলি দিয়ে।
    Explanation: An intranet is internal and closed to outsiders. An extranet extends part of it to trusted partners.
    নেটৱৰ্কৰ সৰ্বোচ্চ তথ্য হাৰ সাধাৰণতে কিৰে প্ৰকাশ কৰা হয়
    Q28. The maximum data rate of a network is usually expressed in
    (A) megabits per second প্ৰতি ছেকেণ্ডত মেগাবিট
    (B) megabytes per hour প্ৰতি ঘণ্টাত মেগাবাইট
    (C) megahertz মেগাহাৰ্টজ
    (D) megapixels মেগাপিক্সেল
    A) প্ৰতি ছেকেণ্ডত মেগাবিট
    Answer: A) megabits per second
    তথ্য হাৰে বিট গণে, সেয়ে গতি Mbps ত দিয়া হয়। বিট আৰু বাইট মিলাই দিলে সংখ্যা আঠ গুণ ডাঙৰ দেখা যায়।
    Explanation: Data rates count bits, so speeds are quoted in Mbps. Confusing bits with bytes makes a figure look eight times larger.
    মানুহে পঢ়িব পৰা ৱেব ঠিকনা IP ঠিকনালৈ সলনি কৰা সেৱাটো
    Q29. Which service converts a human readable web address into an IP address?
    (A) DNS
    (B) DHCP
    (C) FTP
    (D) SMTP
    Answer: A) DNS
    DNS ইণ্টাৰনেটৰ তালিকা, নামক সংখ্যাৰ সৈতে মিলায়। DHCP এ ঠিকনা দিয়ে।
    Explanation: The domain name system is the internet's directory, matching names to numbers. DHCP assigns addresses instead.
    বাছ ট'প'লজিত সকলো সজুলিয়ে ভাগ কৰে
    Q30. In a bus topology, all devices share
    (A) a single common cable এটা সাধাৰণ কেবল
    (B) a central switch এটা কেন্দ্ৰীয় স্বিচ
    (C) separate links to every other device প্ৰতিটো সজুলিলৈ সুকীয়া সংযোগ
    (D) a wireless channel only কেৱল বেতাঁৰ বাহক
    A) এটা সাধাৰণ কেবল
    Answer: A) a single common cable
    এটা মূল কেবলে প্ৰতিটো ন'ডলৈ সেৱা দিয়ে, সেয়ে ভাঙিলে গোটেই খণ্ড বন্ধ। ষ্টাৰত কেন্দ্ৰীয় স্বিচ ব্যৱহৃত।
    Explanation: One backbone cable serves every node, so a break stops the whole segment. A star uses a central switch instead.
