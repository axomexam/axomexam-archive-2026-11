    Q1. A network that covers a single building or campus is called a

    (C) WAN

    (D) User Registered Location
    Answer: A) Uniform Resource Locator
    Uniform Resource Locator হ'ল সেই ঠিকনা যি ব্ৰাউজাৰক পৃষ্ঠা ক'ত আছে আৰু কেনেকৈ আনিব কয়।

    C) চাৰ্ভাৰ ঠিকনালৈ আঙুলিয়াই দিয়া A ৰেকৰ্ড
    Answer: C) A record pointing to the server address
    A ৰেকৰ্ডে নামটো চাৰ্ভাৰৰ ঠিকনালৈ মেপ কৰে, সেয়ে ঠিকনা সলনি হ'লে তাক সলনি কৰিব লাগে, কেশ কৰা নকলৰ ম্যাদ শেষ হোৱালৈ বাট চাই। MX ৰেকৰ্ডে মেইল চলায়, SPF এ পঠিওঁতাক অনুমোদন দিয়ে আৰু TXT ত বিবিধ পাঠ থাকে।
    Explanation: The A record maps the name to the server's address, so it must change when the address changes, allowing for cached copies to expire. MX records route mail, SPF authorises senders and TXT holds miscellaneous text.

    Q49. A user cannot print from a laptop on the office Wi-Fi although the same laptop prints at home. The most likely cause is
    (A) the keyboard layout is wrong কীব'ৰ্ডৰ বিন্যাস ভুল
    (B) the office network blocks printer discovery or the print port অফিচ নেটৱৰ্কে প্ৰিন্টাৰ আৱিষ্কাৰ বা প্ৰিন্ট প'ৰ্ট অৱৰোধ কৰে
    (C) the laptop battery is low লেপটপৰ বেটাৰী কম
    (D) the screen brightness is low স্ক্ৰীণৰ উজ্জ্বলতা কম
    B) অফিচ নেটৱৰ্কে প্ৰিন্টাৰ আৱিষ্কাৰ বা প্ৰিন্ট প'ৰ্ট অৱৰোধ কৰে
    Answer: B) the office network blocks printer discovery or the print port
    ঘৰত কাম কৰি অফিচত নকৰাটোৱে পাৰ্থক্য নেটৱৰ্কলৈ সীমাবদ্ধ কৰে, যিয়ে আৱিষ্কাৰ প্ৰ'ট'কল বা প্ৰিন্ট প'ৰ্ট অৱৰোধ কৰিছে। বেটাৰী, উজ্জ্বলতা আৰু কীব'ৰ্ডৰ বিন্যাসে দুয়ো ঠাইতে বিফল হ'লহেঁতেন।
    Explanation: Working at home but not in the office isolates the difference to the network, which is blocking the discovery protocol or the print port. Battery, brightness and keyboard layout would fail in both places.
    প্ৰশাসকে এটা ছুইচ বিফল হ'লে গোটেই মহলা বন্ধ হোৱাৰ সম্ভাৱনা কমাব লাগে। আৰ্হিৰ পৰিৱৰ্তন
    Q50. An administrator must reduce the chance of a single switch failure taking down a floor. The design change is to
    (A) provide a redundant switch with a loop free topology লুপমুক্ত ট'প'লজিসহ অতিৰিক্ত ছুইচ দিয়া
    (B) connect every device to the same switch প্ৰতিটো যন্ত্ৰ একেই ছুইচত লগোৱা
    (C) use longer cables দীঘল কেবল ব্যৱহাৰ কৰা
    (D) remove the firewall ফায়াৰৱাল আঁতৰোৱা
    A) লুপমুক্ত ট'প'লজিসহ অতিৰিক্ত ছুইচ দিয়া
    Answer: A) provide a redundant switch with a loop free topology
    দ্বিতীয় ছুইচে স্পেনিং ট্ৰি বা লিংক এগ্ৰিগেশ্যনৰ সৈতে এটা ইউনিট বিফল হ'লেও মহলা সংযুক্ত ৰাখে, যি প্ৰয়োজন। সকলো এটা ছুইচত ৰাখিলে বিপদ বাঢ়ে, আৰু কেবলৰ দীঘ বা ফায়াৰৱাল আঁতৰোৱাই তাক সমাধান নকৰে।
    Explanation: A second switch with spanning tree or link aggregation keeps the floor connected when one unit fails, which is the requirement. Putting everything on one switch increases the risk, and cable length or firewall removal do not address it.
