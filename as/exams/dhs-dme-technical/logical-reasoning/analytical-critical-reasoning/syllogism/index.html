    Q1. Statements: All pens are books. Some books are tables. Conclusion: Some pens are tables. The conclusion is?
    (A) Definitely true নিশ্চিতভাৱে সত্য
    (B) Definitely false নিশ্চিতভাৱে অসত্য
    (C) Does not follow অনুসৰণ নকৰে
    (D) True only if all books are pens যদি সকলো কিতাপ কলম হয়
    C) অনুসৰণ নকৰে
    Answer: C) Does not follow
    সকলো কলম কিতাপ আৰু কিছুমান কিতাপ টেবুল, কিন্তু যিবোৰ কিতাপ টেবুল সেইবোৰ কলম নহ'বও পাৰে। মধ্যপদ 'কিতাপ' বিতৰণ নোহোৱা বাবে 'কিছুমান কলম টেবুল' সিদ্ধান্ত অনুসৰণ নকৰে।
    Explanation: All pens are books and some books are tables, but the books that are tables need not be pens. Since the middle term 'books' is not distributed, the conclusion 'some pens are tables' does not follow.

    Q2. If no cat is dog and some dogs are pets, then 'some cats are pets' ?
    (A) Must be true অৱশ্যে সত্য
    (B) Must be false অৱশ্যে অসত্য
    (C) Cannot be concluded সিদ্ধান্ত কৰিব নোৱাৰি
    (D) True always সদায় সত্য
    C) সিদ্ধান্ত কৰিব নোৱাৰি
    Answer: C) Cannot be concluded
    কোনো মেকুৰী কুকুৰ নহয়, গতিকে মেকুৰী আৰু কুকুৰ সম্পূৰ্ণ সুকীয়া; কিছুমান কুকুৰ পোহনীয়া বুলি জানিলেও মেকুৰী আৰু পোহনীয়াৰ মাজত নিশ্চিত সম্পৰ্ক নাই। সেয়ে সিদ্ধান্ত কৰিব নোৱাৰি।
    Explanation: No cat is a dog, so cats and dogs are completely separate; that some dogs are pets gives no definite link between cats and pets. Hence it cannot be concluded.

    Q3. All mangoes are fruits. All fruits grow on trees. Therefore all mangoes?
    (A) Are vegetables পাচলি
    (B) Grow on ground মাটিত হয়
    (C) Grow on trees গছত হয়
    (D) Are not fruits ফল নহয়
    C) গছত হয়
    Answer: C) Grow on trees
    সকলো আম ফল আৰু সকলো ফল গছত হয়; সেয়ে যুক্তি অনুসৰি সকলো আম গছত হয়।
    Explanation: All mangoes are fruits and all fruits grow on trees, so by syllogism all mangoes grow on trees.

    Q4. All pens are books. Some books are red. Which conclusion follows?
    (A) Only I: Some pens are red কেৱল I: কিছুমান কলম ৰঙা
    (B) Only II: Some red things are books কেৱল II: কিছুমান ৰঙা বস্তু কিতাপ
    (C) Both I and II I আৰু II দুয়োটা
    (D) Neither I nor II I আৰু II কোনোটো নহয়
    B) কেৱল II: কিছুমান ৰঙা বস্তু কিতাপ
    Answer: B) Only II: Some red things are books
    'কিছুমান কিতাপ ৰঙা' মানে কিছুমান ৰঙা বস্তু কিতাপ; সেয়ে কেৱল II সত্য। কলম ৰঙা হোৱাটো নিশ্চিত নহয়।
    Explanation: Some books are red means some red things are books, so only II follows. Some pens being red is not guaranteed.
