    গৃহপৃষ্ঠা/কম্পিউটাৰ সজাগতা/Networking & Internet

    নেটৱৰ্কিং আৰু ইন্টাৰনেট — প্ৰশ্নোত্তৰ

    ৯২ টা প্ৰশ্ন আৰু উত্তৰ

    ১. পৰস্পৰ সংযুক্ত কম্পিউটাৰ সমষ্টিক ___ বোলে।
    (A) Network
    (B) Group
    (C) System
    (D) Cluster
    উত্তৰ: network য়ে তথ্য আৰু সম্পদ ভাগ-বতৰা কৰিবলৈ কম্পিউটাৰ সংযোগ কৰে।
    ব্যাখ্যা: Network হৈছে দুটা বা অধিক কম্পিউটাৰ, যিবোৰ সংযোগ কৰি তথ্য, ফাইল, printer আৰু অন্য সম্পদ ভাগ-বতৰা কৰিব পৰা যায়।
    ২. অট্টালিকাৰ দৰে সৰু অঞ্চল জুৰি থকা network ক ___ বোলে।
    (A) LAN
    (B) WAN
    (C) MAN
    (D) PAN
    উত্তৰ: LAN (Local Area Network) এ অফিচ বা অট্টালিকাৰ দৰে সৰু অঞ্চল জুৰে।
    ব্যাখ্যা: LAN (Local Area Network) এটা সৰু এলেকা, যেনে এটা কোঠা, ভৱন বা কাৰ্যালয় সামৰি লয় আৰু সাধাৰণতে ব্যক্তিগতভাৱে পৰিচালিত।
    ৩. দেশৰ দৰে বহুত ডাঙৰ অঞ্চল জুৰি network ক ___ বোলে।
    (A) WAN
    (B) LAN
    (C) MAN
    (D) CAN
    উত্তৰ: WAN (Wide Area Network) এ ডাঙৰ ভৌগোলিক অঞ্চল জুৰে; ইন্টারনেটেই সবাতোকৈ ডাঙৰ WAN।
    ব্যাখ্যা: WAN (Wide Area Network) ৰাজ্য, দেশ বা গোটেই পৃথিৱীৰ দৰে ডাঙৰ ভৌগোলিক এলেকা সামৰি লয়। ইন্টাৰনেট হৈছে আটাইতকৈ ডাঙৰ WAN।
    ৪. চহৰ এখন জুৰি network ক ___ বোলে।
    (A) MAN
    (B) LAN
    (C) WAN
    (D) PAN
    উত্তৰ: MAN (Metropolitan Area Network) এ চহৰ বা নগৰীয়া অঞ্চল জুৰে।
    ব্যাখ্যা: MAN (Metropolitan Area Network) এটা চহৰ বা মহানগৰীয় এলেকা সামৰি লয়, LAN তকৈ ডাঙৰ কিন্তু WAN তকৈ সৰু।
    ৫. LAN ৰ সম্পূৰ্ণ ৰূপ কি?
    (A) Local Area Network
    (B) Large Area Network
    (C) Long Area Network
    (D) Linked Area Network
    উত্তৰ: LAN ৰ অৰ্থ Local Area Network।
    ব্যাখ্যা: LAN ৰ অৰ্থ Local Area Network, এটা ব্যক্তিগত মালিকানাধীন নেটৱৰ্ক, সৰু এলেকাত সীমিত আৰু উচ্চ গতিৰ।
    ৬. WAN ৰ সম্পূৰ্ণ ৰূপ কি?
    (A) Wide Area Network
    (B) Web Area Network
    (C) World Area Network
    (D) Wireless Area Network
    উত্তৰ: WAN ৰ অৰ্থ Wide Area Network।
    ব্যাখ্যা: WAN ৰ অৰ্থ Wide Area Network, ৰাজহুৱা বা ভাড়া কৰা যোগাযোগ লাইন ব্যৱহাৰ কৰি বিস্তৃত ভৌগোলিক এলেকাত বিয়পা নেটৱৰ্ক।
    ৭. বিশ্বব্যাপী কম্পিউটাৰ network ক ___ বোলে।
    (A) Internet
    (B) Intranet
    (C) Extranet
    (D) Modem
    উত্তৰ: ইন্টারনেট হৈছে বিশ্বব্যাপী সংযুক্ত কম্পিউটাৰ network।
    ব্যাখ্যা: ইন্টাৰনেট হৈছে নেটৱৰ্কৰ গোলকীয় নেটৱৰ্ক, যি TCP/IP protocol suite ব্যৱহাৰ কৰি বিশ্বজুৰি কোটি কম্পিউটাৰ সংযোগ কৰে।
    ৮. সংস্থা এটাৰ ভিতৰত ব্যক্তিগত network ক ___ বোলে।
    (A) Intranet
    (B) Internet
    (C) Extranet
    (D) Hypernet
    উত্তৰ: intranet হৈছে সংস্থা এটাৰ ভিতৰত internet প্রযুক্তিৰে নির্মিত ব্যক্তিগত network।
    ব্যাখ্যা: Intranet হৈছে ইন্টাৰনেট প্ৰযুক্তি ব্যৱহাৰ কৰা ব্যক্তিগত নেটৱৰ্ক, যি কেৱল এটা প্ৰতিষ্ঠানৰ কৰ্মী বা সদস্যই ব্যৱহাৰ কৰিব পাৰে।
    ৯. সংস্থাৰ intranet ৰ বাহিৰৰ পৰা নিয়ন্ত্ৰিত প্রবেশ দিয়া network ক ___ বোলে।
    (A) Extranet
    (B) Intranet
    (C) Internet
    (D) Localnet
    উত্তৰ: extranet হৈছে বাহিৰৰ অংশীদাৰলৈ intranet ৰ নিয়ন্ত্ৰিত বিস্তাৰ।
    ব্যাখ্যা: Extranet হৈছে এনে intranet, যি নিয়ন্ত্ৰিত প্ৰৱেশৰে যোগানকৰ্তা, অংশীদাৰ বা গ্ৰাহকৰ দৰে বিশ্বস্ত বাহিৰা ব্যক্তিলৈ আংশিকভাৱে মুকলি।
    ১০. টেলিফোন বা cable line ৰে কম্পিউটাৰক ইন্টারনেটত সংযোগ কৰা যন্ত্ৰ কোনটো?
    (A) Modem
    (B) Printer
    (C) Scanner
    (D) Joystick
    উত্তৰ: modem য়ে সংকেত মডুলেট/ডিমডুলেট কৰি ইন্টারনেট সংযোগ দিয়ে।
    ব্যাখ্যা: Modem (modulator-demodulator) য়ে কম্পিউটাৰৰ digital signal ক টেলিফোন বা cable লাইনৰ মাজেৰে যাব পৰা analog signal লৈ আৰু ঘূৰাই ৰূপান্তৰ কৰে।
    ১১. LAN ত একাধিক কম্পিউটাৰ সংযোগ কৰা যন্ত্ৰক ___ বোলে।
    (A) Switch / Hub
    (B) Modem
    (C) Router over modem
    (D) Repeater
    উত্তৰ: switch (বা hub) য়ে LAN ত কম্পিউটাৰ সংযোগ কৰে।
    ব্যাখ্যা: Hub বা switch য়ে এটা LAN ৰ ভিতৰত বহু কম্পিউটাৰ সংযোগ কৰে। Switch বুদ্ধিমান, কাৰণ ই কেৱল নিৰ্দিষ্ট port লৈ data পঠিয়ায়, আনহাতে hub য়ে সকলো port লৈ প্ৰেৰণ কৰে।
    ১২. দুই বা ততোধিক ভিন্ন network সংযোগ কৰি তথ্যৰ বাবে উত্তম পথ বাছি লোৱা যন্ত্ৰ কোনটো?
    (A) Router
    (B) Switch
    (C) Hub
    (D) Modem
    উত্তৰ: router য়ে network সংযোগ আৰু মাজত data packet পৰিবহণ কৰে।
    ব্যাখ্যা: Router য়ে দুটা বা অধিক ভিন্ন নেটৱৰ্ক সংযোগ কৰে আৰু routing table আৰু IP address ব্যৱহাৰ কৰি data packet সৰ্বোত্তম পথেদি পঠিয়ায়।
    ১৩. network ত কম্পিউটাৰৰ অনন্য ঠিকনাক ___ বোলে।
    (A) IP address
    (B) CPU number
    (C) Port name
    (D) File ID
    উত্তৰ: IP address য়ে network ত যন্ত্ৰ এটা চিনাক্ত কৰে।
    ব্যাখ্যা: IP address হৈছে নেটৱৰ্কৰ প্ৰতিটো ডিভাইচলৈ দিয়া অদ্বিতীয় সংখ্যাযুক্ত ঠিকনা, যাতে তথ্য সঠিক গন্তব্যস্থানলৈ পঠিয়াব পাৰি।
    ১৪. IP ৰ সম্পূৰ্ণ ৰূপ কি?
    (A) Internet Protocol
    (B) Internet Process
    (C) Internal Protocol
    (D) Input Protocol
    উত্তৰ: IP ৰ অৰ্থ Internet Protocol।
    ব্যাখ্যা: IP ৰ অৰ্থ Internet Protocol, এনে নিয়মৰ সমষ্টি যি নেটৱৰ্কত data packet কেনেকৈ ঠিকনা পাব আৰু পথ ল'ব নিয়ন্ত্ৰণ কৰে।
    ১৫. IPv4 address ত কিমান bit থাকে?
    (A) 32
    (B) 64
    (C) 16
    (D) 128
    উত্তৰ: IPv4 address ত 32 bit থাকে (যেনে 192.168.1.1)।
    ব্যাখ্যা: IPv4 address ৩২ bit দীঘল আৰু বিন্দুৰে পৃথক কৰা চাৰিটা দশমিক সংখ্যা হিচাপে লিখা হয়, যেনে 192.168.1.1।
    ১৬. IPv6 address ত কিমান bit থাকে?
    (A) 128
    (B) 32
    (C) 64
    (D) 256
    উত্তৰ: IPv6 address ত 128 bit থাকে।
    ব্যাখ্যা: IPv6 address ১২৮ bit দীঘল, colon ৰে পৃথক কৰা hexadecimal গোটত লিখা হয়। IPv4 address শেষ হৈ অহাৰ বাবে ইয়াক সৃষ্টি কৰা হৈছিল।
    ১৭. URL ৰ সম্পূৰ্ণ ৰূপ কি?
    (A) Uniform Resource Locator
    (B) Universal Resource Link
    (C) Uniform Research Locator
    (D) United Resource Locator
    উত্তৰ: URL ৰ অৰ্থ Uniform Resource Locator, web page ৰ ঠিকনা।
    ব্যাখ্যা: URL ৰ অৰ্থ Uniform Resource Locator। ইন্টাৰনেটত এটা নিৰ্দিষ্ট সম্পদ, যেনে web page, বিচাৰি উলিয়াবলৈ ব্যৱহাৰ কৰা সম্পূৰ্ণ ঠিকনা।
    ১৮. HTTP ৰ সম্পূৰ্ণ ৰূপ কি?
    (A) Hyper Text Transfer Protocol
    (B) High Text Transfer Protocol
    (C) Hyper Test Transmission Protocol
    (D) Hyper Text Transmission Process
    উত্তৰ: HTTP ৰ অৰ্থ Hyper Text Transfer Protocol।
    ব্যাখ্যা: HTTP ৰ অৰ্থ Hyper Text Transfer Protocol। web browser আৰু web server ৰ মাজত web page আৰু অন্য content কেনেকৈ বিনিময় হ'ব সেয়া ই নিৰ্ধাৰণ কৰে।
    ১৯. HTTPS ৰ 's' ৰ অৰ্থ কি?
    (A) Secure
    (B) System
    (C) Simple
    (D) Server
    উত্তৰ: HTTPS = HTTP Secure; তথ্য এনক্রিপ্টেড থাকে।
    ব্যাখ্যা: HTTPS ত 's' ৰ অৰ্থ Secure। HTTPS য়ে ৱেবছাইটৰ সৈতে বিনিময় হোৱা তথ্য encrypt কৰে, ফলত পথত পঢ়া বা সলনি কৰাৰ পৰা সুৰক্ষা মেলে।
    ২০. ইমেইল পঠাবলৈ কোন protocol ব্যৱহাৰ হয়?
    (A) SMTP
    (B) FTP
    (C) HTTP
    (D) POP3
    উত্তৰ: SMTP (Simple Mail Transfer Protocol) ইমেইল পঠাবলৈ ব্যৱহাৰ হয়।
    ব্যাখ্যা: SMTP (Simple Mail Transfer Protocol) হৈছে mail client আৰু server এ outgoing ইমেইল পঠিয়াবলৈ ব্যৱহাৰ কৰা মানক protocol।
    ২১. ইমেইল ল'বলৈ কোন protocol ব্যৱহাৰ হয়?
    (A) POP3 / IMAP
    (B) SMTP
    (C) FTP
    (D) Telnet
    উত্তৰ: POP3 আৰু IMAP server ৰ পৰা ইমেইল ল'বলৈ ব্যৱহাৰ হয়।
    ব্যাখ্যা: POP3 আৰু IMAP হৈছে mail server ৰ পৰা ইমেইল লাভ বা download কৰিবলৈ ব্যৱহাৰ কৰা protocol। IMAP য়ে server ত mail ৰাখে, আনহাতে POP3 য়ে সাধাৰণতে download কৰি আঁতৰায়।
    ২২. ইন্টারনেটত ফাইল স্থানান্তৰৰ বাবে কোন protocol?
    (A) FTP
    (B) HTTP
    (C) SMTP
    (D) DNS
    উত্তৰ: FTP (File Transfer Protocol) য়ে কম্পিউটাৰৰ মাজত ফাইল স্থানান্তৰ কৰে।
    ব্যাখ্যা: FTP (File Transfer Protocol) য়ে নেটৱৰ্কত client কম্পিউটাৰ আৰু server ৰ মাজত ফাইল upload আৰু download কৰিবলৈ ব্যৱহাৰ হয়।
    ২৩. কোন protocol য়ে domain name ক IP address লৈ ৰূপান্তৰ কৰে?
    (A) DNS
    (B) FTP
    (C) SMTP
    (D) POP
    উত্তৰ: DNS (Domain Name System) য়ে domain name ক IP address লৈ সমাধান কৰে।
    ব্যাখ্যা: DNS (Domain Name System) য়ে www.example.com ৰ দৰে মানুহে বুজা domain নামক কম্পিউটাৰে বুজা সংখ্যাযুক্ত IP address লৈ ৰূপান্তৰ কৰে।
    ২৪. ইন্টারনেটত web page চাবলৈ কোন ছফ্টৱেৰ ব্যৱহাৰ হয়?
    (A) Web browser
    (B) Word processor
    (C) Spreadsheet
    (D) Antivirus
    উত্তৰ: web browser (Chrome, Firefox আদি) ৱেবছাইট চাবলৈ ব্যৱহাৰ হয়।
    ব্যাখ্যা: Chrome, Firefox বা Edge ৰ দৰে web browser এটা application software, যি server ৰ পৰা web page বিচাৰি আনি ব্যৱহাৰকাৰীক দেখুৱায়।
    ২৫. সম্পর্কিত web page ৰ সংগ্ৰহক ___ বোলে।
    (A) Website
    (B) Webpage
    (C) Web server
    (D) Web link
    উত্তৰ: website হৈছে এটা domain ৰ তলত থকা সম্পর্কিত web page ৰ সংগ্ৰহ।
    ব্যাখ্যা: Website হৈছে সম্পর্কিত web page ৰ সমষ্টি, যিবোৰে এটা সাধাৰণ domain নাম ভাগ কৰে আৰু সাধাৰণতে এজন মালিকৰ দ্বাৰা পৰিচালিত।
    ২৬. website ৰ প্ৰথম পৃষ্ঠাক ___ বোলে।
    (A) Home page
    (B) Index page only
    (C) Header page
    (D) Main view
    উত্তৰ: home page হৈছে website ৰ প্ৰথম বা মূল পৃষ্ঠা।
    ব্যাখ্যা: Home page হৈছে ৱেবছাইটৰ প্ৰথম বা মূল পৃষ্ঠা, যি ছাইটৰ ঠিকনা খুলিলে দেখা যায়।
    ২৭. World Wide Web ৰ এটা দলিলক ___ বোলে।
    (A) Web page
    (B) Website
    (C) Web service
    (D) Web portal

    নেটৱৰ্কিং প্ৰশ্নই তিনিটা কথা পৰীক্ষা কৰে: কম্পিউটাৰবোৰ কেনেকৈ সংযোগ কৰা হয়, প্ৰতিটো সংযোগী যন্ত্ৰই কি কৰে, আৰু কোনটো protocol বা service এ কোনটো কাম কৰে। শব্দবোৰ চুটি, প্ৰশ্নপত্ৰত পুনৰ আহে, আৰু প্ৰতিটো শব্দক তাৰ এশাৰী কামৰ লগত জুৰি ৰখা প্ৰাৰ্থীয়ে এই নম্বৰবোৰ বিৰলেহে হেৰুৱায়। এই টোকাত প্ৰথমে পৰিভাষা, তাৰ পিছত network ৰ প্ৰকাৰ আৰু বিন্যাস, তাৰ পিছত যন্ত্ৰ আৰু protocol, আৰু শেষত এৰাই চলিবলগীয়া ভুলবোৰ দিয়া হৈছে।

    মূল পৰিভাষা

    • Computer network: তথ্য, সম্পদ আৰু সেৱা ভগাই ল'বলৈ দুটা বা ততোধিক কম্পিউটাৰৰ সংযোগ।
    • Node: network ত সংযুক্ত যিকোনো যন্ত্ৰ, যেনে কম্পিউটাৰ বা printer।
    • LAN: এটা কোঠা, ভৱন বা campus ৰ দৰে সৰু এলেকা সামৰি লোৱা local area network।
    • MAN: এখন চহৰ সামৰি লোৱা metropolitan area network।
    • WAN: ডাঙৰ অঞ্চল বা গোটেই পৃথিৱী সামৰি লোৱা wide area network।
    • PAN: এজন ব্যক্তিৰ চাৰিওফালে কেইমিটাৰমান সামৰি লোৱা personal area network।
    • Topology: node বোৰ সংযোগ কৰা বিন্যাস, যেনে bus, star, ring, mesh বা tree।
    • Protocol: network ত তথ্য কেনেকৈ বিনিময় হ'ব নিয়ন্ত্ৰণ কৰা নিয়মৰ সংহতি।
    • IP address: network ত যন্ত্ৰ চিনাক্ত কৰা অদ্বিতীয় ঠিকনা, যেনে 192.168.0.1।
    • MAC address: network card ত সোমাই থকা স্থায়ী ভৌতিক ঠিকনা।
    • DNS: domain name ক IP address লৈ সলোৱা domain name system।
    • Bandwidth: এটা সংযোগে নিৰ্দিষ্ট সময়ত কঢ়িয়াব পৰা তথ্যৰ পৰিমাণ।
    • Router: বেলেগ network জোৰা লগাই তথ্য আগবঢ়োৱা যন্ত্ৰ।
    • Web browser: World Wide Web ৰ পৃষ্ঠা চাবলৈ ব্যৱহৃত software।

    Network ৰ প্ৰকাৰবোৰৰ পাৰ্থক্য

    চাৰিটা network প্ৰকাৰৰ মাজত আচল পাৰ্থক্য কেৱল আকাৰ, আৰু প্ৰতিটোৰ নাম ই সামৰি লোৱা এলেকাৰ পৰা হয়। PAN এ এজন ব্যক্তিৰ চাৰিওফালে কেইমিটাৰমান পায়, সাধাৰণতে Bluetooth ৰে। LAN এ এটা কোঠা, ভৱন বা campus সামৰে। MAN এ এখন চহৰত বিয়পে। WAN এ ৰাজ্য, দেশ বা গোটেই পৃথিৱী সামৰে, আৰু internet হৈছে মাথোঁ আটাইতকৈ ডাঙৰ WAN। বেছিভাগ প্ৰশ্নই হয় full form সোধে, নহয় এটা এলেকা বৰ্ণনা কৰি কোন প্ৰকাৰ সোধে; গতিকে চাৰিটা এলেকা আকাৰৰ ক্ৰমত শিকিলে দুয়োটাৰে উত্তৰ পোৱা যায়।

    Topology আৰু সিহঁতৰ লাভ-লোকসান

    সংযোগৰ বিন্যাসক topology বোলা হয়। Bus topology ত প্ৰতিটো node এ এটা মূল cable ভাগ কৰে, যি সস্তা কিন্তু এটা ঠাই ভাঙিলে গোটেই network বন্ধ হ'ব পাৰে। Star topology ত প্ৰতিটো node এ কেন্দ্ৰীয় hub বা switch লৈ সংযুক্ত; ই পৰিচালনা কৰা সহজ আৰু আজি আটাইতকৈ সাধাৰণ বিন্যাস। Ring topology এ node বোৰক এটা বৃত্তত জোৰা লগায়। Mesh topology এ প্ৰতিটো node ক আন প্ৰতিটোৰ লগত সংযোগ কৰি আটাইতকৈ বেছি নিৰ্ভৰযোগ্যতা দিয়ে, কিন্তু cable খৰচো আটাইতকৈ বেছি। Tree topology এ কেইবাটাও star network ক শ্ৰেণীবদ্ধভাৱে জোৰা লগায়।

    যন্ত্ৰ, প্ৰতিটোৰ এটা কাম

    Modem এ Telephone, cable বা fibre লাইনৰ পৰা অহা সংকেতক কম্পিউটাৰে ব্যৱহাৰ কৰিব পৰা ৰূপলৈ সলায়। Hub এ অহা তথ্য আটাই port লৈ পুনৰাবৃত্তি কৰে, গতিকে প্ৰতিটো যন্ত্ৰই সেয়া পায়। Switch এ কোন যন্ত্ৰ কোন port ত আছে শিকি কেৱল সঠিক port লৈহে তথ্য পঠিয়ায়, সেয়ে ই hub তকৈ দ্ৰুত। Router এ বেলেগ network সংযোগ কৰি সিহঁতৰ মাজত তথ্যৰ বাবে শ্ৰেষ্ঠ পথ বাছি লয়। Gateway এ বেলেগ protocol ব্যৱহাৰ কৰা দুটা network জোৰা লগায়, আৰু repeater লগতে bridge এ network বঢ়ায় বা ভাগ কৰে। প্ৰশ্নত যদি এটা কাম কোৱা হয়, তেন্তে কোন যন্ত্ৰই ঠিক সেই কামটো কৰে, আৰু তাতকৈ বেছি নকৰে, সেয়া ভাবক।

    Protocol আৰু Internet সেৱা

    Internet TCP/IP suite ত চলে: TCP এ তথ্যক packet লৈ ভাগ কৰি আন মূৰত পুনৰ একত্ৰিত কৰে, আনহাতে IP এ প্ৰতিটো packet ৰ ঠিকনা নিৰ্ণয় কৰি পথ দেখুৱায়। তাৰ ওপৰত থাকে application protocol: web ৰ HTTP আৰু HTTPS, file transfer ৰ FTP, আৰু mail পঠিয়াবলৈ SMTP লগতে ল'বলৈ POP3 বা IMAP। HTTPS হৈছে HTTP ৰ এনক্ৰিপ্ট কৰা ৰূপ, আৰু address bar ৰ padlock ইয়াক দেখুৱায়। DNS এ axomexam.in ৰ দৰে নামক সংখ্যাযুক্ত ঠিকনালৈ সলায়, আৰু DHCP এ network ত যোগ দিয়া যন্ত্ৰক স্বয়ংক্ৰিয়ভাৱে IP address দিয়ে। মনত ৰাখক, WWW হৈছে internet ত চলা এটা সেৱা; internet নিজেই হৈছে বিশ্বব্যাপী network ৰ network, আৰু ISP হৈছে ইয়াৰ সুবিধা দিয়া কোম্পানী। IPv4 ৰ ঠিকনা 32 bit দীঘল, আনহাতে IPv6 এ 128 bit ব্যৱহাৰ কৰে।

    সাধাৰণ ফান্দ

    • Internet আৰু World Wide Web একে ভবা; web হৈছে internet ৰ এটা সেৱা।
    • Hub আৰু switch মিলাই দিয়া; hub এ broadcast কৰে, switch এ এটা port লক্ষ্য কৰে।
    • FTP ক web protocol বোলা; ই file transfer কৰে।
    • SMTP, যি mail পঠিয়ায়, POP3 আৰু IMAP, যি mail লয়, মিলাই দিয়া।
    • IPv4 আৰু IPv6 ওলোটাই দিয়া; IPv4 32-bit, IPv6 128-bit।
    • HTTP আৰু HTTPS সলনি কৰা; HTTPS সুৰক্ষিত সংস্কৰণ।

    এই অংশ কেনেকৈ পুনৰালোচনা কৰিব

    দুখন তালিকা লিখক। প্ৰথমখনে প্ৰতিটো abbreviation ক তাৰ full form আৰু ই সমৰ্থন কৰা service ৰ লগত জুৰি দিয়ে; দ্বিতীয়খনে প্ৰতিটো যন্ত্ৰক তাৰ এশাৰী কামৰ লগত জুৰি দিয়ে। তাৰ পিছত পাঁচটা topology আঁকি প্ৰতিটোৰ কাষত এটা গুণ আৰু এটা দোষ লিখক, কাৰণ প্ৰশ্নই সঘনাই নাম নলৈ বিন্যাস বৰ্ণনা কৰে। সোঁফালৰ স্তম্ভ ঢাকি পঢ়ি আৰু তাৰ পিছত মুকলি কৰি পৰীক্ষা কৰি অভ্যাস কৰক। যি যোৰবোৰে আপোনাক আটাইতকৈ বেছি ধৰে — hub বনাম switch, internet বনাম WWW — সেইবোৰ পৃষ্ঠাৰ ওপৰত সুকীয়া শাৰীত ৰাখক, কাৰণ প্ৰশ্নপত্ৰই সেইবোৰলৈকে ঘূৰি আহে।

    সঘনাই সোধা প্ৰশ্ন

    LAN আৰু WAN ৰ full form কি?

    LAN হৈছে local area network, যি সৰু এলেকা সামৰে, আৰু WAN হৈছে wide area network, যি ডাঙৰ অঞ্চল সামৰে।

    কোন যন্ত্ৰই দুটা বেলেগ network জোৰা লগায়?

    Router এ দুটা সুকীয়া network সংযোগ কৰি এটাৰ পৰা আনটোলৈ তথ্য পাচ কৰে।

    E-mail পঠিয়াবলৈ কোন protocol ব্যৱহৃত হয়?

    SMTP, অৰ্থাৎ simple mail transfer protocol, ইমেইল পঠিয়ায়, আৰু POP3 লগতে IMAP ইমেইল লয়।

    DNS ৰ কাম কি?

    DNS, অৰ্থাৎ domain name system, এ মানুহে পঢ়িব পৰা domain name ক সংখ্যাযুক্ত IP address লৈ সলায়।

    Internet আৰু WWW ৰ পাৰ্থক্য কি?

    Internet হৈছে আন্তঃসংযুক্ত network ৰ বিশ্বব্যাপী জাল; World Wide Web হৈছে তাৰ ওপৰত চলা সংযুক্ত পৃষ্ঠাৰ এটা সেৱা।

    সম্পৰ্কিত কম্পিউটাৰ জ্ঞান বিষয়সমূহ

    এই বিষয়ৰ সৈতে একে শিতানৰ অন্য বিষয়সমূহ — প্ৰতিটোতে প্ৰশ্ন, শুদ্ধ উত্তৰ আৰু ব্যাখ্যা আছে।

    • DBMS, সংখ্যা পদ্ধতি আৰু চৰ্টকাট
    • MS Office ছুট
    • কম্পিউটাৰ মৌলিক ধাৰণা আৰু হাৰ্ডৱেৰ
    • চফ্টৱেৰ আৰু অপাৰেটিং ছিষ্টেম
    • চাইবাৰ নিৰাপত্তা
    • সকলো কম্পিউটাৰ জ্ঞান

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
