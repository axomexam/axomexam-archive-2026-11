    চাইবাৰ নিৰাপত্তা — প্ৰশ্নোত্তৰ

    ৭৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. কোন ছফ্টৱেৰে কম্পিউটাৰক ভাইৰাছৰ পৰা ৰক্ষা কৰে?
    (A) Antivirus
    (B) Word processor
    (C) Spreadsheet
    (D) Browser
    উত্তৰ: antivirus ছফ্টৱেৰে ভাইৰাছ আৰু malware চিনাক্ত আৰু আঁতৰায়।
    ব্যাখ্যা: Antivirus ছফ্টৱেৰে ফাইল আৰু memory স্কেন কৰি জনাজাত ভাইৰাছ signature আৰু সন্দেহজনক আচৰণ চিনাক্ত কৰি বিপদ আঁতৰায় বা quarantine কৰে। Word processor, spreadsheet বা browser-এ এইটো কৰিব নোৱাৰে।
    ২. নিজকে কপি কৰি আন কম্পিউটাৰলৈ বিয়পোৱা দুষ্ট program ক ___ বোলে।
    (A) Virus
    (B) Spam
    (C) Cookie
    (D) Patch
    উত্তৰ: কম্পিউটাৰ ভাইৰাছ নিজকে কপি কৰি আন ছিষ্টেমলৈ বিয়পে।
    ব্যাখ্যা: কম্পিউটাৰ ভাইৰাছ হৈছে এনে ক্ষতিকাৰক program যিয়ে host ফাইলত লগ লাগি নিজকে কপি কৰে আৰু আন কম্পিউটাৰলৈ বিয়পে, সাধাৰণতে সংক্ৰমিত ফাইল খোলা বা শেয়াৰ কৰিলে।
    ৩. সকলো ধৰণৰ দুষ্ট ছফ্টৱেৰক বুজোৱা পৰিভাষা ___।
    (A) Malware
    (B) Freeware
    (C) Shareware
    (D) Firmware
    উত্তৰ: malware (দুষ্ট ছফ্টৱেৰ) ত ভাইৰাছ, worm, trojan আৰু ransomware আদি অন্তর্ভুক্ত।
    ব্যাখ্যা: Malware হৈছে সকলো ক্ষতিকাৰক ছফ্টৱেৰৰ সাধাৰণ নাম, যাৰ ভিতৰত ভাইৰাছ, worm, trojan, ransomware, spyware আৰু adware পৰে। Freeware, shareware আৰু firmware বৈধ ছফ্টৱেৰৰ প্ৰকাৰ।
    ৪. ফাইল লক কৰি মূল্য দাবি কৰা ছফ্টৱেৰক ___ বোলে।
    (A) Ransomware
    (B) Adware
    (C) Spyware
    (D) Shareware
    উত্তৰ: ransomware য়ে ফাইল এনক্রিপ্ট/লক কৰি মুকলি কৰিবলৈ ধন দাবি কৰে।
    ব্যাখ্যা: Ransomware য়ে ভুক্তভোগীৰ ফাইল encrypt বা lock কৰি পুনৰ প্ৰৱেশৰ বাবে মুক্তিপণ (সাধাৰণতে cryptocurrency) দাবী কৰে।
    ৫. কোন malware য়ে কম্পিউটাৰত অবাঞ্ছিত বিজ্ঞাপন দেখুৱায়?
    (A) Adware
    (B) Ransomware
    (C) Worm
    (D) Boot sector virus
    উত্তৰ: adware য়ে অবাঞ্ছিত pop-up বিজ্ঞাপন দেখুৱায়।
    ব্যাখ্যা: Adware হৈছে অবাঞ্ছিত ছফ্টৱেৰ যিয়ে স্বয়ংক্ৰিয়ভাৱে বিজ্ঞাপন বা pop-up দেখুৱায়, প্ৰায়ে system লেহেমীয়া কৰে আৰু browsing অভ্যাস ট্ৰেক কৰে।
    ৬. গোপনে ইউজাৰৰ তথ্য সংগ্ৰহ কৰা ছফ্টৱেৰক ___ বোলে।
    (A) Spyware
    (B) Shareware
    (C) Freeware
    (D) Groupware
    উত্তৰ: spyware য়ে গোপনে ইউজাৰৰ কাৰ্য আৰু তথ্য সংগ্ৰহ কৰে।
    ব্যাখ্যা: Spyware য়ে ব্যৱহাৰকাৰীৰ কাৰ্যকলাপ গোপনে নিৰীক্ষণ কৰি সম্মতি নোহোৱাকৈ পাছৱৰ্ড, browsing ইতিহাস আৰু ব্যক্তিগত তথ্য সংগ্ৰহ কৰে।
    ৭. উপকাৰী যেন লাগি আচলতে কম্পিউটাৰৰ ক্ষতি কৰা program ক ___ বোলে।
    (A) Trojan horse
    (B) Worm
    (C) Adware
    (D) Patch
    উত্তৰ: Trojan horse য়ে উপকাৰী যেন লগা ছফ্টৱেৰৰ ভিতৰত দুষ্ট code লুকুৱায়।
    ব্যাখ্যা: Trojan horse য়ে উপযোগী বা বৈধ ছফ্টৱেৰ হিচাপে নিজকে লুকুৱায়, কিন্তু ইনষ্টল হোৱাৰ পিছত আক্ৰমণকাৰীৰ বাবে backdoor খোলাৰ দৰে ক্ষতিকাৰক কাম কৰে।
    ৮. ফাইলত লগ নলগাই নিজে নিজে বিয়পা program ক ___ বোলে।
    (A) Worm
    (B) Trojan
    (C) Spyware
    (D) Adware
    উত্তৰ: worm ফাইলত নলগাই নিজে নিজে network ত বিয়পে।
    ব্যাখ্যা: Worm হৈছে স্ব-প্ৰতিলিপিকাৰী malware যিয়ে host ফাইলত লগ নালাগিয়েই নিজে নেটৱৰ্কত বিয়পে, সেয়ে অতি দ্ৰুতগতিত বিয়পিব পাৰে।
    ৯. পাছৱৰ্ড উদ্ধাৰৰ বাবে ছলনা কৰা ভুৱা ইমেইলক ___ বোলে।
    (A) Phishing emails
    (B) Spam emails
    (C) Draft emails
    (D) Auto emails
    উত্তৰ: phishing ইমেইলে বিশ্বাসী উৎসৰ ছল ধৰি ব্যক্তিগত তথ্য চুৰি কৰে।
    ব্যাখ্যা: Phishing email হৈছে ভুৱা বাৰ্তা যিয়ে বেংকৰ দৰে বিশ্বাসযোগ্য উৎসৰ পৰা অহা বুলি দেখুৱাই প্ৰাপকক পাছৱৰ্ড, OTP বা card তথ্য প্ৰকাশ কৰিবলৈ প্ৰতাৰণা কৰে।
    ১০. তথ্য চুৰিৰ বাবে বিশ্বাসী ব্যক্তিৰ ছল ধৰাক ___ বোলে।
    (A) Impersonation / phishing
    (B) Firewalling
    (C) Encryption
    (D) Backup
    উত্তৰ: phishing/impersonation য়ে বিশ্বাসী ব্যক্তি বা সংস্থাৰ ছল ধৰি ইউজাৰক ঠগে।
    ব্যাখ্যা: Phishing বা impersonation-ত আক্ৰমণকাৰীয়ে বিশ্বাসযোগ্য ব্যক্তি বা প্ৰতিষ্ঠান হিচাপে নিজকে দেখুৱাই login তথ্যৰ দৰে গোপন তথ্য লাভ কৰে।
    ১১. traffic ঢালি সেৱা অনুপলব্ধ কৰা cyber আক্রমণক ___ বোলে।
    (A) Denial of Service (DoS/DDoS)
    (B) Phishing
    (C) Spamming
    (D) Spoofing
    উত্তৰ: DoS/DDoS আক্রমণে server ৰ ওপৰত traffic ঢালি সি বাস্তৱ ইউজাৰক সেৱা দিব নোৱাৰা কৰে।
    ব্যাখ্যা: Denial of Service (DoS/DDoS) আক্ৰমণত server লৈ ভুৱা request ৰ বান পঠোৱা হয়, যাৰ ফলত প্ৰকৃত ব্যৱহাৰকাৰীয়ে সেৱা ব্যৱহাৰ কৰিব নোৱাৰে।
    ১২. আচল website ৰ দৰে ভুৱা website বনাই ব্যক্তিগত তথ্য চুৰি কৰাকে ___ বোলে।
    (A) Phishing
    (B) বৈধ হেকিং (Hacking legally)
    (C) backup (Backing up)
    (D) download (Downloading)
    উত্তৰ: website phishing য়ে আচল site ৰ অনুকৰণ কৰি login তথ্য চুৰি কৰে।
    ব্যাখ্যা: ৱেবছাইট phishing য়ে প্ৰকৃত ৱেবছাইটৰ নকল প্ৰতিলিপি বনাই ভুক্তভোগীয়ে login কৰিবলৈ চেষ্টা কৰোঁতে user ID আৰু পাছৱৰ্ড চোৰ কৰে।
    ১৩. এইবোৰৰ কোনটো password সবাতোকৈ শক্তিশালী?
    (A) As3#kQ!9zW@2
    (B) 123456
    (C) password
    (D) abc123
    উত্তৰ: শক্তিশালী password ত ডাঙৰ/সৰু আখৰ, সংখ্যা আৰু চিহ্ন মিহলি আৰু দীঘল হয়।
    ব্যাখ্যা: শক্তিশালী পাছৱৰ্ড দীঘল আৰু ইয়াত uppercase, lowercase, অংক আৰু symbol মিশ্ৰিত থাকে। 'As3#kQ!9zW@2' এই নিয়ম পূৰণ কৰে, আনহাতে বাকীবোৰ সাধাৰণ আৰু সহজে অনুমান কৰিব পৰা।
    ১৪. তলৰ কোনটো দুৰ্বল password?
    (A) 123456
    (B) Kt#8pLq$2m
    (C) x9@BqW4!z
    (D) R3d!g0ld7
    উত্তৰ: 123456 দৰে সহজ password অতি দুৰ্বল আৰু অনুমান কৰা সহজ।
    ব্যাখ্যা: '123456' আটাইতকৈ সাধাৰণ পাছৱৰ্ডবোৰৰ এটা আৰু তৎক্ষণাত অনুমান কৰিব পৰা যায়। শক্তিশালী পাছৱৰ্ডৰ বাবে দীঘল আৰু বিভিন্ন আখৰৰ মিশ্ৰণ প্ৰয়োজন।
    ১৫. 'টু-ফেক্টৰ প্ৰমাণীকৰণ' (2FA) কি?
    (A) দুটা ভিন্ন পৰিচয় প্রমাণেৰে login (Login using two different proofs of identity)
    (B) দুটা কম্পিউটাৰ একেলগে (Two computers together)
    (C) দুটা antivirus (Two antivirus programs)
    (D) দুটা ইন্টারনেট সংযোগ (Two internet connections)
    উত্তৰ: 2FA ত login ৰ বাবে password ৰ লগত OTP আদি দ্বিতীয় ফেক্টৰ লাগে।
    ব্যাখ্যা: Two-factor authentication-ত দুটা ভিন্ন পৰিচয় প্ৰমাণ লাগে, সাধাৰণতে এটা পাছৱৰ্ড আৰু OTP বা আঙুলিৰ ছাপৰ দৰে দ্বিতীয় factor, সেয়ে কেৱল চোৰ কৰা পাছৱৰ্ডেৰে প্ৰৱেশ নহয়।
    ১৬. OTP (One Time Password) মূলত ___ বাবে ব্যৱহাৰ হয়।
    (A) login/লেনদেনত পৰিচয় সত্যাপন (Verifying identity during login/transactions)
    (B) ইন্টারনেট বেগ (Increasing internet speed)
    (C) ভাইৰাছ পৰিষ্কাৰ (Cleaning viruses)
    (D) দলিল প্ৰিন্ট (Printing documents)
    উত্তৰ: OTP হৈছে login বা লেনদেনত ইউজাৰ সত্যাপনৰ বাবে পঠোৱা সাময়িক কোড।
    ব্যাখ্যা: OTP (One Time Password) হৈছে অলপ সময়ৰ বাবে বৈধ এটা অস্থায়ী code, login বা লেনদেনৰ সময়ত ব্যৱহাৰকাৰীক সত্যতা প্ৰমাণ কৰিবলৈ পঞ্জীকৃত ম'বাইল বা ইমেইললৈ পঠোৱা হয়।
    ১৭. CAPTCHA য়ে কিসৰ পৰা ৰক্ষা কৰে?
    (A) স্বয়ংক্রিয় bot / spam (Automated bots / spam)
    (B) বিদ্যুৎ বিভ্রাট (Power failure)
    (C) RAM ৰ ভাইৰাছ (Virus in RAM)
    (D) প্ৰিন্টাৰ ত্রুটি (Printer errors)
    উত্তৰ: CAPTCHA য়ে স্বয়ংক্রিয় bot ৰ দ্বাৰা ফর্ম আৰু সেৱাৰ অপব্যৱহাৰ ৰোধ কৰে।
    ব্যাখ্যা: CAPTCHA য়ে ব্যৱহাৰকাৰী মানুহ হয় নে নহয় পৰীক্ষা কৰে আৰু স্বয়ংক্ৰিয় bot-ক form ব্যৱহাৰ, ভুৱা account সৃষ্টি বা spam পঠোৱাৰ পৰা বাধা দিয়ে।
    ১৮. ভাৰতত cyber অপরাধ সম্পৰ্কে কোন আইন?
    (A) IT Act, 2000
    (B) RTI Act
    (C) Consumer Act
    (D) Companies Act
    উত্তৰ: Information Technology Act, 2000 হৈছে ভাৰতৰ cyber আইন।
    ব্যাখ্যা: Information Technology Act, 2000 ভাৰতৰ প্ৰধান cyber আইন। ই cyber অপৰাধ নিৰ্ধাৰণ কৰে আৰু electronic লেনদেনক আইনী স্বীকৃতি দিয়ে।
    ১৯. IT Act ৰ ধাৰা 66 ___ সৈতে জড়িত।
    (A) কম্পিউটাৰ সম্পর্কিত অপৰাধ (Computer related offences)
    (B) কৰ নিয়ম (Tax rules)
    (C) বিবাহ আইন (Marriage law)
    (D) মোটৰ যানবাহন (Motor vehicles)
    উত্তৰ: IT Act ৰ ধাৰা 66 ত hacking আদি কম্পিউটাৰ সম্পর্কিত অপৰাধ জড়িত।
    ব্যাখ্যা: IT Act ৰ ধাৰা 66 য়ে hacking, তথ্য চুৰি বা কম্পিউটাৰ সম্পদৰ ক্ষতিৰ দৰে computer-সংশ্লিষ্ট অপৰাধৰ বাবে কাৰাদণ্ড আৰু জৰিমনাৰ বিধান দিয়ে।
    ২০. ভাৰতৰ ব্যক্তিগত তথ্য সংগ্ৰহ আৰু প্রক্রিয়া আইন ___।
    (A) DPDP Act, 2023 (Digital Personal Data Protection)
    (B) RTI Act, 2005
    (C) Cinema Act
    (D) Police Act
    উত্তৰ: Digital Personal Data Protection Act, 2023 য়ে ভাৰতত ব্যক্তিগত তথ্য ৰক্ষা কৰে।
    ব্যাখ্যা: Digital Personal Data Protection (DPDP) Act, 2023 য়ে ভাৰতত ব্যক্তিগত ডিজিটেল তথ্যৰ সংগ্ৰহ, প্ৰক্ৰিয়াকৰণ আৰু সুৰক্ষা নিয়ন্ত্ৰণ কৰে।
    ২১. পঠনযোগ্য তথ্য গোপন code লৈ ৰূপান্তৰকে ___ বোলে।
    (A) Encryption
    (B) Decryption

    চাইবাৰ সুৰক্ষা: ভাবুকি, সুৰক্ষা আৰু চাইবাৰ আইন

    Cyber security ৰ প্ৰশ্নই পৰীক্ষা কৰে যে সাধাৰণ online ভাবুকিবোৰ প্ৰাৰ্থীয়ে নাম ল'ব পাৰে নে নাই, এটাক আনটোৰ পৰা বেলেগ কৰিব পাৰে নে নাই, আৰু সুৰক্ষিত internet ব্যৱহাৰৰ মূল নিয়ম আৰু চাইবাৰ আইনৰ মূল ধাৰাবোৰ মনত আছে নে নাই। প্ৰশ্নবোৰ পোনপটীয়া আৰু তথ্যভিত্তিক, গতিকে চুটি কিন্তু সুসংগঠিত পুনৰালোচনাই এই অংশ দ্ৰুতভাৱে জনা যায়।

    এই গভীৰ অধ্যয়ন টোকাত মূল পৰিভাষা, malware ৰ প্ৰকাৰ, আক্ৰমণৰ ধৰণ, সুৰক্ষিত অভ্যাস, encryption আৰু ভাৰতৰ চাইবাৰ আইন, প্ৰশ্নৰ ধৰণ, সমাধানৰ পদ্ধতি, পৰীক্ষকে পতা ফান্দ আৰু প্ৰস্তুতিৰ পৰিকল্পনা দিয়া হৈছে। পঢ়াৰ পিছত প্ৰাৰ্থীয়ে ভাবুকি বা নিয়ম দ্বিধা নকৰি চিনি পাব।

    মূল পৰিভাষা

    • Cyber security: computer, network আৰু data ক online ভাবুকি আৰু অননুমোদিত প্ৰৱেশৰ পৰা সুৰক্ষা দিয়া।
    • Cyber crime: কম্পিউটাৰ বা internet ব্যৱহাৰ কৰি কৰা যিকোনো অপৰাধ।
    • Malware: virus, worm, trojan, ransomware বা spyware ৰ দৰে ক্ষতিকাৰক software।
    • Virus: file এটাত লাগি থকা আৰু file খুলিলে বিয়পি পৰা কাৰ্যসূচী।
    • Worm: নিজে নিজে copy হৈ network ত বিয়পি পৰা কাৰ্যসূচী।
    • Trojan horse: উপকাৰী যেন লগা কাৰ্যসূচীৰ ভিতৰত লুকুৱাই ৰখা ক্ষতিকাৰক code।
    • Ransomware: ব্যৱহাৰকাৰীৰ file বন্ধ কৰি খুলিবলৈ টকা দাবী কৰা malware।
    • Spyware: গোপনে ব্যৱহাৰকাৰীৰ কাম চাই তথ্য আনলৈ পঠিওৱা software।
    • Phishing: ভুৱা e-mail, message বা website ৰে ব্যক্তিগত তথ্য লোৱাৰ ছল।
    • Hacking: কম্পিউটাৰ বা network লৈ অননুমোদিত প্ৰৱেশ লাভ কৰা।
    • Firewall: network লৈ অহা-যোৱা traffic মনিটৰ আৰু filter কৰা বাধা।
    • Antivirus: malware ধৰা পেলাই আঁতৰোৱা software।
    • Encryption: কেৱল সঠিক ব্যক্তিয়ে পঢ়িব পৰাকৈ তথ্যক coded ৰূপলৈ সলোৱা।
    • Password: ব্যৱহাৰকাৰীৰ পৰিচয় প্ৰমাণ কৰিবলৈ ব্যৱহৃত গোপন আখৰৰ শাৰী।

    মুখ্য ধাৰণা আৰু নিয়ম

    • Virus এ host file আৰু ব্যৱহাৰকাৰীৰ কাম বিচাৰে, আনহাতে worm এ নিজে নিজে network ত বিয়পে।
    • Trojan উপকাৰী যেন লাগি গোপনে কাম কৰে, আৰু ransomware য়ে file বন্ধ কৰি টকা বিচাৰে।
    • Phishing, smishing আৰু vishing একেই ছল, ক্ৰমে e-mail, SMS আৰু ফোন কলৰ জৰিয়তে।
    • Firewall এ network traffic filter কৰে, আৰু antivirus এ file scan কৰি malware আঁতৰায়।
    • Encryption য়ে plain text ক cipher text লৈ সলায় আৰু decryption য়ে উলটি কৰে।
    • বলৱান password দীঘল, আখৰ-সংখ্যা-চিহ্ন মিহলি আৰু পুনৰ ব্যৱহাৰ নোহোৱা।
    • Two-factor authentication য়ে দুটা প্ৰমাণ বিচাৰে, যেনে password আৰু এটা one-time code।
    • Digital signature য়ে প্ৰেৰকৰ পৰিচয় আৰু বাৰ্তা সলনি নোহোৱা প্ৰমাণ কৰে।
    • VPN য়ে ৰাজহুৱা network ৰ ওপৰত সুৰক্ষিত, ব্যক্তিগত channel বনায়।
    • ভাৰতত চাইবাৰ অপৰাধ Information Technology Act, 2000 ৰ অধীনত চোৱা হয়।

    Malware আৰু আক্ৰমণৰ প্ৰকাৰ

    Malware হৈছে ক্ষতিকাৰক software ৰ সাধাৰণ নাম। Virus এ file এটাত লাগি থাকে আৰু file খুলিলে চলে, আৰু ই এটা host বিচাৰে। Worm ইয়াৰ দৰেই কিন্তু কোনো file নুখুলাকৈ নিজে নিজে network ত বিয়পে। Trojan এ উপকাৰী যেন লগা কাৰ্যসূচীৰ ভিতৰত লুকাই গোপনে ক্ষতিকাৰক কাম কৰে। Ransomware য়ে file বা গোটেই system বন্ধ কৰি মুকলি কৰিবলৈ টকা দাবী কৰে। Spyware আৰু keylogger এ গোপনে কাম আৰু কি-ষ্ট্ৰোক ৰেকৰ্ড কৰি আক্ৰমণকাৰীলৈ পঠিয়ায়, আৰু adware য়ে অবাঞ্ছিত বিজ্ঞাপনেৰে উপচাই পেলায়। আক্ৰমণৰ ভিতৰত phishing এ ভুৱা e-mail বা website ৰে তথ্য চুৰি কৰে, আৰু SMS আৰু ফোন কলৰ ৰূপক ক্ৰমে smishing আৰু vishing বোলা হয়। Denial-of-service আক্ৰমণে সেৱা এটা উপচাই দিয়ে যাতে প্ৰকৃত ব্যৱহাৰকাৰীয়ে ইয়াক পালোৱা নাপায়। Identity theft য়ে আন এজনৰ ব্যক্তিগত তথ্য ব্যৱহাৰ কৰে, আৰু social engineering য়ে সাধাৰণতে এজন ব্যক্তিক ঠগি গোপন তথ্য উলিয়ায়।

    সুৰক্ষিত অভ্যাস আৰু চাইবাৰ আইন

    সুৰক্ষিত ব্যৱহাৰ আৰম্ভ হয় এটা বলৱান password ৰে, যি সময়ে সময়ে সলাই সদায় গোপন ৰাখিব লাগে, আৰু য'ত পোৱা যায় তাত two-factor authentication ৰে। Software আৰু operating system আপডেট কৰি ৰাখিব লাগে, antivirus আৰু firewall জ্বলাই ৰাখিব লাগে, আৰু অচিনাকি প্ৰেৰকৰ link বা attachment নুখুলিব। ব্যক্তিগত তথ্য ৰাজহুৱাভাৱে নিদিব, আৰু ৰাজহুৱা wi-fi ত banking নকৰিব। তথ্যৰ backup ৰাখিব, কাৰণ ransomware ৰ বিৰুদ্ধে backup হৈছে শ্ৰেষ্ঠ সুৰক্ষা। ভাৰতত মূল আইন হৈছে Information Technology Act, 2000, যি 2008 চনত সংশোধন কৰা হয় আৰু অননুমোদিত প্ৰৱেশ, identity theft, অশ্লীল সমল প্ৰকাশ আৰু cyber terrorism ৰ দৰে অপৰাধ চম্ভালে, লগতে electronic record আৰু digital signature মানি লয়। CERT-In হৈছে চাইবাৰ সুৰক্ষা ঘটনাৰ প্ৰতিক্ৰিয়াৰ ৰাষ্ট্ৰীয় সংস্থা।

    সোধা প্ৰশ্নৰ প্ৰকাৰ

    আটাইতকৈ বেছি অহা ধৰণ হ'ল দিয়া বৰ্ণনাৰ লগত কোন ভাবুকি মিলে সোধা, যেনে কোন malware নিজে নিজে বিয়পে। দ্বিতীয়ত VPN বা CERT-In ৰ দৰে শব্দৰ full form বা অৰ্থ সোধা হয়। তৃতীয়ত ভাৰতৰ চাইবাৰ আইনৰ নাম সোধা হয়। চতুৰ্থত সুৰক্ষিত অভ্যাস এটা, যেনে বলৱান password ৰ নিয়ম, সোধা হয়। পঞ্চমত virus আৰু worm ৰ দৰে দুটা শব্দৰ পাৰ্থক্য সোধা হয়। পোনপটীয়া চিনাক্তকৰণ প্ৰশ্নই বেছি নম্বৰ লয়।

    Cyber Security প্ৰশ্ন সমাধানৰ স্তৰ

    প্ৰথমে প্ৰশ্ন পঢ়ি ই ভাবুকি, সঁজুলি, নিয়ম নে আইন বিচাৰে চাওক। দ্বিতীয়ে ভাবুকি হ'লে মূল সূত্ৰটো মিলাওক, যেনে নিজে বিয়পাৰ বাবে worm বা file বন্ধৰ বাবে ransomware। তৃতীয়ে সঁজুলি হ'লে তাৰ এশাৰী কাম মনত পেলাওক, যেনে firewall এ traffic filter কৰে। চতুৰ্থে আইন হ'লে Information Technology Act, 2000 মনত ৰাখক। পঞ্চমে বেলেগ শ্ৰেণীৰ বিকল্প আতৰাওক। শেষত full form শব্দে শব্দে পৰীক্ষা কৰক, কাৰণ এটা ভুল শব্দই শুদ্ধ উত্তৰ লুকুৱায়।

    পৰীক্ষাৰ প্ৰৱণতা

    অসমৰ নিয়োগ পৰীক্ষাত malware ৰ প্ৰকাৰ, phishing আৰু তাৰ ৰূপ, encryption, firewall আৰু antivirus, সুৰক্ষিত অভ্যাস আৰু IT Act, 2000 আটাইতকৈ বেছি আহে, তাৰ পিছত VPN, digital signature, DDoS আৰু identity theft ৰ দৰে শব্দ। প্ৰশ্ন চুটি আৰু এটা তথ্যভিত্তিক, গতিকে নিয়মীয়া পুনৰালোচনেই যথেষ্ট। একেই সংজ্ঞা সৰু সালসলনিৰে পুনৰ আহে, যাৰ ফলত এই অংশ দ্ৰুতভাৱে জনা যায়।

    সাধাৰণ ভুল

    • Virus আৰু worm মিলাই নিদিব; worm এ নিজে নিজে বিয়পে।
    • Trojan আৰু virus মিলাই নিদিব; trojan এ উপকাৰী কাৰ্যসূচীৰ ভিতৰত লুকায়।
    • Firewall ক antivirus নুবুলিব; দুয়োৱে সুৰক্ষা দিয়ে, কিন্তু বেলেগ ধৰণে।
    • Encryption আৰু decryption মিলাই নিদিব, এটাই বন্ধ কৰে আনটোৱে খোলে।
    • ভাৰতৰ চাইবাৰ আইন IT Act, 2000 যে, নাপাহৰিব।
    • Phishing, smishing আৰু vishing মিলাই নিদিব; সিহঁত e-mail, SMS আৰু voice।

    প্ৰস্তুতি কেনেকৈ কৰিব

    Malware ৰ প্ৰকাৰ আৰু সিহঁতৰ এশাৰী সংজ্ঞা, লগতে প্ৰতিটোক চিনাক্ত কৰা এটা সূত্ৰ লৈ তালিকা বনাওক। তাৰ পিছত phishing আৰু denial of service ৰ দৰে সাধাৰণ আক্ৰমণ, প্ৰতিটোৰ এটা উদাহৰণ সৈতে লিখক। তাৰ পিছত বলৱান password, software আপডেট আৰু firewall-antivirus ৰ দৰে সুৰক্ষিত অভ্যাস লিখক। শেষত IT Act, 2000 ৰ মূল কথা আৰু CERT-In ৰ ভূমিকা লিখক।

    দিনে কুৰিটা প্ৰশ্ন কৰি ভুল হোৱা সংজ্ঞা আৰু full form ৰ এখন তালিকা ৰাখক, কাৰণ একেই বস্তু পুনৰ আহে। Virus আৰু worm ৰ, লগতে firewall আৰু antivirus ৰ পাৰ্থক্য উচ্চস্বৰে পুনৰালোচনা কৰক, কাৰণ এয়াই আটাইতকৈ সাধাৰণ ফান্দ। শেষ সপ্তাহত কেৱল তালিকা আৰু ৰেজিষ্টাৰ চাওক, তেতিয়া এই অংশ সাজু হ'ব।

    দ্ৰুত পুনৰালোচনাৰ টিপছ

    • Virus এ host বিচাৰে; worm এ নিজে নিজে বিয়পে।
    • Trojan লুকায়, ransomware বন্ধ কৰে, spyware চায়।
    • Phishing e-mail, smishing SMS, vishing voice।
    • Encryption য়ে data ক cipher text ত বন্ধ কৰে; decryption য়ে খোলে।
    • ভাৰতৰ চাইবাৰ আইন Information Technology Act, 2000।

    শেষ পুনৰালোচনা

    শেষ দিনা malware ৰ তালিকা, সুৰক্ষিত অভ্যাস আৰু IT Act ৰ কথা পুনৰালোচনা কৰি কুৰিটা প্ৰশ্নৰ সময়বদ্ধ সংহতি কৰক। প্ৰতিটো ভুল উত্তৰৰ বাবে বাদ পৰা শব্দটো লিখি ৰাখক। Cyber security ৰ প্ৰশ্নই স্পষ্ট সংজ্ঞা বিচাৰে, আৰু সংজ্ঞা জনা প্ৰাৰ্থীয়ে দ্ৰুতভাৱে উত্তৰ দি সহজ নম্বৰ পায়।

    সঘনাই সোধা প্ৰশ্ন

    Virus আৰু worm ৰ পাৰ্থক্য কি?

    Virus এ file এটাত লাগি থাকে আৰু file খুলিলে বিয়পে, আনহাতে worm এ ব্যৱহাৰকাৰীৰ কাম নালাগে নিজে নিজে network ত বিয়পে।

    Phishing কি?

    Phishing হৈছে ভুৱা e-mail, message বা website ৰে ব্যক্তিগত তথ্য উলিওৱাৰ ছল।

    ভাৰতৰ মূল চাইবাৰ আইন কি?

    Information Technology Act, 2000, যি 2008 চনত সংশোধন কৰা হয়, ভাৰতৰ মূল চাইবাৰ আইন।

    Firewall ৰ কাম কি?

    Firewall এ network লৈ অহা-যোৱা traffic মনিটৰ আৰু filter কৰি অননুমোদিত প্ৰৱেশ ৰোধ কৰে।

    Ransomware কি?

    Ransomware হৈছে এনে malware, যি ব্যৱহাৰকাৰীৰ file বা system বন্ধ কৰি মুকলি কৰিবলৈ টকা দাবী কৰে।

    সম্পৰ্কিত কম্পিউটাৰ জ্ঞান বিষয়সমূহ

    এই বিষয়ৰ সৈতে একে শিতানৰ অন্য বিষয়সমূহ — প্ৰতিটোতে প্ৰশ্ন, শুদ্ধ উত্তৰ আৰু ব্যাখ্যা আছে।

    • DBMS, সংখ্যা পদ্ধতি আৰু চৰ্টকাট
    • MS Office ছুট
    • কম্পিউটাৰ মৌলিক ধাৰণা আৰু হাৰ্ডৱেৰ
    • চফ্টৱেৰ আৰু অপাৰেটিং ছিষ্টেম
    • নেটৱৰ্কিং আৰু ইন্টাৰনেট
    • সকলো কম্পিউটাৰ জ্ঞান

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
