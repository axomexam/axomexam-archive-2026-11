    Coding-Decoding

    Q1. If in a code MANGO is written as NZOHP, then APPLE is written as?
    যদি MANGO-ক NZOHP লিখা হয়, APPLE কি লিখা হ’ব?
    (A) ZOOKD
    (B) BQQME
    (C) BQQMF
    (D) CRRNG
    Answer: C) BQQMF
    Explanation: In this coding each letter is replaced by the letter one step ahead in the alphabet, so APPLE becomes BQQMF (A to B, P to Q, P to Q, L to M, E to F).
    এই সংকেতত প্ৰতিটো আখৰ বৰ্ণমালাৰ এখোপ আগৰ আখৰেৰে সলনি হয়, সেয়ে APPLE → BQQMF (A→B, P→Q, P→Q, L→M, E→F)।
    Q2. If in a code LION is written as MJPO, then TIGER is written as?
    যদি LION-ক MJPO লিখা হয়, TIGER কি লিখা হ’ব?
    (A) UJHFS
    (B) SHFDQ
    (C) UJHFR
    (D) VJIGT
    Answer: A) UJHFS
    Explanation: In the given code each letter of LION moves one step forward (L→M, I→J, O→P, N→O). Applying the same rule, TIGER becomes UJHFS.
    দিয়া সংকেতত LION ৰ প্ৰতিটো আখৰ এখোজ আগুৱাইছে (L→M, I→J, O→P, N→O)। একে নিয়ম প্ৰয়োগ কৰি TIGER → UJHFS।
