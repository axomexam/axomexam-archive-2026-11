    Q1. Which of the following is a volatile component of a computer?
    তলৰ কোনটো কম্পিউটাৰৰ অস্থিৰ অংশ
    (A) BIOS chip BIOS চিপ
    (B) RAM module RAM মডিউল
    (C) hard disk হাৰ্ড ডিস্ক
    (D) DVD ডিভিডি
    Answer: B) RAM module
    B) RAM মডিউল
    Explanation: A RAM module holds charge that leaks away without power, so it is volatile. Disks and the BIOS chip keep their data.
    RAM মডিউলৰ আধান বিদ্যুৎ নোহোৱাকৈ লাহে লাহে যায়, সেয়ে ই অস্থিৰ। ডিস্ক আৰু BIOS চিপে তথ্য ৰাখে।
    Q2. The component that supplies power to all parts of a desktop computer is the
    ডেস্কটপ কম্পিউটাৰৰ সকলো অংশলৈ শক্তি যোগান ধৰা অংশটো
    (A) SMPS
    (B) CPU
    (C) GPU
    (D) NIC
    Answer: A) SMPS
    Explanation: The switched mode power supply converts mains AC into the low DC voltages the board needs. The CPU only consumes that power.
    SMPS এ মেইন AC ক বৰ্তনীৰ প্ৰয়োজনীয় কম DC ভল্টেজলৈ সলায়। CPU এ কেবল সেই শক্তি খৰচ কৰে।
    Q3. Which of the following is application software?
    তলৰ কোনটো এপ্লিকেশ্যন ছফ্টৱেৰ
    (A) device driver ডিভাইচ ড্ৰাইভাৰ
    (B) linker লিংকাৰ
    (C) firmware ফাৰ্মৱেৰ
    (D) a payroll package এটা পেৰ'ল পেকেজ
    Answer: D) a payroll package
    D) এটা পেৰ'ল পেকেজ
    Explanation: A payroll package does a user's work, so it is application software. Drivers, linkers and firmware serve the machine itself.
    পেৰ'ল পেকেজে ব্যৱহাৰকাৰীৰ কাম কৰে, সেয়ে ই এপ্লিকেশ্যন ছফ্টৱেৰ। ড্ৰাইভাৰ, লিংকাৰ আৰু ফাৰ্মৱেৰে যন্ত্ৰটোক সহায় কৰে।
    Q4. A ROM chip that can be erased and rewritten using ultraviolet light is
    অতি-বেঙুনীয়া পোহৰেৰে মচি পুনৰ লিখিব পৰা ROM চিপ
    (A) DRAM
    (B) SRAM
    (C) EPROM
    (D) PROM
    Answer: C) EPROM
    Explanation: Erasable programmable ROM clears under ultraviolet light. PROM can be written only once and cannot be erased.
    EPROM অতি-বেঙুনীয়া পোহৰত মচি যায়। PROM কেবল এবাৰ লিখা যায় আৰু মচিব নোৱাৰি।

    (A) PS/2
    (B) HDMI
    (C) RJ-45
    (D) USB-A
    Answer: B) HDMI
    Explanation: HDMI carries digital video and audio to a display. RJ-45 is for network cable and PS/2 for old keyboards.
    HDMI এ ডিজিটেল ভিডিঅ' আৰু অডিঅ' ডিচপ্লেলৈ নিয়ে। RJ-45 নেটৱৰ্ক কেবলৰ আৰু PS/2 পুৰণি কীবৰ্ডৰ।
    Q6. The set of instructions that tells the hardware what to do is called

    ছফ্টৱেৰ প্ৰগ্ৰাম আৰু তাৰ তথ্যৰ সাধাৰণ নাম। হাৰ্ডৱেৰ শাৰীৰিক সজুলি।

    Q8. The firmware that starts a computer and tests the hardware is the
    কম্পিউটাৰ আৰম্ভ কৰি হাৰ্ডৱেৰ পৰীক্ষা কৰা ফাৰ্মৱেৰটো

    (B) shell শ্বেল
    (C) BIOS
    (D) driver ড্ৰাইভাৰ

    Explanation: The basic input output system runs a power-on self test and then loads the boot loader. The kernel comes later, inside the operating system.
    BIOS এ আৰম্ভণিৰ স্ব-পৰীক্ষা চলাই তাৰ পিছত বুট লোডাৰ লোড কৰে। কাৰ্নেল পিছত, অপাৰেটিং চিষ্টেমৰ ভিতৰত আহে।
    Q9. Which of the following is an example of a solid state storage device?
    তলৰ কোনটো কঠিন অৱস্থা সঞ্চয় সজুলিৰ উদাহৰণ
    (A) floppy disk ফ্লপি ডিস্ক
    (B) SSD
    (C) HDD
    (D) CD-ROM
    Answer: B) SSD
    Explanation: A solid state drive stores data in flash chips with no moving parts. A hard disk spins magnetic platters.
    SSD এ চলন্ত অংশ নথকা ফ্লেশ্ব চিপত তথ্য ৰাখে। হাৰ্ড ডিস্কে চুম্বকীয় প্লেটাৰ ঘূৰায়।
    Q10. A program that translates the whole source code at once before running is a

    (A) compiler কম্পাইলাৰ
    (B) interpreter ইন্টাৰপ্ৰেটৰ
    (C) assembler এচেম্বলাৰ
    (D) linker লিংকাৰ
    Answer: A) compiler
    A) কম্পাইলাৰ
    Explanation: A compiler produces an executable file in one pass. An interpreter translates and runs line by line.
    কম্পাইলাৰে এবাৰতে চলনশীল ফাইল বনায়। ইন্টাৰপ্ৰেটৰে শাৰী শাৰী অনুবাদ কৰি চলে।
    Q11. Which of the following is used to connect a computer to a local network by cable?

    (A) sound card ছাউণ্ড কাৰ্ড

    নেটৱৰ্ক ইন্টাৰফেচ কাৰ্ডে RJ-45 ছকেট দিয়ে আৰু পেকেট চলায়। ছাউণ্ড আৰু গ্ৰাফিক্স কাৰ্ডে সম্পূৰ্ণ বেলেগ কাম কৰে।

    (A) stored only on disk কেৱল ডিস্কত ৰখা
    (B) always free of cost সদায় বিনামূলীয়া
    (C) physical and can be touched শাৰীৰিক আৰু স্পৰ্শ কৰিব পৰা

    Answer: C) physical and can be touched

    হাৰ্ডৱেৰ স্পৰ্শযোগ্য সজুলি, ছফ্টৱেৰ অস্পৰ্শযোগ্য নিৰ্দেশৰ সমষ্টি। ছফ্টৱেৰৰ শাৰীৰিক ৰূপ নাই।
    Q13. Which of the following memories is read and written by the processor during execution?

    চলি থকা অৱস্থাত প্ৰগ্ৰাম আৰু কামৰ তথ্য মূল স্মৃতিত থাকে, সেয়ে প্ৰচেছৰে ইয়াক নিৰন্তৰ পঢ়ে আৰু লিখে।

    Q15. Which of the following is a utility program?

    Q16. The number of bits moved along the data bus at one time is called the bus

    C) প্ৰস্থ
    Explanation: Bus width counts the parallel lines, so a 64-bit bus carries 64 bits together. Speed is how often it does so.
    বাছ প্ৰস্থই সমান্তৰাল ৰেখাৰ সংখ্যা গণে, সেয়ে ৬৪-বিট বাছে একেলগে ৬৪ বিট নিয়ে। গতিয়ে কিমান সঘন কৰে সেয়া বুজায়।

    Q19. Which of the following is a characteristic of a hard disk?

    Hardware & Software: study notes

    Read this before you attempt the questions. It is written for the DHS & DME Technical Grade III paper.

    What the hardware and software block asks

    This topic is the machine and the instructions that run it, split into two halves that the paper keeps separate. The hardware half asks you to name a component and say what it does, or to say which device is input and which is output. The software half asks you to sort a program into system or application, to name the function of an operating system, and to say which translator does what. Almost every question is a matching question in disguise.

    The most efficient preparation is two short lists with a one-line job against each name. Once the jobs are attached, the paper cannot ask a version of the question that you have not already answered, because the wording changes but the pairing does not.

    Hardware, inside the case

    The motherboard is the main circuit board that carries the processor, the memory slots and the expansion slots, and connects everything. The processor, or CPU, executes instructions and is described as the brain of the computer. RAM is the working memory that holds the program currently running; ROM holds the firmware that starts the machine. The hard disk or SSD is the permanent store. The SMPS is the power supply unit that converts mains current into the low voltages the components need. The graphics processing unit handles images, and the heat sink and fan keep the processor within its temperature limit.

    The ports are asked by shape and by use. USB is the general-purpose port for keyboards, pen drives and printers. HDMI carries digital video and audio to a monitor or a projector. VGA carries analogue video only. An RJ45 port takes the Ethernet cable for a wired network. A 3.5 mm jack carries audio. A card reader takes memory cards. Knowing which port carries which signal answers the whole family of connector questions.

    Hardware, outside the case

    Peripherals are devices attached to the machine, and the split between input and output is the one thing to keep straight. Input: keyboard, mouse, trackball, joystick, scanner, microphone, webcam, light pen, barcode reader, biometric reader, touch pad. Output: monitor, printer, plotter, speaker, headphone, projector. Both: touch screen, modem, and a network card, which sends and receives. A pen drive is storage, not input or output, and that is a favourite distractor.

    Printers deserve one line each because they are asked as matches. A dot matrix printer is impact, uses a ribbon and is noisy but cheap for multi-part forms. An inkjet printer sprays ink and is good for photographs. A laser printer uses toner and a drum and is the fastest for text. A thermal printer uses heat-sensitive paper and is used for bills and labels. Resolution is measured in dots per inch, and speed in pages per minute.

    Software, in two halves

    System software runs the machine. It includes the operating system, the device drivers that let the system talk to each piece of hardware, the firmware that sits in ROM, and utility programs such as antivirus, backup, disk cleanup and file compression. Application software does the user's work: word processors, spreadsheets, presentation tools, browsers, media players, photo editors and games. The dividing line is simple - if it manages the machine, it is system software; if it does a task for the person, it is application software.

    The operating system has five jobs, and they are asked as a list. It manages the processor by deciding which program runs next, manages memory by allocating it to programs, manages files and folders, manages input and output devices through drivers, and provides the user interface. It also handles security and accounts. The user interface is either a graphical one, with windows, icons and a pointer, or a command line, where instructions are typed.

    Operating systems are classified by how many users and tasks they handle. A single-user single-task system runs one program for one person, as early personal computers did. A multi-user system serves several people at once, as a server does. A multitasking system runs several programs apparently at once by switching quickly. A real-time system must respond within a fixed deadline and is used in machinery, aircraft and medical devices. A distributed system spreads the work across several connected machines.

    Languages and translators

    A program is written in a language and must be translated before the processor can run it. A compiler translates the whole program at once and produces an executable file, so the program then runs fast but must be rebuilt after every change. An interpreter translates and runs one statement at a time, so it is easier to debug but slower in execution. An assembler translates assembly language, which uses short mnemonics in place of binary codes. C and C++ are usually compiled, Python and JavaScript are usually interpreted, and Java is compiled to bytecode that a virtual machine then runs.

    Software is also sorted by licence. Proprietary software is sold under restrictions and its source code is not available, as with Microsoft Windows and Adobe Photoshop. Open-source software publishes its source code and may be modified and redistributed under the licence, as with Linux, LibreOffice, Firefox and Python. Freeware is free of charge but not necessarily open, and shareware is a trial that must be paid for to continue.

    Two questions worked the short way

    A question asks which of four items is system software: MS Word, Windows, Excel, Photoshop. Windows is the answer, because it manages the machine; the other three do a task for the user. The same logic answers the reverse question, where the odd one out is the operating system among three applications.

    A question asks which translator produces an executable file. A compiler does, because it translates the whole program in advance. An interpreter does not produce one, and an assembler produces machine code only from assembly language. Read whether the question says whole program or line by line before choosing.

    Where marks are lost

    Assembling a machine, and keeping it healthy

    A working desktop needs six parts: a processor on a motherboard, RAM, a storage drive, a power supply, a monitor and an input device. Everything else is optional. Two upgrade facts are asked. Adding RAM makes a slow machine responsive when many programs are open, because the system stops swapping data to disk. Replacing a hard disk with an SSD makes start-up and file opening faster, because there are no moving parts to wait for.

    Maintenance is also a question set. A surge protector or a UPS protects against voltage spikes and outages. Dust cleaning keeps the fan and heat sink effective, which prevents overheating and sudden shutdowns. Regular backup, an updated antivirus and a current operating system patch level are the three standard answers to how a computer is kept safe. And defragmentation matters for a mechanical hard disk, not for an SSD.

    Where the two halves meet

    The connection between hardware and software is the driver, a small program that translates the operating system's instructions into commands a particular device understands. That is why a printer needs its own driver, and why a new device may not work until its driver is installed. The same idea explains the BIOS: it is firmware, so it is software permanently stored in hardware, and it runs before any operating system exists.

    Three errors recur. A pen drive is called an input device, when it is storage. Firmware is confused with software in general, when firmware is the small program fixed in ROM that starts the hardware. And a compiler is confused with an interpreter, so the answer says line by line for a compiler. Attach the correct one-line job to each term and all three disappear.

    • Motherboard carries everything; CPU executes; RAM is working memory; ROM holds firmware.
    • Input: keyboard, mouse, scanner, mic. Output: monitor, printer, speaker. Both: touch screen, modem.
    • System software manages the machine; application software does the user's task.
    • Compiler translates the whole program; interpreter translates line by line; assembler handles assembly.
    • OS jobs: processor, memory, files, devices, user interface.
    Exam tip: For any software question, ask who the work is for. If the answer is the machine itself, it is system software; if it is the person, it is application software.

    মাডাৰব'ৰ্ড হ'ল মূল চাৰ্কিট বৰ্ড যি প্ৰচেছৰ, মেম'ৰি স্লট আৰু এক্সপেনশন স্লট ধৰি ৰাখি সকলো সংযুক্ত কৰে। প্ৰচেছৰ বা CPU এ নিৰ্দেশনা চলায় আৰু তাক কম্পিউটাৰৰ মগজু বুলি কোৱা হয়। RAM হ'ল কাৰ্যকৰী মেম'ৰি যি বৰ্তমান চলি থকা কাৰ্যসূচী ধৰি ৰাখে; ROM এ যন্ত্ৰ আৰম্ভ কৰা ফাৰ্মৱেৰ ধৰি ৰাখে। হাৰ্ড ডিস্ক বা SSD স্থায়ী ভাণ্ডাৰ। SMPS হ'ল বিদ্যুৎ যোগান একক যি মেইন প্ৰবাহক উপাংশৰ বাবে প্ৰয়োজনীয় কম ভ'ল্টলৈ ৰূপান্তৰ কৰে। গ্ৰাফিক্স প্ৰচেছিং ইউনিটে ছবি চম্ভালে, আৰু হিট চিংক আৰু ফেনে প্ৰচেছৰক তাৰ উষ্ণতাৰ সীমাৰ ভিতৰত ৰাখে।

    প'ৰ্টবোৰ আকৃতি আৰু ব্যৱহাৰৰ পৰা সোধা হয়। USB হ'ল কীব'ৰ্ড, পেন ড্ৰাইভ আৰু প্ৰিণ্টাৰৰ সাধাৰণ প'ৰ্ট। HDMI য়ে মনিটৰ বা প্ৰজেক্টৰলৈ ডিজিটেল ভিডিঅ' আৰু শব্দ লৈ যায়। VGA য়ে কেৱল এনালগ ভিডিঅ' লৈ যায়। RJ45 প'ৰ্টে তারযুক্ত নেটৱৰ্কৰ ইথাৰনেট কেবল লয়। 3.5 মি.মি. জেকে শব্দ লয়। কাৰ্ড ৰিডাৰে মেম'ৰি কাৰ্ড লয়। কোন প'ৰ্টে কোন সংকেত লৈ যায় জানিলে সংযোগৰ গোটেই প্ৰশ্নৰ উত্তৰ পোৱা যায়।

    হাৰ্ডৱেৰ, কেছৰ বাহিৰত

    পেৰিফেৰেল হ'ল যন্ত্ৰৰ লগত সংযুক্ত সঁজুলি, আৰু ইনপুট-আউটপুটৰ ভাগটোৱেই একমাত্ৰ মনত ৰখাৰ কথা। ইনপুট: কীব'ৰ্ড, মাউছ, ট্ৰেকবল, জয়ষ্টিক, স্কেনাৰ, মাইক্ৰ'ফ'ন, ৱেবকেম, লাইট পেন, বাৰক'ড ৰিডাৰ, বায়'মেট্ৰিক ৰিডাৰ, টাচ পেড। আউটপুট: মনিটৰ, প্ৰিণ্টাৰ, প্লটাৰ, স্পীকাৰ, হেডফোন, প্ৰজেক্টৰ। দুয়োটা: টাচ স্ক্ৰিন, মডেম, আৰু নেটৱৰ্ক কাৰ্ড, যি পঠিয়ায় আৰু লয়। পেন ড্ৰাইভ হ'ল সংৰক্ষণ, ইনপুট বা আউটপুট নহয়, আৰু সেয়াই এটা চিনাকি ফান্দ।

    প্ৰিণ্টাৰবোৰ প্ৰতিটোৰে এশাৰী লগা উচিত কাৰণ মিলোৱা প্ৰশ্ন হিচাপে আহে। ডট মেট্ৰিক্স প্ৰিণ্টাৰ ইম্পেক্ট, ৰিবন ব্যৱহাৰ কৰে, শব্দ কৰে কিন্তু একাধিক কপিৰ ফৰ্মৰ বাবে সস্তা। ইংকজেট প্ৰিণ্টাৰে চিয়াঁহী ছটিয়ায় আৰু ফটোগ্ৰাফৰ বাবে ভাল। লেজাৰ প্ৰিণ্টাৰে ট'নাৰ আৰু ড্ৰাম ব্যৱহাৰ কৰে আৰু লিখনীৰ বাবে আটাইতকৈ দ্ৰুত। থাৰ্মেল প্ৰিণ্টাৰে তাপ-সংবেদী কাগজ ব্যৱহাৰ কৰে আৰু বিল আৰু লেবেলত লাগে। ৰিজ'লিউচন প্ৰতি ইঞ্চিত বিন্দুত আৰু গতি প্ৰতি মিনিটত পৃষ্ঠাত মাপা হয়।

    চফ্টৱেৰ, দুটা ভাগত

    চিষ্টেম চফ্টৱেৰে যন্ত্ৰ চলায়। ইয়াত অপাৰেটিং চিষ্টেম, প্ৰতিটো হাৰ্ডৱেৰৰ লগত কথা পাতিবলৈ দিয়া ডিভাইচ ড্ৰাইভাৰ, ROM ত থকা ফাৰ্মৱেৰ, আৰু এণ্টিভাইৰাছ, বেকআপ, ডিস্ক ক্লিনআপ আৰু ফাইল কম্প্ৰেছনৰ দৰে ইউটিলিটি কাৰ্যসূচী পৰে। এপ্লিকেচন চফ্টৱেৰে ব্যৱহাৰকাৰীৰ কাম কৰে: ৱৰ্ড প্ৰচেছৰ, স্প্ৰেডশ্বীট, প্ৰজেণ্টেচন সঁজুলি, ব্ৰাউজাৰ, মিডিয়া প্লেয়াৰ, ফটো এডিটৰ আৰু গেম। ভাগৰ ৰেখা সৰল - যি যন্ত্ৰ পৰিচালনা কৰে সেয়া চিষ্টেম চফ্টৱেৰ; যি ব্যক্তিৰ কাম কৰে সেয়া এপ্লিকেচন চফ্টৱেৰ।

    অপাৰেটিং চিষ্টেমৰ পাঁচটা কাম, আৰু তালিকা হিচাপে সোধা হয়। ই প্ৰচেছৰ পৰিচালনা কৰে কাৰ্যসূচী কোনটো পিছত চলিব ঠিক কৰি, মেম'ৰি পৰিচালনা কৰে কাৰ্যসূচীলৈ বিতৰণ কৰি, ফাইল আৰু ফ'ল্ডাৰ পৰিচালনা কৰে, ড্ৰাইভাৰৰ জৰিয়তে ইনপুট আউটপুট সঁজুলি পৰিচালনা কৰে, আৰু ব্যৱহাৰকাৰী ইণ্টাৰফেচ দিয়ে। ই নিৰাপত্তা আৰু একাউণ্টো চম্ভালে। ইণ্টাৰফেচ গ্ৰাফিকেল - ৱিণ্ড', আইকন আৰু পইণ্টাৰেৰে - বা কমাণ্ড লাইন, য'ত নিৰ্দেশনা টাইপ কৰা হয়।

    অপাৰেটিং চিষ্টেম কিমান ব্যৱহাৰকাৰী আৰু কিমান কাম চম্ভালে তাৰ ওপৰত ভাগ কৰা হয়। একক-ব্যৱহাৰকাৰী একক-কামৰ চিষ্টেমে এজনৰ বাবে এটা কাৰ্যসূচী চলায়, যেনেকৈ আৰম্ভণিৰ ব্যক্তিগত কম্পিউটাৰে কৰিছিল। বহু-ব্যৱহাৰকাৰী চিষ্টেমে একেলগে কেইবাজনক সেৱা দিয়ে, যেনেকৈ চাৰ্ভাৰে কৰে। মাল্টিটাস্কিং চিষ্টেমে দ্ৰুতভাৱে সলনি কৰি কেইবাটাও কাৰ্যসূচী একেলগে চলোৱা যেন দেখুৱায়। ৰিয়েল-টাইম চিষ্টেমে নিৰ্দিষ্ট সময়ৰ ভিতৰত সঁহাৰি দিব লাগে আৰু যন্ত্ৰ, বিমান আৰু চিকিৎসা সঁজুলিত ব্যৱহৃত হয়। বিতৰণ চিষ্টেমে কামক কেইবাখন সংযুক্ত যন্ত্ৰত ভাগ কৰে।

    ভাষা আৰু ৰূপান্তৰক

    কাৰ্যসূচী এটা ভাষাত লিখা হয় আৰু প্ৰচেছৰে চলোৱাৰ আগতে ৰূপান্তৰ কৰিব লাগে। কম্পাইলাৰে গোটেই কাৰ্যসূচী একেলগে ৰূপান্তৰ কৰি চলিব পৰা ফাইল বনায়, সেয়ে কাৰ্যসূচী দ্ৰুত চলে কিন্তু প্ৰতিবাৰ সলনি কৰিলে পুনৰ বনাব লাগে। ইণ্টাৰপ্ৰিটাৰে এটাৰ পিছত এটা নিৰ্দেশনা ৰূপান্তৰ কৰি চলায়, সেয়ে ডিবাগ কৰিবলৈ সহজ কিন্তু চলোৱাত লাহী। এচেম্বলাৰে এচেম্বলি ভাষা ৰূপান্তৰ কৰে, যি বাইনেৰি ক'ডৰ ঠাইত চুটি নাম ব্যৱহাৰ কৰে। C আৰু C++ সাধাৰণতে কম্পাইল হয়, Python আৰু JavaScript সাধাৰণতে ইণ্টাৰপ্ৰিট হয়, আৰু Java বাইটক'ডলৈ কম্পাইল হৈ ভাৰ্চুৱেল মেচিনে চালায়।

    চফ্টৱেৰ অনুজ্ঞাপতিত্বৰ পৰাও ভাগ কৰা হয়। মালিকানাধীন চফ্টৱেৰ নিষেধাজ্ঞাৰে বিক্ৰী হয় আৰু তাৰ উৎস ক'ড উপলব্ধ নহয়, যেনে Microsoft Windows আৰু Adobe Photoshop। মুক্ত-উৎস চফ্টৱেৰে উৎস ক'ড প্ৰকাশ কৰে আৰু অনুজ্ঞাপতিত্ব অনুসৰি সলনি আৰু পুনৰ বিতৰণ কৰিব পাৰি, যেনে Linux, LibreOffice, Firefox আৰু Python। ফ্ৰীৱেৰ বিনামূলীয়া কিন্তু মুক্ত নহ'বও পাৰে, আৰু শ্বেয়াৰৱেৰ এটা পৰীক্ষা যাক চলাই ৰাখিবলৈ টকা দিব লাগে।

    চুটিকৈ কৰা দুটা প্ৰশ্ন

    চাৰিটা বস্তুৰ ভিতৰত কোনটো চিষ্টেম চফ্টৱেৰ সোধা হ'ল: MS Word, Windows, Excel, Photoshop। উত্তৰ Windows, কাৰণ ই যন্ত্ৰ পৰিচালনা কৰে; বাকী তিনিওটা ব্যৱহাৰকাৰীৰ কাম কৰে। একেই যুক্তিয়ে ওলোটা প্ৰশ্নৰ উত্তৰ দিয়ে, য'ত তিনিটা এপ্লিকেচনৰ মাজত অপাৰেটিং চিষ্টেমটো পৃথক।

    কোন ৰূপান্তৰকে চলিব পৰা ফাইল বনায় সোধা হ'ল। কম্পাইলাৰে বনায়, কাৰণ ই গোটেই কাৰ্যসূচী আগতে ৰূপান্তৰ কৰে। ইণ্টাৰপ্ৰিটাৰে নবনায়, আৰু এচেম্বলাৰে কেৱল এচেম্বলি ভাষাৰ পৰা মেচিন ক'ড বনায়। বাছনিৰ আগতে প্ৰশ্নত গোটেই কাৰ্যসূচী নে শাৰী শাৰী সেয়া পঢ়া।

    ক'ত নম্বৰ যায়

    যন্ত্ৰ জোৰা আৰু তাৰ যতন লোৱা

    কাম কৰা ডেস্কটপত ছটা অংশ লাগে: মাডাৰব'ৰ্ডত এটা প্ৰচেছৰ, RAM, এটা সংৰক্ষণ ড্ৰাইভ, বিদ্যুৎ যোগান, এটা মনিটৰ আৰু এটা ইনপুট সঁজুলি। বাকী সকলো ঐচ্ছিক। দুটা আপগ্ৰেডৰ তথ্য সোধা হয়। RAM যোগ কৰিলে বহু কাৰ্যসূচী খোলা থাকিলেও লাহী যন্ত্ৰ সক্ৰিয় হয়, কাৰণ চিষ্টেমে ডিস্কলৈ তথ্য সলোৱা বন্ধ কৰে। হাৰ্ড ডিস্কৰ ঠাইত SSD দিলে আৰম্ভণি আৰু ফাইল খোলা দ্ৰুত হয়, কাৰণ অপেক্ষা কৰিবলগীয়া চলন্ত অংশ নাথাকে।

    যতন লোৱাও প্ৰশ্নৰ অংশ। চাৰ্জ প্ৰটেক্টৰ বা UPS এ ভ'ল্টেজৰ ঢৌ আৰু বিদ্যুৎ বন্ধৰ পৰা ৰক্ষা কৰে। ধূলি পৰিষ্কাৰ কৰিলে ফেন আৰু হিট চিংক কাৰ্যকৰী থাকে, যাৰ ফলত অতিতাপ আৰু হঠাতে বন্ধ হোৱা ৰোধ হয়। নিয়মীয়া বেকআপ, আপডেট কৰা এণ্টিভাইৰাছ আৰু শেহতীয়া অপাৰেটিং চিষ্টেম পেটচ - কম্পিউটাৰ সুৰক্ষিত ৰখাৰ তিনি চিনাকি উত্তৰ। আৰু ডিফ্ৰেগমেণ্টেচন যান্ত্ৰিক হাৰ্ড ডিস্কৰ বাবে প্ৰয়োজন, SSD ৰ বাবে নহয়।

    দুই ভাগৰ সংযোগস্থল

    হাৰ্ডৱেৰ আৰু চফ্টৱেৰৰ সংযোগ হ'ল ড্ৰাইভাৰ, এটা সৰু কাৰ্যসূচী যি অপাৰেটিং চিষ্টেমৰ নিৰ্দেশনা এটা নিৰ্দিষ্ট সঁজুলিয়ে বুজা আদেশলৈ ৰূপান্তৰ কৰে। সেয়ে প্ৰিণ্টাৰৰ নিজা ড্ৰাইভাৰ লাগে, আৰু সেয়ে নতুন সঁজুলি তাৰ ড্ৰাইভাৰ নলগালৈকে নচলিবও পাৰে। একেই ধাৰণাই BIOS বুজায়: সেয়া ফাৰ্মৱেৰ, অৰ্থাৎ হাৰ্ডৱেৰত স্থায়ীভাৱে সাঁচি ৰখা চফ্টৱেৰ, আৰু যিকোনো অপাৰেটিং চিষ্টেম থকাৰ আগতেই চলে।

    শেষত এটা সহজ নিয়ম: যি বস্তু হাতৰে ধৰিব পাৰি সেয়া হাৰ্ডৱেৰ, যি পৰ্দাত দেখা যায় বা চলিবলৈ ইনষ্টল কৰিব লাগে সেয়া চফ্টৱেৰ। এই নিয়মেই মিলোৱা প্ৰশ্নৰ বেছিভাগ উত্তৰ দিয়ে।

    তিনিটা ভুল বাৰে বাৰে আহে। পেন ড্ৰাইভক ইনপুট সঁজুলি বুলি কোৱা হয়, অথচ সেয়া সংৰক্ষণ। ফাৰ্মৱেৰক সাধাৰণ চফ্টৱেৰৰ লগত মিলাই পেলোৱা হয়, অথচ ফাৰ্মৱেৰ হ'ল ROM ত স্থিৰ থকা সৰু কাৰ্যসূচী যি হাৰ্ডৱেৰ আৰম্ভ কৰে। আৰু কম্পাইলাৰক ইণ্টাৰপ্ৰিটাৰৰ লগত মিলাই পেলোৱা হয়, সেয়ে কম্পাইলাৰৰ বাবে শাৰী শাৰী বুলি উত্তৰ দিয়া হয়। প্ৰতিটো শব্দৰ লগত শুদ্ধ এশাৰী কাম জোৰা লগালে তিনিওটা নোহোৱা হয়।

    • মাডাৰব'ৰ্ডে সকলো ধৰে; CPU চালায়; RAM কাৰ্যকৰী মেম'ৰি; ROM ত ফাৰ্মৱেৰ।
    • ইনপুট: কীব'ৰ্ড, মাউছ, স্কেনাৰ, মাইক। আউটপুট: মনিটৰ, প্ৰিণ্টাৰ, স্পীকাৰ। দুয়োটা: টাচ স্ক্ৰিন, মডেম।
    • চিষ্টেম চফ্টৱেৰে যন্ত্ৰ চলায়; এপ্লিকেচন চফ্টৱেৰে ব্যৱহাৰকাৰীৰ কাম কৰে।
    • কম্পাইলাৰে গোটেই কাৰ্যসূচী; ইণ্টাৰপ্ৰিটাৰে শাৰী শাৰী; এচেম্বলাৰে এচেম্বলি।
    • অপাৰেটিং চিষ্টেমৰ কাম: প্ৰচেছৰ, মেম'ৰি, ফাইল, সঁজুলি, ইণ্টাৰফেচ।

    ফাৰ্মৱেৰ, BIOS আৰু বুটিং

    ফাৰ্মৱেৰ হ'ল ROM ত থকা সৰু কাৰ্যসূচী যি যন্ত্ৰ অন কৰাৰ লগে লগে চলে। BIOS (বেছিক ইনপুট আউটপুট চিষ্টেম) য়ে হাৰ্ডৱেৰ পৰীক্ষা কৰি অপাৰেটিং চিষ্টেম বিচাৰি লোড কৰে। এই প্ৰক্ৰিয়াক বুটিং বোলে। যদি অপাৰেটিং চিষ্টেম নাথাকে, কম্পিউটাৰে বুট নহয় আৰু পৰ্দাত কেৱল এটা বাৰ্তা দেখুৱায়। প্ৰশ্নকাকতত সোধা হয় কোনে যন্ত্ৰ আৰম্ভ কৰে - উত্তৰ BIOS।

    মেম'ৰিৰ স্তৰবিন্যাসো এশাৰীত সোধা হয়: ৰেজিষ্টাৰ আটাইতকৈ দ্ৰুত আৰু আটাইতকৈ সৰু, তাৰ পিছত কেশ্ব মেম'ৰি, তাৰ পিছত RAM, আৰু শেষত হাৰ্ড ডিস্ক আটাইতকৈ লাহী কিন্তু আটাইতকৈ ডাঙৰ। কেশ্ব মেম'ৰিৰ কাম হ'ল CPU এ সঘনাই ব্যৱহাৰ কৰা তথ্য ওচৰত ৰখা, যাতে অপেক্ষা কম হয়।

    গ্ৰাফিকেল আৰু কমাণ্ড ইণ্টাৰফেচ

    গ্ৰাফিকেল ইউজাৰ ইণ্টাৰফেচত ৱিণ্ড', আইকন, মেনু আৰু মাউছ থাকে, সেয়ে শিকিবলৈ সহজ। কমাণ্ড লাইন ইণ্টাৰফেচত নিৰ্দেশনা টাইপ কৰিব লাগে, সেয়ে শিকিবলৈ কঠিন কিন্তু দ্ৰুত আৰু স্বয়ংক্ৰিয় কৰিব পৰা যায়। Windows, macOS আৰু Android গ্ৰাফিকেল, আনহাতে Linux ৰ টাৰ্মিনেল কমাণ্ড লাইন। প্ৰশ্নকাকতত সোধা হয় কোনটো চিষ্টেমত মাউছ লাগে - উত্তৰ গ্ৰাফিকেল।

    পৰীক্ষাৰ টিপ: চফ্টৱেৰৰ যিকোনো প্ৰশ্নত সোধা, কামটো কাৰ বাবে? উত্তৰ যদি যন্ত্ৰ নিজে, তেন্তে চিষ্টেম চফ্টৱেৰ; যদি ব্যক্তি, তেন্তে এপ্লিকেচন চফ্টৱেৰ।
