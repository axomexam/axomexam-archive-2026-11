    Hardware & Software

    30 Questions with Answers

    Q1. Which of the following is a volatile component of a computer?
    তলৰ কোনটো কম্পিউটাৰৰ অস্থিৰ অংশ
    (A) RAM module RAM মডিউল
    (B) hard disk হাৰ্ড ডিস্ক
    (C) DVD ডিভিডি
    (D) BIOS chip BIOS চিপ
    Answer: A) RAM module
    A) RAM মডিউল
    Explanation: A RAM module holds charge that leaks away without power, so it is volatile. Disks and the BIOS chip keep their data.
    RAM মডিউলৰ আধান বিদ্যুৎ নোহোৱাকৈ লাহে লাহে যায়, সেয়ে ই অস্থিৰ। ডিস্ক আৰু BIOS চিপে তথ্য ৰাখে।
    Q2. The component that supplies power to all parts of a desktop computer is the
    ডেস্কটপ কম্পিউটাৰৰ সকলো অংশলৈ শক্তি যোগান ধৰা অংশটো
    (A) SMPS
    (B) CPU
    (C) GPU
    (D) NIC
    Answer: A) SMPS
    Explanation: The switched mode power supply converts mains AC into the low DC voltages the board needs. The CPU only consumes that power.
    SMPS এ মেইন AC ক বৰ্তনীৰ প্ৰয়োজনীয় কম DC ভল্টেজলৈ সলায়। CPU এ কেবল সেই শক্তি খৰচ কৰে।
    Q3. Which of the following is application software?
    তলৰ কোনটো এপ্লিকেশ্যন ছফ্টৱেৰ
    (A) a payroll package এটা পেৰ'ল পেকেজ
    (B) device driver ডিভাইচ ড্ৰাইভাৰ
    (C) linker লিংকাৰ
    (D) firmware ফাৰ্মৱেৰ
    Answer: A) a payroll package
    A) এটা পেৰ'ল পেকেজ
    Explanation: A payroll package does a user's work, so it is application software. Drivers, linkers and firmware serve the machine itself.
    পেৰ'ল পেকেজে ব্যৱহাৰকাৰীৰ কাম কৰে, সেয়ে ই এপ্লিকেশ্যন ছফ্টৱেৰ। ড্ৰাইভাৰ, লিংকাৰ আৰু ফাৰ্মৱেৰে যন্ত্ৰটোক সহায় কৰে।
    Q4. A ROM chip that can be erased and rewritten using ultraviolet light is
    অতি-বেঙুনীয়া পোহৰেৰে মচি পুনৰ লিখিব পৰা ROM চিপ
    (A) EPROM
    (B) PROM
    (C) DRAM
    (D) SRAM
    Answer: A) EPROM
    Explanation: Erasable programmable ROM clears under ultraviolet light. PROM can be written only once and cannot be erased.
    EPROM অতি-বেঙুনীয়া পোহৰত মচি যায়। PROM কেবল এবাৰ লিখা যায় আৰু মচিব নোৱাৰি।
    Q5. Which port is commonly used to connect a monitor?
    মনিটৰ সংযোগ কৰিবলৈ সাধাৰণতে কোন প'ৰ্ট ব্যৱহৃত হয়
    (A) HDMI
    (B) RJ-45
    (C) USB-A
    (D) PS/2
    Answer: A) HDMI
    Explanation: HDMI carries digital video and audio to a display. RJ-45 is for network cable and PS/2 for old keyboards.
    HDMI এ ডিজিটেল ভিডিঅ' আৰু অডিঅ' ডিচপ্লেলৈ নিয়ে। RJ-45 নেটৱৰ্ক কেবলৰ আৰু PS/2 পুৰণি কীবৰ্ডৰ।
    Q6. The set of instructions that tells the hardware what to do is called
    হাৰ্ডৱেৰক কি কৰিব লাগে কোৱা নিৰ্দেশৰ সমষ্টিক কি বোলা হয়
    (A) software ছফ্টৱেৰ
    (B) firmware only কেৱল ফাৰ্মৱেৰ
    (C) hardware হাৰ্ডৱেৰ
    (D) peripheral পেৰিফেৰেল
    Answer: A) software
    A) ছফ্টৱেৰ
    Explanation: Software is the general term for programs and the data they work on. Hardware is the physical equipment itself.
    ছফ্টৱেৰ প্ৰগ্ৰাম আৰু তাৰ তথ্যৰ সাধাৰণ নাম। হাৰ্ডৱেৰ শাৰীৰিক সজুলি।
    Q7. Which of the following is a pointing device?
    তলৰ কোনটো নিৰ্দেশক সজুলি
    (A) trackball ট্ৰেকবল
    (B) plotter প্লটাৰ
    (C) speaker স্পীকাৰ
    (D) projector প্ৰজেক্টৰ
    Answer: A) trackball
    A) ট্ৰেকবল
    Explanation: A trackball moves a pointer on screen by rolling a ball, so it points. The rest produce output.
    ট্ৰেকবলে বল ঘূৰাই পৰ্দাত পইণ্টাৰ লৰায়, সেয়ে ই নিৰ্দেশ কৰে। বাকীবোৰে আউটপুট দিয়ে।
    Q8. The firmware that starts a computer and tests the hardware is the
    কম্পিউটাৰ আৰম্ভ কৰি হাৰ্ডৱেৰ পৰীক্ষা কৰা ফাৰ্মৱেৰটো
    (A) BIOS
    (B) driver ড্ৰাইভাৰ
    (C) kernel কাৰ্নেল
    (D) shell শ্বেল
    Answer: A) BIOS
    Explanation: The basic input output system runs a power-on self test and then loads the boot loader. The kernel comes later, inside the operating system.
    BIOS এ আৰম্ভণিৰ স্ব-পৰীক্ষা চলাই তাৰ পিছত বুট লোডাৰ লোড কৰে। কাৰ্নেল পিছত, অপাৰেটিং চিষ্টেমৰ ভিতৰত আহে।
    Q9. Which of the following is an example of a solid state storage device?
    তলৰ কোনটো কঠিন অৱস্থা সঞ্চয় সজুলিৰ উদাহৰণ
    (A) SSD
    (B) HDD
    (C) CD-ROM
    (D) floppy disk ফ্লপি ডিস্ক
    Answer: A) SSD
    Explanation: A solid state drive stores data in flash chips with no moving parts. A hard disk spins magnetic platters.
    SSD এ চলন্ত অংশ নথকা ফ্লেশ্ব চিপত তথ্য ৰাখে। হাৰ্ড ডিস্কে চুম্বকীয় প্লেটাৰ ঘূৰায়।
    Q10. A program that translates the whole source code at once before running is a
    চলোৱাৰ আগতে গোটেই উৎস ক'ড একেলগে অনুবাদ কৰা প্ৰগ্ৰামটো
    (A) compiler কম্পাইলাৰ
    (B) interpreter ইন্টাৰপ্ৰেটৰ
    (C) assembler এচেম্বলাৰ
    (D) linker লিংকাৰ
    Answer: A) compiler
    A) কম্পাইলাৰ
    Explanation: A compiler produces an executable file in one pass. An interpreter translates and runs line by line.
    কম্পাইলাৰে এবাৰতে চলনশীল ফাইল বনায়। ইন্টাৰপ্ৰেটৰে শাৰী শাৰী অনুবাদ কৰি চলে।
    Q11. Which of the following is used to connect a computer to a local network by cable?
    কেবলেৰে কম্পিউটাৰ স্থানীয় নেটৱৰ্কত সংযোগ কৰিবলৈ কোনটো ব্যৱহৃত হয়
    (A) Ethernet card ইথাৰনেট কাৰ্ড
    (B) sound card ছাউণ্ড কাৰ্ড
    (C) graphics card গ্ৰাফিক্স কাৰ্ড
    (D) TV tuner card TV টিউনাৰ কাৰ্ড
    Answer: A) Ethernet card
    A) ইথাৰনেট কাৰ্ড
    Explanation: A network interface card provides the RJ-45 socket and handles packet traffic. Sound and graphics cards do entirely different jobs.
    নেটৱৰ্ক ইন্টাৰফেচ কাৰ্ডে RJ-45 ছকেট দিয়ে আৰু পেকেট চলায়। ছাউণ্ড আৰু গ্ৰাফিক্স কাৰ্ডে সম্পূৰ্ণ বেলেগ কাম কৰে।
    Q12. The difference between hardware and software is that hardware is
    হাৰ্ডৱেৰ আৰু ছফ্টৱেৰৰ পাৰ্থক্য হ'ল হাৰ্ডৱেৰ
    (A) physical and can be touched শাৰীৰিক আৰু স্পৰ্শ কৰিব পৰা
    (B) written in a high level language উচ্চস্তৰীয় ভাষাত লিখা
    (C) stored only on disk কেৱল ডিস্কত ৰখা
    (D) always free of cost সদায় বিনামূলীয়া
    Answer: A) physical and can be touched
    A) শাৰীৰিক আৰু স্পৰ্শ কৰিব পৰা
    Explanation: Hardware is the tangible equipment, while software is the intangible set of instructions. Software has no physical form.
    হাৰ্ডৱেৰ স্পৰ্শযোগ্য সজুলি, ছফ্টৱেৰ অস্পৰ্শযোগ্য নিৰ্দেশৰ সমষ্টি। ছফ্টৱেৰৰ শাৰীৰিক ৰূপ নাই।
    Q13. Which of the following memories is read and written by the processor during execution?
    কাৰ্যকৰণৰ সময়ত প্ৰচেছৰে কোন স্মৃতি পঢ়ে আৰু লিখে
    (A) main memory মূল স্মৃতি
    (B) ROM
    (C) cache only কেৱল কেশ্ব
    (D) BIOS
    Answer: A) main memory
    A) মূল স্মৃতি
    Explanation: Programs and working data sit in main memory while they run, so the processor reads and writes it constantly.
    চলি থকা অৱস্থাত প্ৰগ্ৰাম আৰু কামৰ তথ্য মূল স্মৃতিত থাকে, সেয়ে প্ৰচেছৰে ইয়াক নিৰন্তৰ পঢ়ে আৰু লিখে।
    Q14. A device driver is
    ডিভাইচ ড্ৰাইভাৰ হ'ল
    (A) software that lets the operating system use a device ছফ্টৱেৰ যি অপাৰেটিং চিষ্টেমক সজুলি ব্যৱহাৰ কৰিব দিয়ে
    (B) a cable joining two computers দুটা কম্পিউটাৰ জোড়া কেবল
    (C) a chip on the motherboard মাদাৰব'ৰ্ডৰ চিপ
    (D) a type of printer এবিধ প্ৰিণ্টাৰ
    Answer: A) software that lets the operating system use a device
    A) ছফ্টৱেৰ যি অপাৰেটিং চিষ্টেমক সজুলি ব্যৱহাৰ কৰিব দিয়ে
    Explanation: The driver translates the operating system's general requests into the specific commands a device understands.
    ড্ৰাইভাৰে অপাৰেটিং চিষ্টেমৰ সাধাৰণ অনুৰোধ সজুলিয়ে বুজা নিৰ্দিষ্ট আদেশলৈ সলায়।
    Q15. Which of the following is a utility program?
    তলৰ কোনটো ইউটিলিটি প্ৰগ্ৰাম
    (A) antivirus scanner এণ্টিভাইৰাছ স্কেনাৰ
    (B) word processor শব্দ প্ৰচেছৰ
    (C) presentation tool প্ৰেজেণ্টেশ্যন সজুলি
    (D) web browser ৱেব ব্ৰাউজাৰ
    Answer: A) antivirus scanner
    A) এণ্টিভাইৰাছ স্কেনাৰ
    Explanation: Utility programs maintain the system, and an antivirus scanner protects files. Word processors and browsers do user work.
    ইউটিলিটি প্ৰগ্ৰামে চিষ্টেম ৰক্ষণাবেক্ষণ কৰে, আৰু এণ্টিভাইৰাছে ফাইল সুৰক্ষা দিয়ে। শব্দ প্ৰচেছৰ আৰু ব্ৰাউজাৰে ব্যৱহাৰকাৰীৰ কাম কৰে।
    Q16. The number of bits moved along the data bus at one time is called the bus
    তথ্য বাছে এসময়ত কঢ়িয়া যোৱা বিটৰ সংখ্যাক কি বোলা হয়
    (A) width প্ৰস্থ
    (B) speed গতি
    (C) clock ঘড়ী
    (D) cache কেশ্ব
    Answer: A) width
    A) প্ৰস্থ
    Explanation: Bus width counts the parallel lines, so a 64-bit bus carries 64 bits together. Speed is how often it does so.
    বাছ প্ৰস্থই সমান্তৰাল ৰেখাৰ সংখ্যা গণে, সেয়ে ৬৪-বিট বাছে একেলগে ৬৪ বিট নিয়ে। গতিয়ে কিমান সঘন কৰে সেয়া বুজায়।
    Q17. Which of the following is an example of free and open source software?
    তলৰ কোনটো মুক্ত আৰু উন্মুক্ত উৎস ছফ্টৱেৰৰ উদাহৰণ
    (A) LibreOffice লিব্ৰে অফিচ

    (C) Adobe Photoshop এড'বি ফট'শ্বপ
    (D) Windows 11 উইণ্ড'জ ১১
    Answer: A) LibreOffice
    A) লিব্ৰে অফিচ
    Explanation: LibreOffice publishes its source code and may be used and modified freely. The others are proprietary.
    লিব্ৰে অফিচে নিজৰ উৎস ক'ড প্ৰকাশ কৰে আৰু মুক্তভাৱে ব্যৱহাৰ তথা সলনি কৰিব পাৰি। বাকীবোৰ মালিকানাধীন।
    Q18. The main function of an expansion slot is to
    বিস্তাৰণ স্লটৰ মূল কাম হ'ল
    (A) hold add-on cards such as graphics or network cards গ্ৰাফিক্স বা নেটৱৰ্ক কাৰ্ডৰ দৰে অতিৰিক্ত কাৰ্ড ধৰি ৰখা
    (B) store the operating system অপাৰেটিং চিষ্টেম ৰখা
    (C) cool the processor প্ৰচেছৰ শীতল কৰা
    (D) supply mains power মেইন শক্তি যোগান ধৰা
    Answer: A) hold add-on cards such as graphics or network cards
    A) গ্ৰাফিক্স বা নেটৱৰ্ক কাৰ্ডৰ দৰে অতিৰিক্ত কাৰ্ড ধৰি ৰখা
    Explanation: Expansion slots let you add capability the board did not ship with. Storage and cooling are handled elsewhere.
    বিস্তাৰণ স্লটে বৰ্তনীত নথকা ক্ষমতা যোগ কৰিব দিয়ে। সঞ্চয় আৰু শীতল কৰা আন ঠাইত হয়।
    Q19. Which of the following is a characteristic of a hard disk?
    তলৰ কোনটো হাৰ্ড ডিস্কৰ বৈশিষ্ট্য
    (A) it stores data magnetically on spinning platters ই ঘূৰ্ণনশীল প্লেটাৰত চুম্বকীয়ভাৱে তথ্য ৰাখে
    (B) it has no moving parts ইয়াৰ চলন্ত অংশ নাই
    (C) it is volatile ই অস্থিৰ
    (D) it holds only the operating system ই কেবল অপাৰেটিং চিষ্টেম ৰাখে
    Answer: A) it stores data magnetically on spinning platters
    A) ই ঘূৰ্ণনশীল প্লেটাৰত চুম্বকীয়ভাৱে তথ্য ৰাখে
    Explanation: A hard disk writes magnetically to platters that spin under a read-write head. Solid state drives are the ones with no moving parts.
    হাৰ্ড ডিস্কে পঢ়া-লিখা মূৰৰ তলত ঘূৰা প্লেটাৰত চুম্বকীয়ভাৱে লিখে। SSD হ'ল চলন্ত অংশ নথকা।
    Q20. An assembler converts
    এচেম্বলাৰে সলনি কৰে
    (A) assembly language into machine code এচেম্বলি ভাষা যন্ত্ৰ ক'ডলৈ
    (B) machine code into assembly language যন্ত্ৰ ক'ড এচেম্বলি ভাষালৈ
    (C) high level code into assembly language উচ্চস্তৰীয় ক'ড এচেম্বলি ভাষালৈ
    (D) source code into object code directly উৎস ক'ড পোনপটীয়াকৈ অবজেক্ট ক'ডলৈ
    Answer: A) assembly language into machine code
    A) এচেম্বলি ভাষা যন্ত্ৰ ক'ডলৈ
    Explanation: An assembler translates mnemonics one for one into machine instructions. Compilers handle high level languages instead.
    এচেম্বলাৰে নেম'নিক একৰ বাবে এক যন্ত্ৰ নিৰ্দেশলৈ সলায়। কম্পাইলাৰে উচ্চস্তৰীয় ভাষা চম্ভালে।
    Q21. Which of the following is used for permanent internal storage of programs and data?
    প্ৰগ্ৰাম আৰু তথ্যৰ স্থায়ী আভ্যন্তৰীণ সঞ্চয়লৈ তলৰ কোনটো ব্যৱহৃত হয়
    (A) hard disk drive হাৰ্ড ডিস্ক ড্ৰাইভ
    (B) RAM
    (C) cache কেশ্ব
    (D) register ৰেজিষ্টাৰ
    Answer: A) hard disk drive
    A) হাৰ্ড ডিস্ক ড্ৰাইভ
    Explanation: The hard disk keeps files when the machine is off. RAM, cache and registers all lose their contents on shutdown.
    যন্ত্ৰ বন্ধ থাকিলেও হাৰ্ড ডিস্কে ফাইল ৰাখে। RAM, কেশ্ব আৰু ৰেজিষ্টাৰে বন্ধ কৰিলে তথ্য হেৰুৱায়।
    Q22. The component that converts digital signals to analog for a telephone line is a
    টেলিফোন লাইনলৈ ডিজিটেল সংকেত এনালগলৈ সলনি কৰা অংশটো
    (A) modem মডেম
    (B) router ৰাউটাৰ
    (C) switch স্বিচ
    (D) hub হাব
    Answer: A) modem
    A) মডেম
    Explanation: A modem modulates and demodulates, which is where its name comes from. Routers and switches stay digital.
    মডেমে মডুলেট আৰু ডিমডুলেট কৰে, সেয়ে এই নাম। ৰাউটাৰ আৰু স্বিচ ডিজিটেলেই থাকে।
    Q23. Which of the following is not an operating system function?
    তলৰ কোনটো অপাৰেটিং চিষ্টেমৰ কাম নহয়
    (A) designing a poster প'ষ্টাৰ ডিজাইন কৰা
    (B) managing files ফাইল চলোৱা
    (C) allocating memory স্মৃতি বিতৰণ কৰা
    (D) scheduling processes প্ৰক্ৰিয়া সময়সূচী কৰা
    Answer: A) designing a poster
    A) প'ষ্টাৰ ডিজাইন কৰা
    Explanation: The operating system manages resources, not content. Designing a poster needs application software such as a drawing package.
    অপাৰেটিং চিষ্টেমে সম্পদ চলায়, সমল নহয়। প'ষ্টাৰ ডিজাইন কৰিবলৈ এড্ৰয়িং পেকেজৰ দৰে এপ্লিকেশ্যন লাগে।
    Q24. The term peripheral refers to
    পেৰিফেৰেল শব্দই বুজায়
    (A) any device attached to the computer for input, output or storage ইনপুট, আউটপুট বা সঞ্চয়ৰ বাবে কম্পিউটাৰত লগোৱা যিকোনো সজুলি
    (B) the processor only কেৱল প্ৰচেছৰ
    (C) the operating system অপাৰেটিং চিষ্টেম
    (D) the motherboard মাদাৰব'ৰ্ড
    Answer: A) any device attached to the computer for input, output or storage
    A) ইনপুট, আউটপুট বা সঞ্চয়ৰ বাবে কম্পিউটাৰত লগোৱা যিকোনো সজুলি
    Explanation: Peripherals sit outside the core processing unit and add capability. The processor and board are the core, not peripherals.
    পেৰিফেৰেল মূল প্ৰচেছিং ইউনিটৰ বাহিৰত থাকে আৰু ক্ষমতা যোগ কৰে। প্ৰচেছৰ আৰু বৰ্তনী মূল, পেৰিফেৰেল নহয়।
    Q25. Which of the following best describes cloud storage?
    তলৰ কোনটোৱে ক্লাউড সঞ্চয় ভালদৰে বৰ্ণনা কৰে
    (A) files kept on remote servers and reached over the internet দূৰৰ ছাৰ্ভাৰত ৰখা ফাইল যি ইণ্টাৰনেটেৰে পোৱা যায়
    (B) files kept only on a pen drive কেৱল পেন ড্ৰাইভত ৰখা ফাইল
    (C) memory inside the processor প্ৰচেছৰৰ ভিতৰৰ স্মৃতি
    (D) a printed backup ছপা বেকআপ
    Answer: A) files kept on remote servers and reached over the internet
    A) দূৰৰ ছাৰ্ভাৰত ৰখা ফাইল যি ইণ্টাৰনেটেৰে পোৱা যায়
    Explanation: Cloud storage puts your data on someone else's servers, so you need a network to reach it. Local drives need no network.
    ক্লাউড সঞ্চয়ে আপোনাৰ তথ্য আনৰ ছাৰ্ভাৰত ৰাখে, সেয়ে নেটৱৰ্ক লাগে। স্থানীয় ড্ৰাইভলৈ নেটৱৰ্ক নালাগে।
    Q26. A bug in a program is
    প্ৰগ্ৰামত থকা বাগ হ'ল
    (A) an error that causes wrong or unexpected behaviour এটা ভুল যি অসত্য বা অপ্ৰত্যাশিত আচৰণ ঘটায়
    (B) a virus that spreads between machines যন্ত্ৰৰ মাজত বিয়পা ভাইৰাছ
    (C) a hardware connector হাৰ্ডৱেৰ সংযোগক
    (D) a type of file format এবিধ ফাইল ফৰ্মেট
    Answer: A) an error that causes wrong or unexpected behaviour
    A) এটা ভুল যি অসত্য বা অপ্ৰত্যাশিত আচৰণ ঘটায়
    Explanation: A bug is a defect in the code itself. A virus is separate malicious software that may exploit such defects.
    বাগ ক'ডৰ নিজৰ ত্ৰুটি। ভাইৰাছ বেলেগ ক্ষতিকাৰক ছফ্টৱেৰ যি এনে ত্ৰুটি ব্যৱহাৰ কৰিব পাৰে।
    Q27. Which of the following is the correct order of the data size units from smallest to largest?
    তথ্যৰ একক সৰুৰপৰা ডাঙৰলৈ তলৰ কোনটো শুদ্ধ ক্ৰম
    (A) bit, byte, kilobyte, megabyte, gigabyte বিট, বাইট, কিল'বাইট, মেগাবাইট, গিগাবাইট
    (B) byte, bit, megabyte, kilobyte, gigabyte বাইট, বিট, মেগাবাইট, কিল'বাইট, গিগাবাইট
    (C) bit, byte, megabyte, kilobyte, gigabyte বিট, বাইট, মেগাবাইট, কিল'বাইট, গিগাবাইট
    (D) kilobyte, bit, byte, megabyte, gigabyte কিল'বাইট, বিট, বাইট, মেগাবাইট, গিগাবাইট
    Answer: A) bit, byte, kilobyte, megabyte, gigabyte
    A) বিট, বাইট, কিল'বাইট, মেগাবাইট, গিগাবাইট
    Explanation: Eight bits make a byte, then each step multiplies by 1024 through kilo, mega and giga. Any other order misplaces a unit.
    আঠ বিটত এক বাইট, তাৰ পিছত কিল', মেগা, গিগা প্ৰতিটো খোজত ১০২৪ গুণ। আন ক্ৰমত একক ঠাই সলনি হয়।
    Q28. Which of the following is an example of a graphic output device?
    তলৰ কোনটো গ্ৰাফিক আউটপুট সজুলিৰ উদাহৰণ
    (A) monitor মনিটৰ
    (B) keyboard কীবৰ্ড
    (C) joystick জয়ষ্টিক
    (D) microphone মাইক্ৰ'ফোন
    Answer: A) monitor
    A) মনিটৰ
    Explanation: A monitor displays images and text, so it outputs graphics. The others are all input devices.
    মনিটৰে ছবি আৰু লিখা দেখুৱায়, সেয়ে ই গ্ৰাফিক আউটপুট। বাকীবোৰ ইনপুট সজুলি।
    Q29. The main advantage of solid state storage over a hard disk is
    হাৰ্ড ডিস্কতকৈ কঠিন অৱস্থা সঞ্চয়ৰ মূল সুবিধা
    (A) faster access with no moving parts চলন্ত অংশ নথকা বাবে দ্ৰুত প্ৰৱেশ
    (B) much lower cost per gigabyte প্ৰতি গিগাবাইটত বহু কম দাম
    (C) larger capacity always সদায় বেছি ধাৰণক্ষমতা
    (D) it needs no power ই বিদ্যুৎ নালাগে
    Answer: A) faster access with no moving parts
    A) চলন্ত অংশ নথকা বাবে দ্ৰুত প্ৰৱেশ
    Explanation: With no platters to spin up, an SSD answers in microseconds. Hard disks still win on price per gigabyte.
    ঘূৰাবলগীয়া প্লেটাৰ নথকা বাবে SSD এ মাইক্ৰ'ছেকেণ্ডত উত্তৰ দিয়ে। দামত হাৰ্ড ডিস্ক এতিয়াও আগত।
    Q30. An operating system that allows more than one user to work at the same time is called
    এসময়ত এজনৰ অধিক ব্যৱহাৰকাৰীক কাম কৰিব দিয়া অপাৰেটিং চিষ্টেমক কি বোলা হয়
    (A) multi-user বহু-ব্যৱহাৰকাৰী
    (B) single-user এক-ব্যৱহাৰকাৰী
    (C) real-time ৰিয়েল-টাইম
    (D) embedded এম্বেডেড
    Answer: A) multi-user
    A) বহু-ব্যৱহাৰকাৰী
    Explanation: A multi-user system shares the processor among several logged-in users, as a server does. A single-user system serves one.
    বহু-ব্যৱহাৰকাৰী চিষ্টেমে কেইবাজন লগইন কৰা ব্যৱহাৰকাৰীৰ মাজত প্ৰচেছৰ ভাগ কৰে, ছাৰ্ভাৰে যেনে কৰে। এক-ব্যৱহাৰকাৰীয়ে এজনক দিয়ে।
