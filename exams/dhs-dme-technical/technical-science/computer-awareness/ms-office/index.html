    (B) Ctrl + X
    (C) Ctrl + S

    সংখ্যা বিন্যাসে সাঁচি ৰখা মান কেনেকৈ দেখুৱাব লাগে নিয়ন্ত্ৰণ কৰে, সেয়ে তথ্য নসলোৱাকৈ দশমিক আৰু বিভাজক ওলায়। পুনৰ লিখিলে সংখ্যা পাঠলৈ সলনি হয়, আৰু গাঢ় ফণ্ট বা বহল স্তম্ভই কেৱল ৰূপ সলায়।
    Q50. A user must protect a shared Excel file so that only certain cells can be edited. The correct sequence is to
    ব্যৱহাৰকাৰীয়ে ভগা এক্সেল ফাইল সুৰক্ষিত কৰি কেৱল নিৰ্দিষ্ট ঘৰত সম্পাদনা কৰিব পৰাকৈ ৰাখিব লাগে। শুদ্ধ ক্ৰম
    (A) unlock the editable cells first, then protect the sheet প্ৰথমে সম্পাদনযোগ্য ঘৰবোৰ খুলি তাৰ পিছত শীট সুৰক্ষিত কৰা
    (B) protect the sheet first, then unlock the cells প্ৰথমে শীট সুৰক্ষিত কৰি তাৰ পিছত ঘৰ খোলা
    (C) hide the sheet and share the file শীট লুকুৱাই ফাইল ভগ কৰা
    (D) password protect the whole workbook only কেৱল গোটেই ৱৰ্কবুক পাছৱৰ্ডেৰে সুৰক্ষিত কৰা
    Answer: A) unlock the editable cells first, then protect the sheet
    A) প্ৰথমে সম্পাদনযোগ্য ঘৰবোৰ খুলি তাৰ পিছত শীট সুৰক্ষিত কৰা
    Explanation: Cells are locked by default, so the editable ones must be unlocked before protection takes effect, otherwise the whole sheet is frozen. Doing it in the reverse order locks everything, hiding removes access and workbook protection does not distinguish cells.
    ঘৰবোৰ সাধাৰণতে বন্ধ থাকে, সেয়ে সুৰক্ষা কাৰ্যকৰী হোৱাৰ আগতে সম্পাদনযোগ্যবোৰ খুলিব লাগে, নহ'লে গোটেই শীট আঁটি যায়। উলটি ক্ৰমে সকলো বন্ধ কৰে, লুকুওৱাই প্ৰৱেশ আঁতৰায় আৰু ৱৰ্কবুক সুৰক্ষাই ঘৰ পৃথক নকৰে।
