    (A) .xlsx
    (B) .docx
    (C) .pptx
    (D) .mdb
    Answer: A) .xlsx
    Explanation: Excel workbooks use xlsx. Word documents use docx and PowerPoint shows use pptx.
    এক্সেল কৰ্কবুক .xlsx ব্যৱহাৰ কৰে। ৱৰ্ড ডকুমেণ্ট .docx আৰু পাৱাৰপইণ্ট .pptx।
    Q2. The keyboard shortcut to save a document in MS Word is
    MS ৱৰ্ডত ডকুমেণ্ট সঞ্চয় কৰাৰ কীবৰ্ড চৰ্টকাট
    (A) Ctrl + S
    (B) Ctrl + P
    (C) Ctrl + V
    (D) Ctrl + X
    Answer: A) Ctrl + S
    Explanation: Ctrl + S saves, Ctrl + P prints, Ctrl + V pastes and Ctrl + X cuts. Confusing S with P is the common slip.
    Ctrl + S এ সঞ্চয়, Ctrl + P এ প্ৰিণ্ট, Ctrl + V এ পেষ্ট আৰু Ctrl + X এ কাটে। S আৰু P মিলাই পেলোৱা সাধাৰণ ভুল।
    Q3. In MS Excel, the cell reference A1 refers to
    MS এক্সেলত A1 কোষ নিৰ্দেশে বুজায়
    (A) column A and row 1 স্তম্ভ A আৰু শাৰী ১
    (B) row A and column 1 শাৰী A আৰু স্তম্ভ ১
    (C) sheet A and cell 1 শ্বীট A আৰু কোষ ১
    (D) range A to 1 A ৰপৰা 1 লৈ পৰিসৰ
    Answer: A) column A and row 1
    A) স্তম্ভ A আৰু শাৰী ১
    Explanation: Excel names cells by column letter first and row number second, so A1 is the top left cell. Reversing them is the usual error.
    এক্সেলে কোষৰ নামত প্ৰথমে স্তম্ভৰ আখৰ আৰু পিছত শাৰীৰ সংখ্যা দিয়ে, সেয়ে A1 ওপৰ বাওঁৰ কোষ। ওলোটা কৰাটো সাধাৰণ ভুল।
    Q4. Which function in MS Excel adds a range of numbers?
    MS এক্সেলত সংখ্যাৰ পৰিসৰ যোগ কৰা ফলনটো
    (A) SUM
    (B) COUNT
    (C) AVERAGE
    (D) MAX
    Answer: A) SUM
    Explanation: SUM totals the values. COUNT counts how many there are, AVERAGE gives the mean and MAX the largest.
    SUM এ যোগফল দিয়ে। COUNT এ কিমানটা গণে, AVERAGE এ গড় আৰু MAX এ আটাই ডাঙৰ।

    (C) Slide Sorter শ্লাইড ছৰ্টাৰ
    (D) Notes Page নোটছ পেজ
    Answer: A) Slide Show
    A) শ্লাইড শ্ব'
    Explanation: Slide Show fills the screen and runs the presentation. Slide Sorter only rearranges thumbnails.
    শ্লাইড শ্ব'ই পৰ্দা ভৰাই প্ৰেজেণ্টেশ্যন চলায়। শ্লাইড ছৰ্টাৰে কেবল থাম্বনেইল সজায়।
    Q6. The default file extension of a MS Word document is

    (A) .docx
    (B) .txt
    (C) .xls
    (D) .rtf
    Answer: A) .docx
    Explanation: Modern Word saves in docx, the XML based format. Plain text and rich text formats lose most formatting.
    আধুনিক ৱৰ্ডে docx ত সঞ্চয় কৰে, যি XML ভিত্তিক। সাধাৰণ লিখা আৰু RTF এ বেছিভাগ ৰূপান্তৰ হেৰুৱায়।

    (C) PowerPoint পাৱাৰপইণ্ট
    (D) Outlook আউটলুক
    Answer: A) Excel
    A) এক্সেল
    Explanation: Excel holds figures in cells and recalculates totals automatically, which suits budgets. Word is for prose.
    এক্সেলে কোষত সংখ্যা ৰাখি যোগফল নিজে পুনৰ গণে, সেয়ে বাজেটৰ বাবে উপযুক্ত। ৱৰ্ড গদ্যৰ বাবে।
    Q8. In MS Word, the shortcut Ctrl + Z is used to

    (C) zoom the page পৃষ্ঠা জুম কৰিবলৈ

    Answer: A) text, numbers or formulas
    A) লিখা, সংখ্যা বা সূত্ৰ

    Q11. The shortcut Ctrl + C is used to

    A) সমান চিন

    প্ৰতিটো সূত্ৰ সমান চিনেৰে আৰম্ভ হয়, যিয়ে এক্সেলক লিখা নহয় গণনা কৰিবলৈ কয়। নহ'লে লিখা হিচাপেই থাকে।

    MS পাৱাৰপইণ্টত ট্ৰেনজিশ্যন প্ৰভাৱ কিৰ ওপৰত প্ৰয়োগ হয়
    (A) the change from one slide to the next এটা শ্লাইডৰপৰা পৰৱৰ্তী শ্লাইডলৈ পৰিৱৰ্তনত
    (B) the text inside one slide এটা শ্লাইডৰ ভিতৰৰ লিখাত
    (C) the slide background only কেৱল শ্লাইডৰ পৃষ্ঠভূমিত
    (D) the printed handout ছপা হেণ্ডআউটত
    Answer: A) the change from one slide to the next
    A) এটা শ্লাইডৰপৰা পৰৱৰ্তী শ্লাইডলৈ পৰিৱৰ্তনত
    Explanation: Transitions act between slides, while animations act on objects within a slide. Mixing the two is a common error.
    ট্ৰেনজিশ্যন শ্লাইডৰ মাজত ক্ৰিয়া কৰে, এনিমেশ্যনে এটা শ্লাইডৰ ভিতৰৰ বস্তুত। দুয়োটা মিলাই পেলোৱাটো সাধাৰণ ভুল।
    Q24. Which of the following is a spreadsheet formula that would give the largest value in the range A1 to A10?
    A1 ৰপৰা A10 পৰিসৰৰ আটাই ডাঙৰ মান দিয়া স্প্ৰেডশ্বীট সূত্ৰটো
    (A) =MAX(A1:A10)
    (B) =MIN(A1:A10)
    (C) =SUM(A1:A10)
    (D) =COUNT(A1:A10)
    Answer: A) =MAX(A1:A10)
    Explanation: MAX returns the largest. MIN gives the smallest, SUM the total and COUNT how many numbers there are.
    MAX এ আটাই ডাঙৰ দিয়ে। MIN এ আটাই সৰু, SUM এ যোগফল আৰু COUNT এ সংখ্যা কিমানটা।
    Q25. In MS Word, the header appears
    MS ৱৰ্ডত হেডাৰ দেখা যায়
    (A) at the top of every page প্ৰতিটো পৃষ্ঠাৰ ওপৰত
    (B) at the bottom of every page প্ৰতিটো পৃষ্ঠাৰ তলত
    (C) only on the first page কেৱল প্ৰথম পৃষ্ঠাত
    (D) inside the footnote area পাদটীকাৰ ঠাইত
    Answer: A) at the top of every page
    A) প্ৰতিটো পৃষ্ঠাৰ ওপৰত
    Explanation: The header repeats at the top of each page and the footer at the bottom, which is how page numbers are added.
    হেডাৰ প্ৰতিটো পৃষ্ঠাৰ ওপৰত আৰু ফুটাৰ তলত পুনৰায় আহে, সেয়ে পৃষ্ঠা সংখ্যা দিয়া হয়।
    Q26. The MS Excel feature that displays only the rows matching a condition is
    শৰ্ত পূৰণ কৰা শাৰীবোৰ কেবল দেখুওৱা MS এক্সেল সুবিধাটো
    (A) filter ফিল্টাৰ
    (B) sort ছৰ্ট
    (C) freeze panes ফ্ৰীজ পেন
    (D) merge cells মাৰ্জ ছেল
    Answer: A) filter
    A) ফিল্টাৰ
    Explanation: Filtering hides rows that do not match, while sorting reorders all rows. Freezing panes only fixes headings on screen.
    ফিল্টাৰে নমিলা শাৰী লুকুৱায়, ছৰ্টে সকলো শাৰী সজায়। ফ্ৰীজ পেনে কেবল শিৰোনামা পৰ্দাত স্থিৰ ৰাখে।
    Q27. Which of the following is the correct way to start a new line inside the same paragraph in MS Word?
    MS ৱৰ্ডত একেই অনুচ্ছেদৰ ভিতৰত নতুন শাৰী আৰম্ভ কৰাৰ শুদ্ধ উপায়
    (A) Shift + Enter
    (B) Enter
    (C) Ctrl + Enter
    (D) Alt + Enter
    Answer: A) Shift + Enter
    Explanation: Shift + Enter inserts a line break without ending the paragraph. Enter alone starts a new paragraph.
    Shift + Enter এ অনুচ্ছেদ নটুটি নতুন শাৰী দিয়ে। অকলৈ Enter এ নতুন অনুচ্ছেদ আৰম্ভ কৰে।
    Q28. In MS PowerPoint, the notes pane is used to
    MS পাৱাৰপইণ্টত নোটছ পেন কিৰ বাবে ব্যৱহৃত হয়
    (A) write speaker notes not shown to the audience দৰ্শকক নেদেখুৱা বক্তাৰ টোকা লিখিবলৈ
    (B) add animation to objects বস্তুত এনিমেশ্যন যোগ কৰিবলৈ
    (C) change the slide size শ্লাইডৰ আকাৰ সলাবলৈ
    (D) insert a chart চাৰ্ট সুমুৱাবলৈ
    Answer: A) write speaker notes not shown to the audience
    A) দৰ্শকক নেদেখুৱা বক্তাৰ টোকা লিখিবলৈ
    Explanation: Notes stay with the slide but appear only in presenter view or printed notes, so they help the speaker.
    টোকা শ্লাইডৰ সৈতে থাকে কিন্তু কেবল প্ৰেজেণ্টাৰ ভিউ বা ছপা টোকাত ওলায়, সেয়ে বক্তাক সহায় কৰে।
    Q29. Which MS Office tool would you use to create a formal invitation card?
    আনুষ্ঠানিক নিমন্ত্ৰণ পত্ৰ বনাবলৈ কোন MS Office সজুলি ব্যৱহাৰ কৰিব
    (A) Publisher পাব্লিছাৰ
    (B) Excel এক্সেল
    (C) Access এক্সেছ
    (D) Outlook আউটলুক
    Answer: A) Publisher
    A) পাব্লিছাৰ
    Explanation: Publisher is built for page layout and print design. Excel and Access handle numbers and records.
    পাব্লিছাৰ পৃষ্ঠা সজ্জা আৰু ছপা ডিজাইনৰ বাবে বনোৱা। এক্সেল আৰু এক্সেছে সংখ্যা আৰু অভিলেখ চম্ভালে।
    Q30. In MS Word, pressing Ctrl + E will
    MS ৱৰ্ডত Ctrl + E টিপিলে
    (A) centre the selected paragraph বাছনি কৰা অনুচ্ছেদ কেন্দ্ৰত ৰাখে
    (B) make the text bold লিখা ডাঠ কৰে
    (C) exit the program প্ৰগ্ৰামৰপৰা ওলায়
    (D) open a new window নতুন উইণ্ড' খোলে
    Answer: A) centre the selected paragraph
    A) বাছনি কৰা অনুচ্ছেদ কেন্দ্ৰত ৰাখে
    Explanation: Ctrl + E centres, Ctrl + B bolds and Ctrl + L aligns left. Ctrl + E does not close anything.
    Ctrl + E এ কেন্দ্ৰত, Ctrl + B এ ডাঠ আৰু Ctrl + L এ বাওঁফালে ৰাখে। Ctrl + E এ একো বন্ধ নহয়।
