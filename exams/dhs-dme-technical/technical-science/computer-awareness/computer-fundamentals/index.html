    Q1. The part of a computer that performs arithmetic and logical operations is the
    কম্পিউটাৰৰ যি অংশই গাণিতিক আৰু যুক্তিমূলক কাম কৰে তাক কি বোলা হয়
    (A) control unit নিয়ন্ত্ৰণ ইউনিট
    (B) memory unit স্মৃতি ইউনিট
    (C) input unit ইনপুট ইউনিট
    (D) ALU
    Answer: D) ALU
    Explanation: The arithmetic logic unit carries out addition, subtraction and comparisons. The control unit only directs traffic between the parts.
    অংকীয় যুক্তি ইউনিটে যোগ, বিয়োগ আৰু তুলনা কৰে। নিয়ন্ত্ৰণ ইউনিটে কেবল অংশবোৰৰ মাজত কাম চলায়।
    Q2. Which generation of computers used integrated circuits?
    কম্পিউটাৰৰ কোন প্ৰজন্মই সমন্বিত বৰ্তনী ব্যৱহাৰ কৰিছিল
    (A) second generation দ্বিতীয় প্ৰজন্ম
    (B) fifth generation পঞ্চম প্ৰজন্ম
    (C) third generation তৃতীয় প্ৰজন্ম
    (D) first generation প্ৰথম প্ৰজন্ম
    Answer: C) third generation
    C) তৃতীয় প্ৰজন্ম
    Explanation: Third generation machines replaced transistors with integrated circuits. The first used valves and the second used discrete transistors.
    তৃতীয় প্ৰজন্মই ট্ৰান্সিষ্টৰৰ সলনি সমন্বিত বৰ্তনী দিলে। প্ৰথমে ভেল্ভ আৰু দ্বিতীয়ই সুকীয়া ট্ৰান্সিষ্টৰ ব্যৱহাৰ কৰিছিল।
    Q3. One kilobyte is equal to
    এক কিল'বাইট কিৰ সমান
    (A) 512 bytes ৫১২ বাইট
    (B) 1024 bytes ১০২৪ বাইট
    (C) 1000 bytes ১০০০ বাইট
    (D) 1024 bits ১০২৪ বিট
    Answer: B) 1024 bytes
    B) ১০২৪ বাইট
    Explanation: Memory is counted in powers of two, so a kilobyte is two to the tenth, that is 1024 bytes. Decimal 1000 is used only by disk makers.
    স্মৃতি দুইৰ ঘাতত গণা হয়, সেয়ে এক কিল'বাইট = ২ ৰ ঘাত ১০ = ১০২৪ বাইট। ১০০০ কেবল ডিস্ক প্ৰস্তুতকাৰীয়ে ব্যৱহাৰ কৰে।
    Q4. The brain of a computer is the
    কম্পিউটাৰৰ মগজু হ'ল
    (A) CPU
    (B) monitor মনিটৰ
    (C) keyboard কীবৰ্ড
    (D) hard disk হাৰ্ড ডিস্ক
    Answer: A) CPU
    Explanation: The central processing unit fetches, decodes and executes every instruction, so it is called the brain. The others are input or storage devices.
    কেন্দ্ৰীয় প্ৰচেছিং ইউনিটে প্ৰতিটো নিৰ্দেশ লৈ, বুজি কাৰ্যকৰী কৰে, সেয়ে ইয়াক মগজু বোলা হয়। বাকীবোৰ ইনপুট বা সঞ্চয় সজুলি।
    Q5. Which of the following is an output device?
    তলৰ কোনটো আউটপুট সজুলি
    (A) scanner স্কেনাৰ
    (B) mouse মাউছ
    (C) light pen লাইট পেন
    (D) plotter প্লটাৰ
    Answer: D) plotter
    D) প্লটাৰ
    Explanation: A plotter draws large technical drawings on paper, so it outputs. Scanner, mouse and light pen all send data into the computer.
    প্লটাৰে কাগজত ডাঙৰ নক্সা আঁকে, সেয়ে ই আউটপুট। স্কেনাৰ, মাউছ আৰু লাইট পেনে তথ্য কম্পিউটাৰলৈ পঠিয়ায়।
    Q6. The first electronic digital computer was
    প্ৰথম ইলেক্ট্ৰনিক ডিজিটেল কম্পিউটাৰ আছিল
    (A) IBM 360
    (B) Altair আল্টেয়াৰ
    (C) ENIAC
    (D) UNIVAC
    Answer: C) ENIAC
    Explanation: ENIAC, completed in 1946, was the first general-purpose electronic digital computer. UNIVAC came later as a commercial machine.
    ১৯৪৬ চনত সম্পূৰ্ণ ENIAC প্ৰথম সাধাৰণ উদ্দেশ্যৰ ইলেক্ট্ৰনিক ডিজিটেল কম্পিউটাৰ আছিল। UNIVAC পিছত বাণিজ্যিক ৰূপে আহিল।
    Q7. The number of bits in one byte is
    এক বাইটত থকা বিটৰ সংখ্যা
    (A) 2 ২
    (B) 8 ৮
    (C) 4 ৪
    (D) 16 ১৬
    Answer: B) 8
    B) ৮
    Explanation: A byte holds eight bits, enough to store one character. Four bits is a nibble and sixteen bits is a word on older machines.
    এক বাইটত আঠ বিট থাকে, যি এটা আখৰ ৰাখিবলৈ যথেষ্ট। চাৰি বিট নিবল আৰু ষোল্ল বিট পুৰণি যন্ত্ৰৰ শব্দ।
    Q8. Which memory is volatile, losing its contents when power is switched off?
    কোন স্মৃতি অস্থিৰ, বিদ্যুৎ বন্ধ হ'লে তথ্য হেৰুৱায়
    (A) RAM
    (B) ROM
    (C) hard disk হাৰ্ড ডিস্ক
    (D) pen drive পেন ড্ৰাইভ
    Answer: A) RAM
    Explanation: RAM needs constant power to hold its charge, so a shutdown clears it. ROM and storage devices keep their contents without power.
    RAM এ আধান ধৰি ৰাখিবলৈ নিৰন্তৰ বিদ্যুৎ লাগে, সেয়ে বন্ধ কৰিলে মচি যায়। ROM আৰু সঞ্চয় সজুলিয়ে বিদ্যুৎ নোহোৱাকৈও ৰাখে।
    Q9. The speed of a processor is measured in
    প্ৰচেছৰৰ গতি কিৰে জোখা হয়
    (A) gigabyte গিগাবাইট
    (B) megapixel মেগাপিক্সেল
    (C) decibel ডেচিবেল
    (D) gigahertz গিগাহাৰ্টজ
    Answer: D) gigahertz
    D) গিগাহাৰ্টজ
    Explanation: Clock speed counts cycles per second, so it is quoted in gigahertz. Gigabyte measures storage and megapixel measures camera resolution.
    ঘড়ীৰ গতি প্ৰতি ছেকেণ্ডত চক্ৰ গণে, সেয়ে গিগাহাৰ্টজত দিয়া হয়। গিগাবাইটে সঞ্চয় আৰু মেগাপিক্সেলে কেমেৰাৰ ৰিজ'লিউশন জোখে।
    Q10. Which of the following is system software?
    তলৰ কোনটো চিষ্টেম ছফ্টৱেৰ
    (A) web browser ৱেব ব্ৰাউজাৰ
    (B) photo editor ফটো এডিটৰ
    (C) operating system অপাৰেটিং চিষ্টেম
    (D) spreadsheet স্প্ৰেডশ্বীট
    Answer: C) operating system
    C) অপাৰেটিং চিষ্টেম
    Explanation: The operating system manages hardware and runs other programs, so it is system software. The rest are application software.
    অপাৰেটিং চিষ্টেমে হাৰ্ডৱেৰ চলাই আন প্ৰগ্ৰাম সক্ৰিয় কৰে, সেয়ে ই চিষ্টেম ছফ্টৱেৰ। বাকীবোৰ এপ্লিকেশ্যন ছফ্টৱেৰ।
    Q11. The base of the binary number system is
    দ্বিমিক সংখ্যা পদ্ধতিৰ ভিত্তি
    (A) 16 ১৬
    (B) 2 ২
    (C) 8 ৮
    (D) 10 ১০
    Answer: B) 2
    B) ২
    Explanation: Binary uses only the digits zero and one, so its base is two. Base eight is octal and base sixteen is hexadecimal.
    দ্বিমিকে কেবল শূন্য আৰু এক ব্যৱহাৰ কৰে, সেয়ে ভিত্তি দুই। ভিত্তি আঠ অষ্টাল আৰু ভিত্তি ষোল্ল হেক্সাডেচিমেল।
    Q12. Which of the following is the fastest memory?
    তলৰ কোনটো আটাই দ্ৰুত স্মৃতি
    (A) cache memory কেশ্ব স্মৃতি
    (B) main memory মূল স্মৃতি
    (C) hard disk হাৰ্ড ডিস্ক
    (D) magnetic tape চুম্বকীয় টেপ
    Answer: A) cache memory
    A) কেশ্ব স্মৃতি
    Explanation: Cache sits on or beside the processor and serves it in a few cycles. Hard disks and tapes are thousands of times slower.
    কেশ্ব প্ৰচেছৰৰ ওপৰত বা কাষত থাকে আৰু কেইচক্ৰতেই তথ্য দিয়ে। হাৰ্ড ডিস্ক আৰু টেপ হাজাৰ গুণ ধীৰ।
    Q13. The full form of ROM is
    ROM ৰ সম্পূৰ্ণ ৰূপ
    (A) Random Only Memory
    (B) Read Open Memory
    (C) Rapid Output Memory
    (D) Read Only Memory
    Answer: D) Read Only Memory
    Explanation: Read only memory is written at manufacture and normally only read. RAM, by contrast, is read and written freely.
    Read Only Memory নিৰ্মাণতে লিখা হয় আৰু সাধাৰণতে কেবল পঢ়া হয়। RAM কিন্তু মুক্তভাৱে পঢ়া আৰু লিখা যায়।
    Q14. A computer virus is
    কম্পিউটাৰ ভাইৰাছ হ'ল
    (A) a type of hardware এবিধ হাৰ্ডৱেৰ
    (B) a cooling fan এটা শীতলক ফেন
    (C) a program that copies itself and damages files এটা প্ৰগ্ৰাম যি নিজকে নকল কৰি ফাইল নষ্ট কৰে
    (D) a fault in the monitor মনিটৰৰ ত্ৰুটি
    Answer: C) a program that copies itself and damages files
    C) এটা প্ৰগ্ৰাম যি নিজকে নকল কৰি ফাইল নষ্ট কৰে
    Explanation: A virus is executable code that attaches itself to files and spreads. It is software, not a physical fault.
    ভাইৰাছ হ'ল চলনশীল ক'ড যি ফাইলত লাগি বিয়পে। ই ছফ্টৱেৰ, শাৰীৰিক ত্ৰুটি নহয়।
    Q15. The device that converts hard copy into digital form is a
    কঠিন কপিক ডিজিটেল ৰূপলৈ সলনি কৰা সজুলিটো
    (A) speaker স্পীকাৰ
    (B) scanner স্কেনাৰ
    (C) plotter প্লটাৰ
    (D) printer প্ৰিণ্টাৰ
    Answer: B) scanner
    B) স্কেনাৰ
    Explanation: A scanner reads a printed page and stores it as an image. Printers and plotters go the other way, from digital to paper.
    স্কেনাৰে ছপা পৃষ্ঠা পঢ়ি ছবি হিচাপে ৰাখে। প্ৰিণ্টাৰ আৰু প্লটাৰে ওলোটা কৰে, ডিজিটেলৰপৰা কাগজলৈ।
    Q16. Which of the following is an example of a non-volatile memory?
    তলৰ কোনটো অস্থিৰ নোহোৱা স্মৃতিৰ উদাহৰণ
    (A) flash memory ফ্লেশ্ব স্মৃতি
    (B) DRAM
    (C) SRAM
    (D) register ৰেজিষ্টাৰ
    Answer: A) flash memory
    A) ফ্লেশ্ব স্মৃতি
    Explanation: Flash memory keeps its data without power, which is why pen drives and memory cards work. DRAM, SRAM and registers all lose data.
    ফ্লেশ্ব স্মৃতি বিদ্যুৎ নোহোৱাকৈও তথ্য ৰাখে, সেয়ে পেন ড্ৰাইভ আৰু মেম'ৰি কাৰ্ড চলে। DRAM, SRAM আৰু ৰেজিষ্টাৰে তথ্য হেৰুৱায়।
    Q17. The process of starting a computer and loading the operating system is called
    কম্পিউটাৰ আৰম্ভ কৰি অপাৰেটিং চিষ্টেম লোড কৰা প্ৰক্ৰিয়াক কি বোলা হয়
    (A) browsing ব্ৰাউজিং
    (B) batching বেটচিং
    (C) buffering বাফাৰিং
    (D) booting বুটিং
    Answer: D) booting
    D) বুটিং
    Explanation: Booting runs the firmware, tests the hardware and hands control to the operating system. Browsing is reading web pages.
    বুটিঙে ফাৰ্মৱেৰ চলায়, হাৰ্ডৱেৰ পৰীক্ষা কৰি নিয়ন্ত্ৰণ অপাৰেটিং চিষ্টেমলৈ দিয়ে। ব্ৰাউজিঙে ৱেব পৃষ্ঠা পঢ়ে।
    Q18. The number of bits a processor can handle at one time is its
    প্ৰচেছৰে এসময়ত কিমান বিট চম্ভালিব পাৰে সেয়া তাৰ
    (A) bus width only কেৱল বাছ প্ৰস্থ
    (B) cache size কেশ্ব আকাৰ
    (C) word length শব্দ দৈৰ্ঘ্য
    (D) clock speed ঘড়ীৰ গতি
    Answer: C) word length
    C) শব্দ দৈৰ্ঘ্য
    Explanation: Word length describes how many bits move together through the processor, as in a 32-bit or 64-bit machine. Clock speed is cycles per second.
    শব্দ দৈৰ্ঘ্যই প্ৰচেছৰৰ মাজেৰে একেলগে যোৱা বিটৰ সংখ্যা বুজায়, যেনে ৩২-বিট বা ৬৪-বিট। ঘড়ীৰ গতি প্ৰতি ছেকেণ্ডত চক্ৰ।
    Q19. Which of the following stores the largest amount of data?
    তলৰ কোনটোত আটাই বেছি তথ্য ৰখা যায়
    (A) kilobyte কিল'বাইট
    (B) terabyte টাৰাবাইট
    (C) megabyte মেগাবাইট
    (D) gigabyte গিগাবাইট
    Answer: B) terabyte
    B) টাৰাবাইট
    Explanation: A terabyte is about a thousand gigabytes, so it is the largest of these. The order from small to large is kilo, mega, giga, tera.
    এক টাৰাবাইট প্ৰায় এহাজাৰ গিগাবাইট, সেয়ে ইহঁতৰ ভিতৰত আটাই ডাঙৰ। সৰুৰপৰা ডাঙৰলৈ ক্ৰম কিল', মেগা, গিগা, টেৰা।
    Q20. An example of an input device that reads marks on an answer sheet is an
    উত্তৰপত্ৰৰ দাগ পঢ়া ইনপুট সজুলি এটাৰ উদাহৰণ
    (A) OMR
    (B) OCR
    (C) MICR
    (D) LCD
    Answer: A) OMR
    Explanation: Optical mark recognition senses darkened bubbles, which is how objective tests are scored. OCR reads printed characters and MICR reads cheque codes.
    OMR এ ক'লা কৰা বৃত্ত চিনি লয়, সেয়ে বস্তুনিষ্ঠ পৰীক্ষা জোখা হয়। OCR এ ছপা আখৰ আৰু MICR এ চেকৰ ক'ড পঢ়ে।
    Q21. The unit that coordinates and controls all parts of a computer is the
    কম্পিউটাৰৰ সকলো অংশ সমন্বয় আৰু নিয়ন্ত্ৰণ কৰা ইউনিটটো
    (A) arithmetic logic unit অংকীয় যুক্তি ইউনিট
    (B) memory unit স্মৃতি ইউনিট
    (C) output unit আউটপুট ইউনিট
    (D) control unit নিয়ন্ত্ৰণ ইউনিট
    Answer: D) control unit
    D) নিয়ন্ত্ৰণ ইউনিট
    Explanation: The control unit reads each instruction and signals the other units in the right order. The ALU only does the arithmetic itself.
    নিয়ন্ত্ৰণ ইউনিটে প্ৰতিটো নিৰ্দেশ পঢ়ি শুদ্ধ ক্ৰমত আন ইউনিটলৈ সংকেত দিয়ে। ALU এ কেবল অংক কৰে।

    (A) machine language যন্ত্ৰ ভাষা
    (B) microcode মাইক্ৰ'ক'ড
    (C) Python পাইথন
    (D) assembly language এচেম্বলি ভাষা

    Computer Fundamentals: study notes

    Read this before you attempt the questions. It is written for the DHS & DME Technical Grade III paper.

    What the computer fundamentals block asks

    This topic covers the machine itself: what a computer is, what its parts are called, what the units of memory mean, how data is represented, and who invented what. The questions are almost all one-line facts, and they are asked in the same form every year - which unit is largest, which device is input, which generation used which technology, which abbreviation stands for what.

    The block is easy to secure because the facts do not change. An hour with the four lists in this article - units, input and output devices, generations, and abbreviations - covers most of the questions the paper can set from this topic.

    What a computer is, and the four functions

    A computer is an electronic device that accepts data, processes it according to a set of instructions, stores the result and outputs it. Those four functions - input, processing, storage and output - are the skeleton of every question about hardware. A keyboard, mouse, scanner, microphone, joystick, light pen, touch screen and barcode reader are input devices. A monitor, printer, speaker, plotter and projector are output devices. A modem, a touch screen and a pen drive that both reads and writes can act in both directions.

    The processing unit is the CPU, and it has three parts: the arithmetic logic unit that does the calculations, the control unit that directs the flow of instructions, and registers that hold the current data. Memory is either primary or secondary. Primary memory is directly accessible to the CPU and is of two kinds: RAM, which is volatile and loses its contents when power goes, and ROM, which is non-volatile and holds the start-up instructions. Secondary memory - hard disk, SSD, pen drive, CD, DVD - is permanent but slower.

    The units of memory, in order

    The order is bit, byte, kilobyte, megabyte, gigabyte, terabyte, petabyte. One byte is eight bits and normally holds one character. One kilobyte is 1,024 bytes, one megabyte is 1,024 kilobytes, one gigabyte is 1,024 megabytes, and one terabyte is 1,024 gigabytes. The 1,024 rather than 1,000 is because memory is organised in powers of two, and a question that uses 1,000 is testing whether you know that.

    Speed is measured separately. The clock speed of a processor is in gigahertz, and one gigahertz is a thousand million cycles per second. A hard disk is measured in revolutions per minute and in access time, and a printer in pages per minute and in dots per inch, which is resolution. These units are asked as matches and they are free marks.

    The generations, and what each one introduced

    The first generation used vacuum tubes, was enormous, and was programmed in machine language. The second used transistors and introduced assembly language. The third used integrated circuits and introduced operating systems and keyboards with monitors. The fourth used microprocessors and brought the personal computer, the graphical user interface and networks. The fifth, still current, is associated with artificial intelligence, parallel processing and natural language.

    A few firsts are worth knowing by name. Charles Babbage designed the analytical engine and is called the father of the computer. Ada Lovelace wrote what is regarded as the first program. John von Neumann described the stored-program architecture that every modern computer still follows. ENIAC was the first general-purpose electronic computer. The transistor was invented at Bell Laboratories, and the integrated circuit followed a decade later.

    Software, and the words that go with it

    Software is of two kinds. System software runs the machine - the operating system, device drivers and utility programs. Application software does the user's work - a word processor, a spreadsheet, a browser, a media player. An operating system manages the hardware, the files and the running programs, and the common examples are Windows, Linux, macOS, Android and iOS. A compiler translates a whole program into machine code before running it; an interpreter translates and runs line by line; an assembler translates assembly language.

    The abbreviations are asked as one-liners and they are the easiest marks in the block. CPU is central processing unit, ALU arithmetic logic unit, RAM random access memory, ROM read only memory, BIOS basic input output system, OS operating system, GUI graphical user interface, LAN local area network, WAN wide area network, and USB universal serial bus. Learn them as expansions, because the question usually gives the expansion and asks for the short form, or the reverse.

    Two questions worked the short way

    A question asks how many bytes are in two kilobytes. One kilobyte is 1,024 bytes, so two kilobytes are 2,048 bytes. If the option list offers 2,000, that option is the trap for candidates who use the decimal meaning instead of the binary one.

    A question asks which of four devices is both input and output. A monitor is output only, a keyboard input only, a scanner input only, and a touch screen is both, because it displays and also senses touch. That single example covers the standard version of the question.

    Where marks are lost

    Storage, and how the devices are sorted

    Storage devices are asked by name. A hard disk uses magnetic platters and is the traditional fixed storage. An SSD uses flash memory, has no moving parts and is faster. A pen drive and a memory card are flash devices that connect through USB or a card slot. A CD holds about 700 megabytes, a DVD about 4.7 gigabytes, and a Blu-ray about 25 gigabytes on a single layer. A floppy disk, now obsolete, held 1.44 megabytes and is still offered as a wrong option in older question sets.

    A few accessories are worth knowing. A UPS provides battery backup for a short time so that a computer can be shut down safely. A printer is impact (dot matrix) or non-impact (inkjet, laser, thermal). A scanner converts a paper image into a digital file. A projector throws the screen onto a wall. These are asked as matches, so attach one line to each device and the question answers itself.

    Number systems and the conversion that is asked

    The paper asks simple binary conversions. Binary 1010 is 1x8 + 0x4 + 1x2 + 0x1, which is 10 in decimal. Binary 1111 is 15. Decimal 9 is 1001 in binary. To go the other way, divide by two repeatedly and read the remainders upwards. Octal uses eight digits and hexadecimal uses sixteen, with A to F standing for ten to fifteen, and a hexadecimal digit represents exactly four binary bits, which is why hexadecimal is used to write memory addresses compactly.

    Computer languages, in order of closeness to the machine

    Machine language is the binary code the processor executes directly, and it is the only language the hardware understands. Assembly language replaces those binary codes with short mnemonics and needs an assembler. High-level languages such as C, C++, Java, Python and JavaScript use English-like statements and need a compiler or an interpreter. The higher the language, the easier it is for a person and the more translation it needs before the machine can run it.

    File extensions are a separate one-line set. .txt is plain text, .docx a word document, .xlsx a spreadsheet, .pptx a presentation, .pdf a portable document, .jpg and .png images, .mp3 audio, .mp4 video, .exe a runnable program and .html a web page. A question that gives a name and asks what kind of file it is is answered straight from this list.

    Three errors recur. RAM is described as permanent memory, when it is the volatile one. ROM is described as the working memory, when it is the one that holds the start-up instructions. And the 1,024 factor is replaced by 1,000, which turns a correct method into a wrong answer. Check the volatility and the factor before choosing.

    • Four functions: input, processing, storage, output.
    • 1 byte = 8 bits; 1 KB = 1,024 B; 1 MB = 1,024 KB; 1 GB = 1,024 MB; 1 TB = 1,024 GB.
    • RAM is volatile, ROM is not; both are primary memory.
    • Generations: valves, transistors, integrated circuits, microprocessors, artificial intelligence.
    • Babbage is the father of the computer; von Neumann gave the stored-program design.
    Exam tip: For any unit question, write the 1,024 chain on the rough sheet before you start. Nearly every wrong option in this block is the same number computed with 1,000.

    কম্পিউটাৰৰ মৌলিক কথা: অধ্যয়ন টোকা

    প্ৰশ্নবোৰত হাত দিয়াৰ আগতে এইখিনি পঢ়ি লওক। তলৰ প্ৰতিটো কথা DHS আৰু DME কাৰিকৰী গ্ৰেড III পৰীক্ষাৰ বাবে লিখা।

    কম্পিউটাৰৰ এই অংশত কি সোধা হয়

    এই অধ্যায়ত যন্ত্ৰটো নিজেই সামৰি লোৱা হৈছে: কম্পিউটাৰ কি, তাৰ অংশবোৰৰ নাম কি, মেম'ৰিৰ এককৰ অৰ্থ কি, তথ্য কেনেকৈ প্ৰকাশ কৰা হয়, আৰু কোনে কি আৱিষ্কাৰ কৰিছিল। প্ৰশ্নবোৰ প্ৰায় সদায় এশাৰী তথ্য, আৰু প্ৰতি বছৰে একেই ৰূপত সোধা হয় - কোনটো একক আটাইতকৈ ডাঙৰ, কোনটো সঁজুলি ইনপুট, কোন শাখাই কোন প্ৰযুক্তি ব্যৱহাৰ কৰিছিল, কোন সংক্ষিপ্ত ৰূপে কি বুজায়।

    তথ্যবোৰ নসলনি হোৱা বাবে এই অংশ সুৰক্ষিত কৰা সহজ। এই লেখাৰ চাৰিটা তালিকা - একক, ইনপুট আৰু আউটপুট সঁজুলি, শাখা, আৰু সংক্ষিপ্ত ৰূপ - এক ঘণ্টা চালে এই বিষয়ৰ পৰা অহা বেছিভাগ প্ৰশ্ন সামৰি লোৱা যায়।

    কম্পিউটাৰ কি, আৰু চাৰিটা কাম

    কম্পিউটাৰ হ'ল এনে এটা ইলেক্ট্ৰনিক সঁজুলি যি তথ্য লয়, নিৰ্দেশনা অনুসৰি তাক প্ৰক্ৰিয়া কৰে, ফল সাঁচি ৰাখে আৰু আউটপুট দিয়ে। এই চাৰিটা কাম - ইনপুট, প্ৰক্ৰিয়াকৰণ, সংৰক্ষণ আৰু আউটপুট - হাৰ্ডৱেৰৰ প্ৰতিটো প্ৰশ্নৰ skeleton। কীব'ৰ্ড, মাউছ, স্কেনাৰ, মাইক্ৰ'ফ'ন, জয়ষ্টিক, লাইট পেন, টাচ স্ক্ৰিন আৰু বাৰক'ড ৰিডাৰ ইনপুট সঁজুলি। মনিটৰ, প্ৰিণ্টাৰ, স্পীকাৰ, প্লটাৰ আৰু প্ৰজেক্টৰ আউটপুট সঁজুলি। মডেম, টাচ স্ক্ৰিন আৰু পেন ড্ৰাইভ দুয়ো দিশত কাম কৰিব পাৰে।

    প্ৰক্ৰিয়াকৰণৰ একক CPU, আৰু তাৰ তিনি অংশ: গণনা কৰা এৰিথমেটিক লজিক ইউনিট, নিৰ্দেশনাৰ প্ৰবাহ পৰিচালনা কৰা কণ্ট্ৰ'ল ইউনিট, আৰু বৰ্তমান তথ্য ধৰি ৰখা ৰেজিষ্টাৰ। মেম'ৰি প্ৰাথমিক বা দ্বিতীয় স্তৰৰ। প্ৰাথমিক মেম'ৰি CPU ৰ পোনপটীয়া প্ৰৱেশত থাকে আৰু দুধৰণৰ: RAM, যি অস্থিৰ আৰু বিদ্যুৎ গ'লে তথ্য হেৰায়, আৰু ROM, যি স্থিৰ আৰু আৰম্ভণিৰ নিৰ্দেশনা ধৰি ৰাখে। দ্বিতীয় স্তৰৰ মেম'ৰি - হাৰ্ড ডিস্ক, SSD, পেন ড্ৰাইভ, CD, DVD - স্থায়ী কিন্তু লাহী।

    মেম'ৰিৰ একক, ক্ৰমে

    ক্ৰমটো হ'ল বিট, বাইট, কিল'বাইট, মেগাবাইট, গিগাবাইট, টেৰাবাইট, পেটাবাইট। এক বাইট = আঠ বিট, আৰু সাধাৰণতে এটা আখৰ ধৰি ৰাখে। এক কিল'বাইট = 1,024 বাইট, এক মেগাবাইট = 1,024 কিল'বাইট, এক গিগাবাইট = 1,024 মেগাবাইট, আৰু এক টেৰাবাইট = 1,024 গিগাবাইট। 1,000 ৰ সলনি 1,024 কাৰণ মেম'ৰি দুৰ্গুণ শক্তিত সজা হয়, আৰু 1,000 ব্যৱহাৰ কৰা প্ৰশ্নই এই কথাটো পৰীক্ষা কৰে।

    গতি বেলেগকৈ মাপা হয়। প্ৰচেছৰৰ ঘড়ীৰ গতি গিগাহাৰ্টজত, আৰু এক গিগাহাৰ্টজ = এশ কোটি চক্ৰ প্ৰতি ছেকেণ্ড। হাৰ্ড ডিস্ক ঘূৰ্ণনৰ হাৰ আৰু প্ৰৱেশ সময়ত, আৰু প্ৰিণ্টাৰ প্ৰতি মিনিটত পৃষ্ঠা আৰু প্ৰতি ইঞ্চিত বিন্দুত, যি ৰিজ'লিউচন। এই এককবোৰ মিলোৱা প্ৰশ্ন হিচাপে আহে আৰু সহজ নম্বৰ।

    শাখাবোৰ, আৰু প্ৰতিটোৱে কি আনি দিলে

    প্ৰথম শাখাত ভেকুৱাম টিউব ব্যৱহাৰ হৈছিল, আকাৰ বিশাল আছিল, আৰু মেচিন ভাষাত কাৰ্যসূচী লিখা হৈছিল। দ্বিতীয় শাখাত ট্ৰেনজিষ্টৰ আছিল আৰু এচেম্বলি ভাষা আহিছিল। তৃতীয় শাখাত ইন্টিগ্ৰেটেড চাৰ্কিট আছিল আৰু অপাৰেটিং চিষ্টেম, কীব'ৰ্ড আৰু মনিটৰ আহিছিল। চতুৰ্থ শাখাত মাইক্ৰ'প্ৰচেছৰ আছিল আৰু ব্যক্তিগত কম্পিউটাৰ, গ্ৰাফিকেল ইউজাৰ ইণ্টাৰফেচ আৰু নেটৱৰ্ক আহিছিল। পঞ্চম শাখা, যি এতিয়াও চলি আছে, কৃত্ৰিম বুদ্ধিমত্তা, সমান্তৰাল প্ৰক্ৰিয়াকৰণ আৰু প্ৰাকৃতিক ভাষাৰ লগত জড়িত।

    কেইটামান প্ৰথম নামেৰে জনা ভাল। চাৰ্লছ বেবেজে এনালিটিকেল ইঞ্জিন সাজিছিল আৰু তেওঁক কম্পিউটাৰৰ পিতা বুলি কোৱা হয়। এডা লাভলেছে প্ৰথম কাৰ্যসূচী বুলি ধৰা লিখনী লিখিছিল। জন ভন নিউমেনে সাঁচি ৰখা কাৰ্যসূচীৰ স্থাপত্যৰ বৰ্ণনা দিছিল, যি আজিও প্ৰতিটো আধুনিক কম্পিউটাৰে অনুসৰণ কৰে। ENIAC প্ৰথম সাধাৰণ উদ্দেশ্যৰ ইলেক্ট্ৰনিক কম্পিউটাৰ আছিল। ট্ৰেনজিষ্টৰ বেল পৰীক্ষাগাৰত আৱিষ্কৃত হৈছিল, আৰু এক দশকৰ পিছত ইন্টিগ্ৰেটেড চাৰ্কিট আহিছিল।

    চফ্টৱেৰ, আৰু তাৰ লগত অহা শব্দ

    চফ্টৱেৰ দুধৰণৰ। চিষ্টেম চফ্টৱেৰে যন্ত্ৰ চলায় - অপাৰেটিং চিষ্টেম, ডিভাইচ ড্ৰাইভাৰ আৰু ইউটিলিটি কাৰ্যসূচী। এপ্লিকেচন চফ্টৱেৰে ব্যৱহাৰকাৰীৰ কাম কৰে - ৱৰ্ড প্ৰচেছৰ, স্প্ৰেডশ্বীট, ব্ৰাউজাৰ, মিডিয়া প্লেয়াৰ। অপাৰেটিং চিষ্টেমে হাৰ্ডৱেৰ, ফাইল আৰু চলি থকা কাৰ্যসূচী পৰিচালনা কৰে, আৰু চিনাকি উদাহৰণ Windows, Linux, macOS, Android আৰু iOS। কম্পাইলাৰে গোটেই কাৰ্যসূচী আগতে মেচিন ক'ডলৈ ৰূপান্তৰ কৰে; ইণ্টাৰপ্ৰিটাৰে শাৰী শাৰী ৰূপান্তৰ কৰি চলায়; এচেম্বলাৰে এচেম্বলি ভাষা ৰূপান্তৰ কৰে।

    সংক্ষিপ্ত ৰূপবোৰ এশাৰী প্ৰশ্ন হিচাপে আহে আৰু এই অংশৰ আটাইতকৈ সহজ নম্বৰ। CPU = চেণ্ট্ৰেল প্ৰচেছিং ইউনিট, ALU = এৰিথমেটিক লজিক ইউনিট, RAM = ৰেণ্ডম এক্সেছ মেম'ৰি, ROM = ৰিড অনলি মেম'ৰি, BIOS = বেছিক ইনপুট আউটপুট চিষ্টেম, OS = অপাৰেটিং চিষ্টেম, GUI = গ্ৰাফিকেল ইউজাৰ ইণ্টাৰফেচ, LAN = লোকেল এৰিয়া নেটৱৰ্ক, WAN = ৱাইড এৰিয়া নেটৱৰ্ক, আৰু USB = ইউনিভাৰ্চেল চিৰিয়েল বাছ। বিস্তাৰিত ৰূপ হিচাপে শিকা, কাৰণ প্ৰশ্নই সাধাৰণতে বিস্তাৰিত ৰূপ দি চুটি ৰূপ সোধে, বা ওলোটাকৈ।

    চুটিকৈ কৰা দুটা প্ৰশ্ন

    দুই কিল'বাইটত কিমান বাইট সোধা হ'ল। এক কিল'বাইট = 1,024 বাইট, সেয়ে দুই কিল'বাইট = 2,048 বাইট। যদি বিকল্পত 2,000 দিয়া থাকে, সেয়া দশমিক অৰ্থ ব্যৱহাৰ কৰা পৰীক্ষাৰ্থীৰ বাবে ফান্দ।

    চাৰিটা সঁজুলিৰ ভিতৰত কোনটো ইনপুট আৰু আউটপুট দুয়োটা সোধা হ'ল। মনিটৰ কেৱল আউটপুট, কীব'ৰ্ড কেৱল ইনপুট, স্কেনাৰ কেৱল ইনপুট, আৰু টাচ স্ক্ৰিন দুয়োটা, কাৰণ ই দেখুৱায় আৰু স্পৰ্শও ধৰে। এই এটা উদাহৰণেই প্ৰশ্নৰ চিনাকি ৰূপ সামৰি লয়।

    ক'ত নম্বৰ যায়

    সংৰক্ষণ, আৰু সঁজুলিবোৰ কেনেকৈ ভাগ কৰা হয়

    সংৰক্ষণ সঁজুলি নামেৰে সোধা হয়। হাৰ্ড ডিস্কত চুম্বকীয় প্লেটাৰ থাকে আৰু ই পৰম্পৰাগত স্থিৰ সংৰক্ষণ। SSD ত ফ্লেছ মেম'ৰি থাকে, চলন্ত অংশ নাই আৰু ই দ্ৰুত। পেন ড্ৰাইভ আৰু মেম'ৰি কাৰ্ড ফ্লেছ সঁজুলি যি USB বা কাৰ্ড স্লটেদি সংযুক্ত হয়। CD ত প্ৰায় 700 মেগাবাইট, DVD ত প্ৰায় 4.7 গিগাবাইট, আৰু ব্লু-ৰে এক স্তৰত প্ৰায় 25 গিগাবাইট ধৰে। ফ্লপি ডিস্ক, যি এতিয়া অচল, 1.44 মেগাবাইট ধৰিছিল আৰু পুৰণি প্ৰশ্নত ভুল বিকল্প হিচাপে এতিয়াও দিয়া হয়।

    কেইটামান উপকৰণ জনা ভাল। UPS য়ে কম সময়ৰ বাবে বেটেৰীৰ সহায় দিয়ে, যাতে কম্পিউটাৰ নিৰাপদে বন্ধ কৰিব পাৰি। প্ৰিণ্টাৰ ইম্পেক্ট (ডট মেট্ৰিক্স) বা নন-ইম্পেক্ট (ইংকজেট, লেজাৰ, থাৰ্মেল)। স্কেনাৰে কাগজৰ ছবিক ডিজিটেল ফাইললৈ ৰূপান্তৰ কৰে। প্ৰজেক্টৰে পৰ্দা এখনত স্ক্ৰিন পেলায়। এইবোৰ মিলোৱা প্ৰশ্ন, সেয়ে প্ৰতিটো সঁজুলিৰ লগত এশাৰী লগাই লোৱা, প্ৰশ্ন নিজেই উত্তৰ দিব।

    সংখ্যা পদ্ধতি আৰু সোধা ৰূপান্তৰ

    প্ৰশ্নকাকতে সৰল বাইনেৰি ৰূপান্তৰ সোধে। বাইনেৰি 1010 = 1x8 + 0x4 + 1x2 + 0x1, অৰ্থাৎ দশমিকত 10। বাইনেৰি 1111 = 15। দশমিক 9 বাইনেৰিত 1001। ওলোটা দিশলৈ যাবলৈ বাৰে বাৰে দুইৰে হৰণ কৰি ভাগশেষবোৰ তলৰ পৰা ওপৰলৈ পঢ়া। অক্টেলে আঠটা অঙ্ক ব্যৱহাৰ কৰে আৰু হেক্সাডেচিমেলে ষোল্লটা, য'ত A ৰ পৰা F লৈকে দহৰ পৰা পোন্ধৰলৈ বুজায়, আৰু এটা হেক্সাডেচিমেল অঙ্কই ঠিক চাৰিটা বাইনেৰি বিট সূচায়, সেয়ে মেম'ৰি ঠিকনা চমুকৈ লিখিবলৈ হেক্সাডেচিমেল ব্যৱহাৰ হয়।

    কম্পিউটাৰ ভাষা, যন্ত্ৰৰ ওচৰত থকাৰ ক্ৰমত

    মেচিন ভাষা হ'ল বাইনেৰি ক'ড যি প্ৰচেছৰে পোনপটীয়াকৈ চলায়, আৰু ইয়েই একমাত্ৰ ভাষা যি হাৰ্ডৱেৰে বুজে। এচেম্বলি ভাষাই সেই বাইনেৰি ক'ডৰ ঠাইত চুটি নাম ব্যৱহাৰ কৰে আৰু এচেম্বলাৰ লাগে। C, C++, Java, Python আৰু JavaScript ৰ দৰে উচ্চ স্তৰৰ ভাষাই ইংৰাজীৰ দৰে বাক্য ব্যৱহাৰ কৰে আৰু কম্পাইলাৰ বা ইণ্টাৰপ্ৰিটাৰ লাগে। ভাষা যিমান ওখ, মানুহৰ বাবে সিমান সহজ আৰু যন্ত্ৰই চলোৱাৰ আগতে সিমান ৰূপান্তৰ লাগে।

    ফাইলৰ নামৰ শেষাংশৰ তালিকাও এশাৰীত সোধা হয়: .txt সাধাৰণ লেখা, .docx ৱৰ্ড ডকুমেণ্ট, .xlsx স্প্ৰেডশ্বীট, .pptx প্ৰজেণ্টেচন, .pdf প'ৰ্টেবল ডকুমেণ্ট, .jpg আৰু .png ছবি, .mp3 শব্দ, .mp4 ভিডিঅ', .exe চলিব পৰা কাৰ্যসূচী আৰু .html ৱেব পৃষ্ঠা। এটা নাম দি কি ধৰণৰ ফাইল সোধা প্ৰশ্ন এই তালিকাৰ পৰাই উত্তৰ পায়।

    তিনিটা ভুল বাৰে বাৰে আহে। RAM ক স্থায়ী মেম'ৰি বুলি কোৱা হয়, অথচ সেয়াই অস্থিৰ। ROM ক কাৰ্যকৰী মেম'ৰি বুলি কোৱা হয়, অথচ সেয়াই আৰম্ভণিৰ নিৰ্দেশনা ধৰি ৰাখে। আৰু 1,024 ৰ ঠাইত 1,000 বহুওৱা হয়, যাৰ ফলত শুদ্ধ পদ্ধতিও ভুল উত্তৰ হয়। বাছনিৰ আগতে অস্থিৰতা আৰু গুণকটো চোৱা।

    দৈনন্দিন ব্যৱহাৰৰ কেইটামান কথা

    ফাইলৰ নামৰ শেষত থকা অংশই ফাইলৰ প্ৰকাৰ কয়: .txt হ'ল সাধাৰণ লেখা, .docx হ'ল ৱৰ্ড ডকুমেণ্ট, .xlsx স্প্ৰেডশ্বীট, .pptx প্ৰজেণ্টেচন, .pdf প'ৰ্টেবল ডকুমেণ্ট, .jpg আৰু .png ছবি, .mp3 শব্দ, .mp4 ভিডিঅ', আৰু .exe চলিব পৰা কাৰ্যসূচী। প্ৰশ্নকাকতত এটা নাম দি সোধা হয় ই কি ধৰণৰ ফাইল, আৰু এই তালিকাখনেই উত্তৰ দিয়ে।

    কীব'ৰ্ডৰ চাৰিটা বিশেষ কি-ও সোধা হয়: Enter এ নতুন শাৰী বা আদেশ সম্পন্ন কৰে, Shift এ ডাঙৰ আখৰ দিয়ে, Ctrl এ চুটিকৈ কাম কৰিবলৈ আন কিৰ লগত মিলি কাম কৰে, আৰু Alt এ মেনু ব্যৱহাৰ কৰিবলৈ দিয়ে। Ctrl + C কপি, Ctrl + V পে'ষ্ট, Ctrl + X কাট, আৰু Ctrl + S সাঁচি ৰখা - এইবোৰ প্ৰায় প্ৰতিবছৰে এটা প্ৰশ্ন।

    তথ্যৰ প্ৰকাশ

    কম্পিউটাৰে সকলো তথ্য শূন্য আৰু এক ৰে ৰাখে, যাক বাইনেৰি পদ্ধতি বোলে। এটা বিটেই এটা শূন্য বা এক, আৰু আঠটা বিটে এটা বাইট। মানুহে দহ অঙ্কৰ দশমিক পদ্ধতি ব্যৱহাৰ কৰে, আৰু কম্পিউটাৰৰ লগত কাম কৰিবলৈ অক্টেল (আঠ) আৰু হেক্সাডেচিমেল (ষোল্ল) পদ্ধতিও ব্যৱহাৰ হয়। প্ৰশ্নকাকতত সোধা হয় বাইনেৰি 1010 ৰ দশমিক মান কিমান - উত্তৰ 10।

    পৰীক্ষাৰ টিপ: এককৰ যিকোনো প্ৰশ্নত আৰম্ভ কৰাৰ আগতে 1,024 ৰ শৃংখল ৰাফ শ্বীটত লিখা। এই অংশত প্ৰায় প্ৰতিটো ভুল বিকল্প একেই সংখ্যা 1,000 ৰে হিচাপ কৰা থাকে।
