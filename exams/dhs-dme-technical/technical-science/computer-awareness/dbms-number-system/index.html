    DBMS & Number System

    DBMS আৰু সংখ্যা পদ্ধতি • Technical / Science • DHS & DME Technical Grade III

    Back to Technical / Science

    30 Questions with Answers

    Q1. In a relational database, data is stored in
    সম্পৰ্কীয় ডাটাবেছত তথ্য ৰখা হয়
    (A) tables made of rows and columns শাৰী আৰু স্তম্ভৰ তালিকাত
    (B) a single long text file এটা দীঘল লিখা ফাইলত
    (C) folders only কেৱল ফোল্ডাৰত
    (D) images only কেৱল ছবিত
    Answer: A) tables made of rows and columns
    A) শাৰী আৰু স্তম্ভৰ তালিকাত
    Explanation: A relation is a table: each row is a record and each column a field. This structure is what makes SQL queries possible.
    সম্পৰ্ক এটা তালিকা: প্ৰতিটো শাৰী অভিলেখ আৰু প্ৰতিটো স্তম্ভ ক্ষেত্ৰ। এই গঠনে SQL প্ৰশ্ন সম্ভৱ কৰে।
    Q2. The binary equivalent of the decimal number 10 is
    দশমিক সংখ্যা ১০ ৰ দ্বিমিক ৰূপ
    (A) 1010 ১০১০
    (B) 1100 ১১০০
    (C) 1001 ১০০১
    (D) 1110 ১১১০
    Answer: A) 1010
    A) ১০১০
    Explanation: Ten is eight plus two, which sets the eight and two place values, giving 1010. Reversing the last two digits gives the wrong 1001.
    দহ মানে আঠ যোগ দুই, সেয়ে আঠ আৰু দুইৰ স্থানত এক, অৰ্থাৎ ১০১০। শেষৰ দুটা অংক ওলোটালে ভুলকৈ ১০০১ হয়।
    Q3. The primary key in a database table is used to
    ডাটাবেছ তালিকাৰ প্ৰাথমিক চাবি কিৰ বাবে ব্যৱহৃত হয়
    (A) uniquely identify each record প্ৰতিটো অভিলেখ অদ্বিতীয়ভাৱে চিনাক্ত কৰিবলৈ
    (B) sort the table by name তালিকা নামেৰে সজাবলৈ
    (C) encrypt the table তালিকা এনক্ৰিপ্ট কৰিবলৈ
    (D) count the rows শাৰী গণিবলৈ
    Answer: A) uniquely identify each record
    A) প্ৰতিটো অভিলেখ অদ্বিতীয়ভাৱে চিনাক্ত কৰিবলৈ
    Explanation: A primary key must be unique and not null, so no two rows can be confused. A sort order is a separate matter.
    প্ৰাথমিক চাবি অদ্বিতীয় আৰু শূন্য নহ'ব লাগে, সেয়ে দুটা শাৰী মিলি নাযায়। সজোৱা ক্ৰম বেলেগ কথা।
    Q4. The decimal value of the binary number 1111 is
    দ্বিমিক সংখ্যা ১১১১ ৰ দশমিক মান
    (A) 15 ১৫
    (B) 11 ১১
    (C) 16 ১৬
    (D) 8 ৮
    Answer: A) 15
    A) ১৫
    Explanation: Four ones mean eight plus four plus two plus one, that is fifteen. Sixteen would need a fifth bit set.
    চাৰিটা এক মানে আঠ যোগ চাৰি যোগ দুই যোগ এক = পোন্ধৰ। ষোল্ললৈ পঞ্চম বিট লাগিব।
    Q5. Which language is used to query a relational database?
    সম্পৰ্কীয় ডাটাবেছত প্ৰশ্ন সোধাৰ বাবে কোন ভাষা ব্যৱহৃত হয়
    (A) SQL
    (B) HTML
    (C) CSS
    (D) XML
    Answer: A) SQL
    Explanation: Structured query language selects, inserts and updates records. HTML marks up pages and CSS styles them.
    SQL এ অভিলেখ বাছে, সুমুৱায় আৰু আপডেট কৰে। HTML এ পৃষ্ঠা চিহ্নিত কৰে আৰু CSS এ ৰূপ দিয়ে।
    Q6. The hexadecimal number system has a base of
    হেক্সাডেচিমেল সংখ্যা পদ্ধতিৰ ভিত্তি
    (A) 16 ১৬
    (B) 10 ১০
    (C) 8 ৮
    (D) 2 ২
    Answer: A) 16
    A) ১৬
    Explanation: Hexadecimal uses sixteen symbols, zero to nine plus A to F. Base eight is octal and base two is binary.
    হেক্সাডেচিমেলে ষোল্ল চিহ্ন, শূন্যৰপৰা ন আৰু A ৰপৰা F। ভিত্তি আঠ অষ্টাল আৰু ভিত্তি দুই দ্বিমিক।
    Q7. In a database, a field that refers to the primary key of another table is called a
    ডাটাবেছত আন তালিকাৰ প্ৰাথমিক চাবিলৈ দেখুওৱা ক্ষেত্ৰক কি বোলা হয়
    (A) foreign key বহিঃ চাবি
    (B) primary key প্ৰাথমিক চাবি
    (C) candidate key প্ৰাৰ্থী চাবি
    (D) super key ছুপাৰ চাবি
    Answer: A) foreign key
    A) বহিঃ চাবি
    Explanation: A foreign key links two tables and enforces that the referenced row exists, which is how relationships are built.
    বহিঃ চাবিয়ে দুটা তালিকা জোড়ে আৰু নিৰ্দেশিত শাৰী আছে বুলি নিশ্চিত কৰে, সেয়ে সম্পৰ্ক গঢ়ে।
    Q8. The binary addition of 101 and 11 gives
    ১০১ আৰু ১১ ৰ দ্বিমিক যোগফল
    (A) 1000 ১০০০
    (B) 110 ১১০
    (C) 111 ১১১
    (D) 1010 ১০১০
    Answer: A) 1000
    A) ১০০০
    Explanation: Five plus three is eight, and eight in binary is 1000. Writing 111 would ignore the carry.
    পাঁচ যোগ তিনি = আঠ, আৰু দ্বিমিকে আঠ ১০০০। ১১১ লিখিলে হাত বঢ়োৱা উপেক্ষা হয়।
    Q9. Which SQL statement is used to retrieve data from a table?
    তালিকাৰপৰা তথ্য অনাৰ বাবে কোন SQL নিৰ্দেশ ব্যৱহৃত হয়
    (A) SELECT
    (B) INSERT
    (C) DELETE
    (D) UPDATE
    Answer: A) SELECT
    Explanation: SELECT reads rows. INSERT adds, UPDATE changes and DELETE removes them.
    SELECT এ শাৰী পঢ়ে। INSERT এ যোগ, UPDATE এ সলনি আৰু DELETE এ মচে।
    Q10. One nibble is equal to
    এক নিবল কিৰ সমান
    (A) 4 bits ৪ বিট
    (B) 8 bits ৮ বিট
    (C) 2 bits ২ বিট
    (D) 16 bits ১৬ বিট
    Answer: A) 4 bits
    A) ৪ বিট
    Explanation: A nibble is half a byte, that is four bits, and it is exactly one hexadecimal digit.
    নিবল আধা বাইট, অৰ্থাৎ চাৰি বিট, আৰু ই ঠিক এটা হেক্সাডেচিমেল অংক।
    Q11. Redundancy in a database leads to
    ডাটাবেছত বাহুল্যই কিৰ সৃষ্টি কৰে
    (A) wasted space and inconsistent data অপচয় ঠাই আৰু অসামঞ্জস্য তথ্য
    (B) faster queries always সদায় দ্ৰুত প্ৰশ্ন
    (C) better security উত্তম সুৰক্ষা
    (D) smaller files সৰু ফাইল
    Answer: A) wasted space and inconsistent data
    A) অপচয় ঠাই আৰু অসামঞ্জস্য তথ্য
    Explanation: Storing the same fact in many places wastes space and lets copies disagree. Normalisation removes such repetition.
    একেই তথ্য বহু ঠাইত ৰাখিলে ঠাই নষ্ট হয় আৰু নকলবোৰ বেলেগ হ'ব পাৰে। নৰ্মেলাইজেশনে পুনৰাবৃত্তি আঁতৰায়।
    Q12. The decimal number 25 in binary is
    দশমিক সংখ্যা ২৫ ৰ দ্বিমিক ৰূপ
    (A) 11001 ১১০০১
    (B) 10101 ১০১০১
    (C) 11010 ১১০১০
    (D) 10011 ১০০১১
    Answer: A) 11001
    A) ১১০০১
    Explanation: Twenty-five is sixteen plus eight plus one, so bits four, three and zero are set, giving 11001.
    পঁচিশ মানে ষোল্ল যোগ আঠ যোগ এক, সেয়ে চাৰি, তিনি আৰু শূন্য স্থানত এক, অৰ্থাৎ ১১০০১।
    Q13. A DBMS is used mainly to
    DBMS মূলতঃ কিৰ বাবে ব্যৱহৃত হয়
    (A) store, retrieve and manage large amounts of data বহু তথ্য ৰখা, অনা আৰু চলোৱা
    (B) design web pages ৱেব পৃষ্ঠা ডিজাইন কৰা
    (C) edit photographs ফট'গ্ৰাফ সম্পাদনা কৰা
    (D) scan documents ডকুমেণ্ট স্কেন কৰা
    Answer: A) store, retrieve and manage large amounts of data
    A) বহু তথ্য ৰখা, অনা আৰু চলোৱা
    Explanation: A database management system controls access, keeps data consistent and answers queries. It is not a design tool.
    DBMS এ প্ৰৱেশ নিয়ন্ত্ৰণ কৰি তথ্য সামঞ্জস্য ৰাখি প্ৰশ্নৰ উত্তৰ দিয়ে। ই ডিজাইন সজুলি নহয়।
    Q14. The octal equivalent of the decimal number 8 is
    দশমিক সংখ্যা ৮ ৰ অষ্টাল ৰূপ
    (A) 10 ১০
    (B) 8 ৮
    (C) 12 ১২
    (D) 18 ১৮
    Answer: A) 10
    A) ১০
    Explanation: In base eight the digits run only to seven, so eight is written as one zero. The symbol 8 does not exist in octal.
    ভিত্তি আঠত অংক কেবল সাতলৈকে, সেয়ে আঠক এক শূন্য লিখা হয়। অষ্টালত ৮ চিহ্ন নাই।
    Q15. Which of the following is a database constraint that prevents null values?
    শূন্য মান ৰোধ কৰা ডাটাবেছ বাধ্যতামূলক চৰ্তটো
    (A) NOT NULL
    (B) UNIQUE only কেৱল UNIQUE
    (C) DEFAULT
    (D) INDEX
    Answer: A) NOT NULL
    Explanation: NOT NULL forces a value in every row. UNIQUE prevents duplicates but still permits a null in many systems.
    NOT NULL এ প্ৰতিটো শাৰীত মান বাধ্যতামূলক কৰে। UNIQUE এ নকল ৰোধ কৰে কিন্তু বহু চিষ্টেমত শূন্য মান দিব পাৰি।
    Q16. The binary number 100000 has the decimal value
    দ্বিমিক সংখ্যা ১০০০০০ ৰ দশমিক মান
    (A) 32 ৩২
    (B) 16 ১৬
    (C) 64 ৬৪
    (D) 8 ৮
    Answer: A) 32
    A) ৩২
    Explanation: A one followed by five zeros sets the two to the fifth place, which is thirty-two.
    একৰ পিছত পাঁচটা শূন্য মানে দুইৰ ঘাত পাঁচ স্থানত এক, অৰ্থাৎ বত্ৰিশ।
    Q17. In a table of students, the column that stores the date of birth is a
    শিক্ষাৰ্থীৰ তালিকাত জন্ম তাৰিখ ৰখা স্তম্ভটো এটা
    (A) field ক্ষেত্ৰ
    (B) record অভিলেখ
    (C) primary key প্ৰাথমিক চাবি
    (D) relation সম্পৰ্ক
    Answer: A) field
    A) ক্ষেত্ৰ
    Explanation: A column is a field describing one attribute. A whole row about one student is a record.
    স্তম্ভ এটা ক্ষেত্ৰ যি এটা গুণ বৰ্ণনা কৰে। এজন শিক্ষাৰ্থীৰ গোটেই শাৰী এটা অভিলেখ।
    Q18. The result of subtracting 1 from the binary number 1000 is
    দ্বিমিক সংখ্যা ১০০০ ৰপৰা ১ বিয়োগ কৰিলে পোৱা ফল
    (A) 111 ১১১
    (B) 0111 only কেৱল ০১১১
    (C) 1001 ১০০১
    (D) 999 ৯৯৯
    Answer: A) 111
    A) ১১১
    Explanation: Eight minus one is seven, which is 111 in binary. Nine would be addition, not subtraction.
    আঠ বিয়োগ এক = সাত, যি দ্বিমিকে ১১১। ন হ'লে যোগ হ'ব, বিয়োগ নহয়।
    Q19. A view in a database is
    ডাটাবেছত ভিউ হ'ল
    (A) a stored query that behaves like a virtual table সাঁচি ৰখা প্ৰশ্ন যি আভাসিক তালিকা যেন কাম কৰে
    (B) a copy of the whole database গোটেই ডাটাবেছৰ নকল
    (C) a type of index এবিধ সূচী
    (D) a backup file এটা বেকআপ ফাইল
    Answer: A) a stored query that behaves like a virtual table
    A) সাঁচি ৰখা প্ৰশ্ন যি আভাসিক তালিকা যেন কাম কৰে
    Explanation: A view holds no data of its own; it runs its query and shows the result, which also limits what a user can see.
    ভিউৱে নিজৰ তথ্য নৰাখে; ই প্ৰশ্ন চলাই ফল দেখুৱায়, যিয়ে ব্যৱহাৰকাৰীয়ে দেখা সমলো সীমিত কৰে।
    Q20. The hexadecimal digit F has the decimal value
    হেক্সাডেচিমেল অংক F ৰ দশমিক মান
    (A) 15 ১৫
    (B) 16 ১৬
    (C) 10 ১০
    (D) 5 ৫
    Answer: A) 15
    A) ১৫
    Explanation: The digits run 0 to 9 and then A to F, so F is the sixteenth value counting from zero, that is fifteen.
    অংক শূন্যৰপৰা ন, তাৰ পিছত A ৰপৰা F, সেয়ে F শূন্যৰপৰা গণি ষোল্লতম, অৰ্থাৎ পোন্ধৰ।
    Q21. Which normal form removes partial dependency on a composite primary key?
    কোন নৰ্মেল ৰূপে যৌগিক প্ৰাথমিক চাবিৰ আংশিক নিৰ্ভৰতা আঁতৰায়
    (A) second normal form দ্বিতীয় নৰ্মেল ৰূপ
    (B) first normal form প্ৰথম নৰ্মেল ৰূপ
    (C) third normal form তৃতীয় নৰ্মেল ৰূপ
    (D) fourth normal form চতুৰ্থ নৰ্মেল ৰূপ
    Answer: A) second normal form
    A) দ্বিতীয় নৰ্মেল ৰূপ
    Explanation: Second normal form requires every non-key attribute to depend on the whole key, not part of it. First normal form only removes repeating groups.
    দ্বিতীয় নৰ্মেল ৰূপত প্ৰতিটো অ-চাবি গুণ গোটেই চাবিৰ ওপৰত নিৰ্ভৰ কৰিব লাগে, তাৰ অংশৰ ওপৰত নহয়। প্ৰথমটোৱে কেবল পুনৰাবৃত্ত গোট আঁতৰায়।
    Q22. The binary equivalent of the decimal number 7 is
    দশমিক সংখ্যা ৭ ৰ দ্বিমিক ৰূপ
    (A) 111 ১১১
    (B) 101 ১০১
    (C) 110 ১১০
    (D) 1000 ১০০০
    Answer: A) 111
    A) ১১১
    Explanation: Seven is four plus two plus one, so the first three bits are set. Eight would be 1000.
    সাত মানে চাৰি যোগ দুই যোগ এক, সেয়ে প্ৰথম তিনি বিটত এক। আঠ হ'লে ১০০০।
    Q23. An index in a database is created mainly to
    ডাটাবেছত সূচী সজা হয় মূলতঃ কিৰ বাবে
    (A) speed up searches on that column সেই স্তম্ভত সন্ধান দ্ৰুত কৰিবলৈ
    (B) save disk space ডিস্কৰ ঠাই ৰাখিবলৈ
    (C) encrypt the column স্তম্ভ এনক্ৰিপ্ট কৰিবলৈ
    (D) delete duplicate rows নকল শাৰী মচিবলৈ
    Answer: A) speed up searches on that column
    A) সেই স্তম্ভত সন্ধান দ্ৰুত কৰিবলৈ
    Explanation: An index is a lookup structure that shortens the search, at the cost of extra space and slower writes.
    সূচী এটা সন্ধান গঠন যি খোজ কমায়, কিন্তু অতিৰিক্ত ঠাই লাগে আৰু লিখা ধীৰ হয়।
    Q24. The hexadecimal equivalent of the binary number 1111 is
    দ্বিমিক সংখ্যা ১১১১ ৰ হেক্সাডেচিমেল ৰূপ
    (A) F
    (B) E
    (C) 10 ১০
    (D) 15 ১৫
    Answer: A) F
    Explanation: Four binary ones make fifteen, and fifteen is written F in hexadecimal. Writing 15 mixes the two bases.
    চাৰিটা দ্বিমিক একে পোন্ধৰ কৰে, আৰু পোন্ধৰক হেক্সাডেচিমেলত F লিখা হয়। ১৫ লিখিলে দুয়ো ভিত্তি মিলি যায়।
    Q25. Which of the following is not a type of database model?
    তলৰ কোনটো ডাটাবেছ আৰ্হি নহয়
    (A) spreadsheet model স্প্ৰেডশ্বীট আৰ্হি
    (B) relational model সম্পৰ্কীয় আৰ্হি
    (C) hierarchical model শ্ৰেণীবদ্ধ আৰ্হি
    (D) network model নেটৱৰ্ক আৰ্হি
    Answer: A) spreadsheet model
    A) স্প্ৰেডশ্বীট আৰ্হি
    Explanation: The classic models are relational, hierarchical, network and object oriented. A spreadsheet is a tool, not a database model.
    প্ৰচলিত আৰ্হি সম্পৰ্কীয়, শ্ৰেণীবদ্ধ, নেটৱৰ্ক আৰু বস্তুগত। স্প্ৰেডশ্বীট এটা সজুলি, ডাটাবেছ আৰ্হি নহয়।
    Q26. The decimal number 100 in binary is
    দশমিক সংখ্যা ১০০ ৰ দ্বিমিক ৰূপ
    (A) 1100100 ১১০০১০০
    (B) 1100010 ১১০০০১০
    (C) 1010100 ১০১০১০০
    (D) 1000100 ১০০০১০০
    Answer: A) 1100100
    A) ১১০০১০০
    Explanation: One hundred is sixty-four plus thirty-two plus four, which sets those three bits in a seven-bit number, giving 1100100.
    এশ মানে চৌষষ্ঠি যোগ বত্ৰিশ যোগ চাৰি, সেয়ে সাত বিটৰ সংখ্যাত সেই তিনি বিটত এক, অৰ্থাৎ ১১০০১০০।
    Q27. A relation in a relational database must have
    সম্পৰ্কীয় ডাটাবেছত সম্পৰ্ক এটাত থাকিব লাগে
    (A) no duplicate rows নকল শাৰী নাথাকিব
    (B) at least one image column অন্ততঃ এটা ছবি স্তম্ভ
    (C) exactly one row ঠিক এটা শাৰী
    (D) no primary key ever কেতিয়াও প্ৰাথমিক চাবি নাথাকিব
    Answer: A) no duplicate rows
    A) নকল শাৰী নাথাকিব
    Explanation: A true relation is a set, so identical rows cannot repeat. Every table normally also has a primary key.
    প্ৰকৃত সম্পৰ্ক এটা সমষ্টি, সেয়ে একেই শাৰী পুনৰ নহয়। প্ৰতিটো তালিকাত সাধাৰণতে প্ৰাথমিক চাবিও থাকে।
    Q28. The value of the binary fraction 0.1 in decimal is
    দ্বিমিক ভগ্নাংশ ০.১ ৰ দশমিক মান
    (A) 0.5 ০.৫
    (B) 0.1 ০.১
    (C) 0.2 ০.২
    (D) 1.0 ১.০
    Answer: A) 0.5
    A) ০.৫
    Explanation: The first place after the binary point means one half, so 0.1 in binary is 0.5 in decimal. Reading it as 0.1 is the common mistake.
    দ্বিমিক বিন্দুৰ পিছৰ প্ৰথম স্থান মানে আধা, সেয়ে দ্বিমিক ০.১ = দশমিক ০.৫। ০.১ বুলি পঢ়াটো সাধাৰণ ভুল।
    Q29. A relational database reduces duplication mainly through
    সম্পৰ্কীয় ডাটাবেছে পুনৰাবৃত্তি কমায় মূলতঃ কিৰে
    (A) normalisation into related tables সম্পৰ্কিত তালিকাত নৰ্মেলাইজেশ্যন কৰি
    (B) storing everything in one table সকলো এটা তালিকাত ৰাখি
    (C) deleting old records পুৰণি অভিলেখ মচি
    (D) compressing the file ফাইল সংকুচিত কৰি
    Answer: A) normalisation into related tables
    A) সম্পৰ্কিত তালিকাত নৰ্মেলাইজেশ্যন কৰি
    Explanation: Splitting data into related tables and joining them on keys removes repeated facts. One big table invites redundancy.
    তথ্য সম্পৰ্কিত তালিকাত ভাগ কৰি চাবিত জোড়ালে পুনৰাবৃত্ত তথ্য আঁতৰে। এটা ডাঙৰ তালিকাই বাহুল্য মাতি আনে।
    Q30. The two digits used in the binary system are
    দ্বিমিক পদ্ধতিত ব্যৱহৃত দুটা অংক
    (A) 0 and 1 ০ আৰু ১
    (B) 1 and 2 ১ আৰু ২
    (C) 0 and 9 ০ আৰু ৯
    (D) 1 and 9 ১ আৰু ৯
    Answer: A) 0 and 1
    A) ০ আৰু ১
    Explanation: Binary is base two, so only zero and one exist. That matches the two states of a digital circuit, off and on.
    দ্বিমিক ভিত্তি দুই, সেয়ে কেবল শূন্য আৰু এক আছে। ই ডিজিটেল বৰ্তনীৰ দুটা অৱস্থা, বন্ধ আৰু চলিত,ৰ সৈতে মিলে।
