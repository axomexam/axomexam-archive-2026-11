    A) এককালীন ক'ডৰ দৰে দ্বিতীয় প্ৰমাণ

    A) ঠিকনা বাৰত থকা সঠিক ডমেইন নাম

    ডমেইনেই চাইট চিনাক্ত কৰে, আৰু পৃষ্ঠা যিমান নিখুঁতভাৱে নকল কৰা নহওক, নকলকাৰীয়ে বেলেগ এটা ব্যৱহাৰ কৰিবই লাগে। ল'গ', ৰং আৰু ছবি হুবহু নকল কৰিব পাৰি, সেয়ে একো প্ৰমাণ নকৰে।
    Q43. A staff member's account sends phishing emails to the whole contact list. The most likely explanation is that the
    কৰ্মচাৰী এজনৰ একাউণ্টে গোটেই সম্পৰ্ক তালিকালৈ ফিচিঙ ইমেইল পঠিয়ায়। আটাই সম্ভাব্য ব্যাখ্যা
    (A) email server is too fast ইমেইল চাৰ্ভাৰ অতি দ্ৰুত
    (B) contact list is too long সম্পৰ্ক তালিকা অতি দীৰ্ঘ
    (C) keyboard needs cleaning কীব'ৰ্ড পৰিষ্কাৰৰ প্ৰয়োজন
    (D) account was compromised and is being used by an attacker একাউণ্ট ক্ষতিগ্ৰস্ত হৈ আক্ৰমণকাৰীয়ে ব্যৱহাৰ কৰিছে
    Answer: D) account was compromised and is being used by an attacker
    D) একাউণ্ট ক্ষতিগ্ৰস্ত হৈ আক্ৰমণকাৰীয়ে ব্যৱহাৰ কৰিছে
    Explanation: Mail that appears to come from a real colleague is sent by whoever holds that account, so the account itself is the problem and must be secured. Server speed, list length and a dirty keyboard cannot send mail.
    প্ৰকৃত সহকৰ্মীৰপৰা অহা যেন দেখা মেইল সেই একাউণ্ট ধৰি ৰখাজনে পঠিয়ায়, সেয়ে একাউণ্ট নিজেই সমস্যা আৰু তাক সুৰক্ষিত কৰিব লাগে। চাৰ্ভাৰৰ গতি, তালিকাৰ দীঘ বা মলিয়ন কীব'ৰ্ডে মেইল পঠিয়াব নোৱাৰে।
    Q44. An organisation must keep working while a supplier's cloud service is unavailable. The preparation that helps most is
    যোগানকৰ্তাৰ ক্লাউড সেৱা অনুপলব্ধ হ'লেও সংস্থাই কাম কৰি থাকিব লাগে। আটাই সহায়ক প্ৰস্তুতি
    (A) a bigger monitor ডাঙৰ মণিটৰ
    (B) more user licences বেছি ব্যৱহাৰকাৰী অনুজ্ঞা
    (C) an offline copy of critical data and a manual procedure গুৰুত্বপূৰ্ণ তথ্যৰ অফলাইন নকল আৰু হাতেৰে কৰাৰ পদ্ধতি
    (D) a faster internet connection দ্ৰুততৰ ইণ্টাৰনেট সংযোগ
    Answer: C) an offline copy of critical data and a manual procedure
    C) গুৰুত্বপূৰ্ণ তথ্যৰ অফলাইন নকল আৰু হাতেৰে কৰাৰ পদ্ধতি
    Explanation: When the service is down the network is irrelevant, so local copies plus a documented manual process keep the work going. A faster link, a monitor or extra licences all depend on the service being up.
    সেৱা বন্ধ থাকিলে নেটৱৰ্ক অপ্ৰাসংগিক, সেয়ে স্থানীয় নকল লগতে লিখিত হাতেৰে কৰাৰ পদ্ধতিয়ে কাম চলাই ৰাখে। দ্ৰুত সংযোগ, মণিটৰ বা অতিৰিক্ত অনুজ্ঞা সকলোৱে সেৱা চলি থকাৰ ওপৰত নিৰ্ভৰ কৰে।
    Q45. A user is asked to install a browser extension that promises free movies but requests access to all browsing data. The risk is that the extension can
    ব্যৱহাৰকাৰীক বিনামূলীয়া চিনেমাৰ প্ৰতিশ্ৰুতি দি সকলো ব্ৰাউজিং তথ্যলৈ প্ৰৱেশ বিচৰা এক্সটেনশ্যন ইনষ্টল কৰিবলৈ কোৱা হ'ল। বিপদ — এক্সটেনশ্যই পাৰে
    (A) repair the hard disk হাৰ্ড ডিস্ক মেৰামতি কৰিব
    (B) read and alter every page including logins লগইনসহ প্ৰতিটো পৃষ্ঠা পঢ়ি সলনি কৰিব
    (C) only change the browser theme কেৱল ব্ৰাউজাৰৰ থীম সলনি কৰিব
    (D) speed up the internet ইণ্টাৰনেট দ্ৰুত কৰিব
    Answer: B) read and alter every page including logins
    B) লগইনসহ প্ৰতিটো পৃষ্ঠা পঢ়ি সলনি কৰিব
    Explanation: Permission to read all browsing data lets an extension see and modify page content, which includes stealing credentials and injecting ads. A theme change needs no such permission, and an extension cannot speed the network or repair a disk.
    সকলো ব্ৰাউজিং তথ্য পঢ়াৰ অনুমতিয়ে এক্সটেনশ্যনক পৃষ্ঠাৰ বস্তু চাই সলনি কৰিবলৈ দিয়ে, যাৰ ভিতৰত প্ৰমাণপত্ৰ চুৰি আৰু বিজ্ঞাপন সোমোৱাও আছে। থীম সলনিৰ এনে অনুমতি নালাগে, আৰু এক্সটেনশ্যই নেটৱৰ্ক দ্ৰুত বা ডিস্ক মেৰামতি কৰিব নোৱাৰে।
    Q46. A company wants to detect an intruder who has already gained access to the network. The control that helps is
    কোম্পানীয়ে ইতিমধ্যে নেটৱৰ্কত প্ৰৱেশ কৰা অনুপ্ৰৱেশকাৰীক ধৰিব বিচাৰে। সহায়ক নিয়ন্ত্ৰণ
    (A) intrusion detection monitoring network traffic নেটৱৰ্ক ট্ৰেফিক নিৰীক্ষণ কৰা অনুপ্ৰৱেশ চিনাক্তকৰণ
    (B) a stronger front door lock শক্তিশালী মূল দুৱাৰৰ তলা
    (C) a larger server room ডাঙৰ চাৰ্ভাৰ কক্ষ
    (D) a new office chair নতুন কাৰ্যালয়ৰ চকী
    Answer: A) intrusion detection monitoring network traffic
    A) নেটৱৰ্ক ট্ৰেফিক নিৰীক্ষণ কৰা অনুপ্ৰৱেশ চিনাক্তকৰণ
    Explanation: Detection watches behaviour inside the network for unusual patterns, which is what finds an intruder who is already in. A door lock prevents entry, and room size or furniture has no role in detection.
    চিনাক্তকৰণে নেটৱৰ্কৰ ভিতৰৰ আচৰণ অস্বাভাৱিক আৰ্হিৰ বাবে চায়, যিয়ে ইতিমধ্যে সোমোৱা অনুপ্ৰৱেশকাৰীক বিচাৰি পায়। দুৱাৰৰ তলাই প্ৰৱেশ ৰোধ কৰে, আৰু কক্ষৰ আকাৰ বা আচবাবৰ চিনাক্তকৰণত ভূমিকা নাই।
    Q47. A user must send a confidential file by email to an external party. The safest method is to
    ব্যৱহাৰকাৰীয়ে বাহিৰৰ পক্ষলৈ গোপনীয় ফাইল ইমেইলেৰে পঠিয়াব লাগে। আটাই সুৰক্ষিত উপায়
    (A) attach the file to a plain email সাধাৰণ ইমেইলত ফাইল সংলগ্ন কৰা
    (B) paste the contents into the message body বস্তু বাৰ্তাৰ গাত ভৰোৱা
    (C) rename the file so it looks harmless ফাইল নিৰীহ যেন দেখুৱাবলৈ নাম সলনি কৰা
    (D) share an encrypted link with an expiry and a separate password channel ম্যাদ আৰু বেলেগ পথেৰে পাছৱৰ্ডসহ এনক্ৰিপ্ট লিংক ভাগ কৰা
    Answer: D) share an encrypted link with an expiry and a separate password channel
    D) ম্যাদ আৰু বেলেগ পথেৰে পাছৱৰ্ডসহ এনক্ৰিপ্ট লিংক ভাগ কৰা
    Explanation: An encrypted link with an expiry limits who can open it and for how long, and sending the password by another channel keeps both halves apart. A plain attachment, pasted contents or a renamed file all travel readable.
    ম্যাদযুক্ত এনক্ৰিপ্ট লিংকে কাৰ কিমান দিন খুলিব পাৰে সীমিত কৰে, আৰু পাছৱৰ্ড বেলেগ পথেৰে পঠিয়ালে দুয়ো অৰ্ধ পৃথক থাকে। সাধাৰণ সংলগ্ন, ভৰোৱা বস্তু বা নাম সলনি কৰা ফাইল সকলোৱে পঢ়িব পৰাকৈ যায়।
    Q48. An employee is asked to grant remote access to a caller claiming to fix a virus. The correct response is to
    কৰ্মচাৰীক ভাইৰাছ মেৰামতিৰ বাহানা কৰি এজন কলকৰ্তাক দূৰ প্ৰৱেশ দিবলৈ কোৱা হ'ল। শুদ্ধ সঁহাৰি
    (A) grant access but watch the screen প্ৰৱেশ দি স্ক্ৰীণ চাই থাকা
    (B) give the password instead of access প্ৰৱেশৰ সলনি পাছৱৰ্ড দিয়া
    (C) refuse and report it to the security team নাকচ কৰি সুৰক্ষা দলক জনোৱা
    (D) grant access because the caller sounds official কলকৰ্তা চৰকাৰী যেন শুনা বাবে প্ৰৱেশ দিয়া
    Answer: C) refuse and report it to the security team
    C) নাকচ কৰি সুৰক্ষা দলক জনোৱা
    Explanation: Unsolicited remote access is the standard technique for installing malware and stealing data, so it is refused and reported. Sounding official proves nothing, watching does not stop the actions, and a password is worse than access.
    অননুৰোধিত দূৰ প্ৰৱেশ মেলৱেৰ ইনষ্টল আৰু তথ্য চুৰিৰ প্ৰচলিত পদ্ধতি, সেয়ে নাকচ কৰি জনায়। চৰকাৰী যেন শুনাটোৱে একো প্ৰমাণ নকৰে, চাই থকিলেও কাম ৰোধ নহয়, আৰু পাছৱৰ্ড দিয়া প্ৰৱেশতকৈ বেয়া।
    Q49. A company's backups are stored on a drive that stays connected to the server. The weakness is that
    কোম্পানীৰ বেকআপ চাৰ্ভাৰৰ লগত সংযুক্ত ড্ৰাইভত ৰখা হয়। দুৰ্বলতা —
    (A) the backups take up no space বেকআপে স্থান নলয়
    (B) ransomware can encrypt the backups too ৰেনছমৱেৰে বেকআপো এনক্ৰিপ্ট কৰিব পাৰে
    (C) the drive uses too much electricity ড্ৰাইভে অতি বেছি বিদ্যুৎ খৰচ কৰে
    (D) the server becomes too fast চাৰ্ভাৰ অতি দ্ৰুত হয়
    Answer: B) ransomware can encrypt the backups too
    B) ৰেনছমৱেৰে বেকআপো এনক্ৰিপ্ট কৰিব পাৰে
    Explanation: Malware that reaches the server reaches every attached volume, so an online backup is encrypted along with the data it should restore. Power use, speed and space are not the security concern.
    চাৰ্ভাৰলৈ যোৱা মেলৱেৰে সংযুক্ত প্ৰতিটো ভলিউমলৈ যায়, সেয়ে অনলাইন বেকআপ তাক ঘূৰাই অনা তথ্যৰ লগতে এনক্ৰিপ্ট হয়। বিদ্যুৎ খৰচ, গতি আৰু স্থান সুৰক্ষাৰ চিন্তা নহয়।
    Q50. An organisation must reduce the harm from a successful password guess. The control that limits the damage is
    সংস্থাই সফল পাছৱৰ্ড অনুমানৰপৰা হোৱা ক্ষতি কমাব লাগে। ক্ষতি সীমিত কৰা নিয়ন্ত্ৰণ
    (A) role based access so an account reaches only what it needs ভূমিকা-ভিত্তিক প্ৰৱেশ যাতে একাউণ্টে কেৱল প্ৰয়োজনীয়টোৱেই পায়
    (B) a longer welcome message দীঘল স্বাগতম বাৰ্তা
    (C) a faster login page দ্ৰুত লগইন পৃষ্ঠা
    (D) a bigger logo ডাঙৰ ল'গ'
    Answer: A) role based access so an account reaches only what it needs
    A) ভূমিকা-ভিত্তিক প্ৰৱেশ যাতে একাউণ্টে কেৱল প্ৰয়োজনীয়টোৱেই পায়
    Explanation: Least privilege means a compromised account exposes only its own scope, which caps the damage whatever the password. Messages, page speed and logos have no effect on what an attacker can reach.
    ন্যূনতম অধিকাৰৰ অৰ্থ ক্ষতিগ্ৰস্ত একাউণ্টে কেৱল নিজৰ পৰিসৰ উন্মোচন কৰে, যিয়ে পাছৱৰ্ড যিয়েই নহওক ক্ষতি সীমাবদ্ধ কৰে। বাৰ্তা, পৃষ্ঠাৰ গতি আৰু ল'গ'ই আক্ৰমণকাৰীয়ে কি পাব পাৰে তাত প্ৰভাৱ নপেলায়।
